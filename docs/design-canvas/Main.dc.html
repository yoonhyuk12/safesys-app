기반 — 색과 표면

의미색 — 안전 도메인
색은 장식이 아니라 상태다. 아래 짝 이외의 조합을 새로 만들지 않는다.
위험 · 미이행
미점검, 부적합, 사고, 기한 초과. 바탕 red-50/100, 글자 red-600~800, 채운 버튼 red-600.
주의 · 대기
기한 임박, 승인 대기, 자재 원장. 바탕 amber-50/100, 글자 amber-600~800.
정상 · 완료
점검 완료, 적합, 서명 완료. 바탕 green-50/100, 글자 green-600~800. emerald는 같은 뜻의 대체가 아니라 지급자재·계약 계열에만 쓴다.
진행 · 정보
진행 중, 안내, 선택된 항목. 바탕 blue-50/100, 글자 blue-700~900.
폭염 · 기상
폭염 단계, 기상특보. orange 계열은 이 도메인에만 쓰고 일반 경고에 쓰지 않는다.
해당 없음
미해당, 종료, 비활성. 바탕 gray-100, 글자 gray-800 또는 gray-500.
표면 계층
아래로 갈수록 앞에 놓인다. 계층을 건너뛰지 않는다.
1 · 셸 (앱 바탕)
min-h-screen bg-gradient-to-b from-blue-950 via-blue-900 to-slate-900
대시보드·게시판 등 전체 화면. 단독 폼 페이지는 대신 bg-gray-50.
2 · 셸 위 패널
bg-white/80 backdrop-blur rounded-lg border border-white/20 shadow-sm
어두운 셸 위에 얹는 반투명 패널. 그 안의 카드는 불투명 흰색으로 돌아간다.
3 · 카드 (정본 · 코드 내 49회)
bg-white rounded-lg shadow-sm border border-gray-200 overflow-hidden
모든 콘텐츠 블록의 기본 그릇. 표를 담을 때 overflow-hidden이 모서리를 잘라준다.
4 · 모달
덮개 fixed inset-0 bg-black/50 … z-50 p-4 · 본체 bg-white rounded-lg shadow-xl
모달만 shadow-xl을 쓴다. 그림자로 계층을 표현하는 유일한 지점이다.
