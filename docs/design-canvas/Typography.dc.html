SafeSys Design System · 02

타이포그래피와 밀도

SafeSys는 현장 관리자가 표와 숫자를 훑는 고밀도 업무 화면이다. 본문 기본은 14px(text-sm)이고 표·라벨은 12px(text-xs)이다. 16px 이상은 화면 제목에만 쓴다.
