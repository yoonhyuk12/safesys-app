SafeSys Design System · 05

쓰지 말 것

코드에 실제로 남아 있는 이탈들이다. 괄호 안 숫자는 현재 사용 횟수. 기존 코드를 지금 일괄 수정하지는 않는다 — 해당 파일을 다른 이유로 열었을 때 그 자리만 정본으로 바꾼다. 새로 쓰는 코드는 처음부터 오른쪽을 쓴다.

쓰지 말 것
대신 이것
bg-black bg-opacity-50 (70)
Tailwind v3 잔재. v4에서는 슬래시 표기가 정식이다.
bg-black/50 (27)
모든 *-opacity-* 유틸리티에 같은 규칙이 적용된다.
bg-white rounded-xl shadow-sm border border-gray-100 (8)
카드 모서리·테두리가 다른 화면과 어긋난다.
bg-white rounded-lg shadow-sm border border-gray-200 (49)
겉 테두리는 gray-200, 카드 안쪽 구분선만 gray-100이다.
globals.css의 .card / .button / .select-control / .safe-documents-*
두 벌이 글자 하나 안 틀리고 복제되어 있다. 한쪽만 고치면 조용히 어긋난다.
Tailwind 유틸리티 클래스
새 코드에서 이 전역 클래스를 쓰지 않는다. globals.css에는 웹폰트·애니메이션·html2canvas 보정만 남긴다.
bg-[#EBF1F5] · text-[#0b1730] 같은 임의 hex (30)
팔레트 밖의 값은 다음 화면에서 재현되지 않는다.
팔레트 단계 (gray-100, blue-950 …)
외부 브랜드색(카카오·네이버 버튼 등)은 예외로 허용하되, 그 자리에만 쓴다.
text-[9px] · text-[8px] (24)
햇빛 아래 현장에서 읽히지 않는다.
text-[10px] 이상
더 담아야 하면 글자를 줄이지 말고 열을 접거나 화면을 나눈다.
이모지를 UI 아이콘으로 (컴포넌트 34개 파일 199회)
OS마다 모양이 달라지고, 크기·색을 맞출 수 없으며, PDF·Excel 출력에서 깨진다.
lucide-react · h-4 w-4
특히 문서로 출력되는 화면에서는 예외 없이. 콘솔 로그의 이모지는 그대로 둬도 된다.
dark: 변형 (현재 0회 — 유지)
globals.css가 color-scheme: light only로 다크모드를 전역 차단하고 있어, 써도 켜지지 않는다.
라이트 모드 단일 팔레트
다크모드를 도입하려면 디자인 결정으로 따로 다뤄야 한다. 화면 단위로 끼워 넣지 않는다.
아직 결정되지 않은 것 — 본문 글꼴
layout.tsx는 Geist Sans를 Google Fonts에서 불러오고 --font-geist-sans까지 연결해 두었지만, 코드 어디에서도 font-sans를 쓰지 않는다(0회). 그래서 실제 화면은 globals.css의 body { font-family: Arial, Helvetica, sans-serif }로 그려지고, Geist는 매 방문마다 받기만 하고 버려진다. 둘 중 하나로 정해야 한다 — (가) body를 var(--font-geist-sans)로 바꿔 Geist를 실제로 쓰거나, (나) layout.tsx의 Geist 로드를 걷어내 낭비를 없애거나. 이 문서는 결정 전까지 현행(Arial)을 기준으로 적는다.
