# TBM AI 작성 완료 알림 문구 설계

## 목적

AI가 TBM 위험요인 칸을 채운 뒤 사용자가 수시 위험성평가와의 연계성을 확인하고 필요한 내용을 수정하도록 안내한다.

## 변경 범위

- 기존 AI 작성 완료 정보는 유지한다.
- 완료 정보 다음 줄에 `수시 위험성평가와 연계성을 확인하고 필요시 수정 바랍니다.`를 표시한다.
- AI 오류 알림과 화면의 다른 안내 문구는 변경하지 않는다.

## 검증

- AI 작성 완료 알림에 지정 문구가 정확히 포함되는지 회귀 테스트로 확인한다.
- TypeScript 타입 검사를 실행한다.
