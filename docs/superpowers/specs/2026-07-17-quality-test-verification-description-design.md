# 확인시험 선택 카드 설명 문구 수정 설계

## 목적

품질시험 실시대장에서 시험·검사구분을 선택할 때 표시되는 `확인시험` 설명을 실제 업무 흐름에 맞춘다.

## 변경 범위

- `QualityTestRecordsTab`의 `TEST_CATEGORY_DEFINITIONS`에 정의된 확인시험 설명 한 문장만 수정한다.
- 기존의 시험 결과를 검증하거나 확인한다는 설명은 제거한다.
- 공사감독자가 본부 품질담당에게 시험을 의뢰한다는 주체와 수신자를 명확히 표시한다.
- 다른 시험구분의 설명, 화면 구조, 데이터 처리 로직은 변경하지 않는다.

## 확정 문구

> 공사감독자가 본부 품질담당에게 의뢰해 진행하는 시험입니다.

## 검증 기준

- 코드에서 기존 확인시험 설명이 더 이상 검색되지 않는다.
- 확인시험 선택 카드에 확정 문구가 표시된다.
- 린트와 TypeScript 타입 검사가 통과한다.
