# TBM AI 위험분석 입력 길이 조정 설계

## 목적

TBM 제출 화면의 위험분석 내용을 수기로 충분히 보완할 수 있게 하면서, AI가 생성하는 초안은 현재보다 구체적으로 작성하도록 한다.

## 변경 범위

- 잠재위험요인 1~3 입력칸의 최대 길이를 15자에서 50자로 변경한다.
- 대책 1~3 입력칸의 최대 길이를 15자에서 50자로 변경한다.
- 잠재위험요소 1~3 입력칸에 최대 50자 제한을 추가한다.
- 중점위험요인과 중점위험요인 대책은 앞선 위험요인·대책을 자동으로 가져오므로 별도 입력 제한을 추가하지 않는다.
- AI 위험분석 프롬프트의 길이 지시를 `각각의 칸에 30자 이내로 작성해주세요.`로 변경한다.

## 동작 기준

- 사용자는 각 수기 입력칸에 최대 50자까지 입력할 수 있다.
- AI는 잠재위험요인, 대책, 중점위험요인, 중점위험요인 대책, 잠재위험요소 각각을 30자 이내로 생성하도록 요청받는다.
- AI 응답을 코드에서 강제로 잘라 문장이 중간에 끊기게 하지 않는다.
- 기존 저장 데이터와 데이터베이스 스키마는 변경하지 않는다.

## 검증

- 잠재위험요인·대책·잠재위험요소 입력칸에서 50자까지 입력되고 51번째 문자는 입력되지 않는지 확인한다.
- AI API 프롬프트에 각 칸별 30자 이내 작성 지시가 포함되는지 확인한다.
- TypeScript 타입 검사를 실행한다.
