# TBM 도구 모음 날짜·아이콘 버튼 표시 설계

## 목표

TBM 현황의 데스크톱 기록 헤더에서 날짜를 짧고 일관된 형식으로 표시하고, 복사·단체문자 버튼의 텍스트가 두 줄로 꺾이지 않게 한다.

## 변경 범위

- 대상은 `safesys-app/src/components/project/TBMStatus.tsx`의 데스크톱 TBM 기록 헤더다.
- 날짜 선택 값과 변경 이벤트는 기존 `input[type="date"]`를 그대로 사용한다.
- 화면에 보이는 날짜만 `YY.MM.DD` 형식으로 표시한다. 예를 들어 `2026-07-16`은 `26.07.16`으로 표시한다.
- 복사·단체문자 버튼은 화면 폭과 관계없이 아이콘만 표시한다.
- 아이콘만 표시되어도 기존 `title`을 유지하고 명시적인 접근성 이름을 제공한다.

## 구현 방식

날짜 입력을 상대 위치 컨테이너로 감싼다. 네이티브 날짜 입력의 편집 텍스트는 투명하게 처리하고, 포인터 이벤트가 없는 표시용 텍스트를 입력 위에 겹친다. 표시 문자열은 기존 ISO 날짜 값에서 연도 앞 두 자리를 제거하고 하이픈을 점으로 바꾼다. 달력 선택과 키보드 입력 동작은 네이티브 입력이 계속 담당한다.

복사·단체문자 버튼의 텍스트 노드는 제거하고 아이콘은 유지한다. JavaScript 너비 측정, 리사이즈 상태, 반응형 라벨 조건은 추가하지 않는다.

## 검증 기준

- 선택 값 `2026-07-16`이 화면에서 `26.07.16`으로 보인다.
- 날짜 입력을 클릭하면 기존 날짜 선택기가 열리고 날짜 변경이 정상 반영된다.
- 모든 데스크톱 화면 폭에서 복사·단체문자 버튼이 아이콘만 표시된다.
- 툴팁과 접근성 이름으로 각 버튼의 목적을 알 수 있다.
- TypeScript 검사와 ESLint 검사를 통과한다.
