# 외과적 변경과 완료 전 검증

- 요청과 무관한 코드·포맷·주석을 "개선"하지 않는다. 변경된 모든 줄이 요청으로 직접 추적되어야 한다.
- 인접 코드의 스타일이 마음에 안 들어도 손대지 않는다. 필요하면 별도 제안으로 보고한다.
- 코드를 건드렸으면 "완료"라고 말하기 전에 `npm run lint`, `npx tsc --noEmit`, 관련 테스트를 돌리고 결과를 사실대로 보고한다. 실패했으면 실패했다고 쓴다.
- 문서가 코드 동작과 어긋나면 그것은 버그다. 발견 즉시 `docs/`를 갱신한다.
