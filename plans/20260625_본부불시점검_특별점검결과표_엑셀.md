# 본부불시점검 엑셀 출력 → 「특별점검 결과표」 양식 변경

## 배경
`/safe/headquarters` 페이지의 "엑셀" 버튼은 현재 사업별 분기 점검 O/X 표(`headquarters-inspection-export.ts`)를 내보낸다. 이를 새 양식 `public/점검예시/1. 특별점검 총괄표(양식)_변경.xlsx` 형태(3단 병합 헤더 + 15개 점검항목 × 여/부/해당없음 + 조치결과 + 비고 + 계 행)로 바꾼다.

## 결정 사항 (사용자 확정)
- 행 데이터: SafeSys DB에 등록된 **모든 지구(준공 제외)**를 각각 1행. `is_active.completed === true` 제외.
- 점검 내용: 해당 분기에 점검 이력이 있는 지구만 채움. 여러 건이면 **최신 점검 1건**.
- 상태 매핑: `good→여(O)`, `bad→부(O)`, 점검은 있으나 미선택(`''`)→`해당없음(O)`. 점검 이력 없는 지구는 점검칸 전부 공백.
- 항목 순서 매핑: DB `critical_items(5)+caution_items(3)+other_items(7)` = 양식 15개 항목 순서. 인덱스 기준 매핑(제목 문구가 양식과 미세하게 달라 인덱스로 매핑).

## 컬럼 매핑
| 양식 | DB |
|---|---|
| 본부/사업단(B) | managing_hq |
| 지사(C) | managing_branch |

| 세부사업명(E) | project_name |

| H~AZ | 15항목 × 여/부/해당없음 (item k: 여=8+k*3, 부=9+k*3, 해당없음=10+k*3) |
| 조치결과(BA소계/BB여/BC부/BD해당없음) | 행별 COUNTA 수식 |
| 비고(BE) | 공백 |
| 계(R7) | 컬럼별 COUNTA / SUM 수식 |

## 추가 요청 반영 (2026-06-25)
- G7(계·점검일)에 `COUNTA(G8:G_last)`로 해당 분기 점검 건수 카운트.
- 점검항목 셀 배경색을 샘플 양식과 동일하게(Office theme+tint): 굴착기=theme9, 추락=theme5, 기타사항=theme8, 헤더 tint 0.6 / 데이터 tint 0.8, 좌측·조치결과 theme0 tint -0.05(연회색), 비고·점검일 흰색.
- 조치결과: 부(BC)는 항상 0, 여(BB)=여+부 합산(조치완료로 간주), 해당없음(BD) 유지.
- ExcelJS는 fgColor의 theme+tint를 그대로 왕복(검증) → 샘플 테마와 100% 동일 렌더.

## 추가 요청 반영 (2026-06-25, 2차)
- 점검일(G) 좌측에 「공사중 여부」 컬럼 신설 → 컬럼이 한 칸씩 이동(G=공사중, H=점검일, 점검항목 I부터, 조치결과 BB~BE, 비고 BF). 컬럼 좌표가 상수 파생이라 기준 상수만 변경.
- 공사중 여부 값: `is_active.q{선택분기}` true→`O`, false→`X`(레거시 boolean은 그 값). 준공 제외는 그대로 유지.
- 점검 건수 카운트는 점검일 컬럼(H)을 따라 이동. `COUNTA(H8:H_last)`.
- 공사중(O)인데 해당 분기 점검 이력이 없는 행은 전체를 연한 빨강(`FFFF9999`) 배경 + 굵은 진빨강(`FF9C0006`) 글씨로 강조(누락 점검 식별). 공사중 아님(X)은 강조 제외.

## 점검 건수 관련 메모 (사용자 문의 reconcile)
- 경기 본부 2분기 점검 레코드 94건 → 프로젝트(지구) 단위 중복 제거 시 79개(1회 70, 2회 6, 3회 2, 6회 1). 엑셀 79는 정확. 점검일은 지구별 최신 1건.
