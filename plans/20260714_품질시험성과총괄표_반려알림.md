# 품질시험 성과총괄표 반려 알림

## Plan

- 성과총괄표의 검토자 서명 칸에 감독용 반려 통보 동작을 추가한다.
- 반려 사유와 미확인 상태를 `quality_summary_reports`에 저장하고 작성자가 확인할 수 있게 한다.
- 미확인 반려 문서 수를 프로젝트 카드, 품질 캐비넷, 품질시험 결과 관리대장 서류철에 파란 뱃지로 표시한다.
- 타입 검사, 린트, 관련 단위 테스트로 회귀 여부를 확인한다.

## Context

- 반려 1건은 미확인 상태인 성과총괄표 1건으로 집계한다.
- 반려 권한은 발주청·감리단 사용자에게 노출하며 검토자 서명을 반려 대상으로 삼는다.
- 작성자가 반려 내용을 확인하면 `rejection_read_at`을 기록해 뱃지에서 제외한다.
- 반려 RPC는 역할뿐 아니라 프로젝트 소유·공유·조직 관할 범위를 직접 검사한다.
- `npx tsc --noEmit`과 `npm run lint`를 통과했다. 린트에는 기존 경고만 남아 있다.
- 공용 `checklist.md`, `context-notes.md`에는 다른 작업 변경이 있어 이 작업 전용 문서만 사용한다.
