# 품질시험 성과총괄표 반려 알림

## Plan

- 성과총괄표의 검토자 서명 칸에 모든 역할이 볼 수 있는 반려 통보 버튼을 표시하고 발주청만 실행할 수 있게 한다.
- 반려 사유와 미확인 상태를 `quality_summary_reports`에 저장하고 작성자가 확인할 수 있게 한다.
- 미확인 반려 문서 수를 프로젝트 카드, 품질 캐비넷, 품질시험 결과 관리대장 서류철에 파란 뱃지로 표시한다.
- 타입 검사, 린트, 관련 단위 테스트로 회귀 여부를 확인한다.

## Context

- 반려 1건은 미확인 상태인 성과총괄표 1건으로 집계한다.
- 반려 통보 버튼과 처리 여부는 모든 역할에 표시하되 실행 권한은 발주청 사용자에게만 부여하며 검토자 서명을 반려 대상으로 삼는다.
- 작성자가 반려 내용을 확인하면 `rejection_read_at`을 기록해 뱃지에서 제외한다.
- 2026-07-14 권한 수정으로 반려 RPC는 발주청 역할만 검사하며 프로젝트 소유·공유·조직 관할 추가 제한은 적용하지 않는다.
- UI는 모든 역할에 버튼을 표시하고 비발주청에게 권한 안내와 비활성 상태를 제공하며, API와 RPC가 각각 발주청 역할을 검증해 직접 요청과 RPC 우회를 함께 차단한다.
- 반려 UI는 서비스 역할 기반 API를 호출하므로 신규 RPC 권한 마이그레이션 적용 전에도 동작하며, 마이그레이션은 직접 RPC 호출을 제한하는 방어선이다.
- `npx tsc --noEmit`과 `npm run lint`를 통과했다. 린트에는 기존 경고만 남아 있다.
- 공용 `checklist.md`, `context-notes.md`에는 다른 작업 변경이 있어 이 작업 전용 문서만 사용한다.
