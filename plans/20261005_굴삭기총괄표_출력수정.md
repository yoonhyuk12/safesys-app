# 굴삭기 특별점검 총괄표 출력 수정

- D열 제목을 사업유형으로 바꾸고 프로젝트 사업구분(project_category)을 출력한다.
- F열은 지구명까지만 추출한다. 점검 지구명 우선, 비어 있으면 프로젝트명에서 추출한다.
- U열 안전핀 사진의 실제 크기와 비율을 보존해 셀 안에 배치한다.
- 기존 권한·조회·다른 다운로드와 사전 미커밋 변경은 보존한다. 빌드·운영 배포는 하지 않는다.

## 순서와 검증

1. 기존 다운로드 파일 XML과 기존 사진 배치 헬퍼 조사.
2. Worker가 회귀 테스트를 먼저 작성하고 출력 모듈을 최소 수정.
3. Advisor가 변경 비교, lint, tsc, 특별점검 테스트 및 실제 파일 사진 크기 확인.

관련 기록은 `20261005_굴삭기총괄표_출력수정/`에 둔다.
