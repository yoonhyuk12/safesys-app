# CLAUDE.md → 하네스(Harness) 구조 개편

OpenAI "Harness engineering" 글의 핵심 처방(리포지터리 지식을 기록 시스템으로)을 SafeSys에 적용한다.

## 배경 (문제)

현재 `CLAUDE.md`는 471줄 모놀리식 백과사전이다. 글이 지적하는 "하나의 큰 AGENTS.md" 안티패턴 그대로다.

- 컨텍스트는 희소 자원인데 거대 지침이 주요 제약을 묻어버린다.
- 지침이 너무 많으면 지침이 되지 않는다 — 에이전트가 탐색 대신 로컬 패턴매칭을 한다.
- 순식간에 낡은 규칙의 무덤이 된다.
- 단일 블롭은 기계적 점검(신선도·소유권·교차링크)에 부적합하다.

## 처방 (목표)

CLAUDE.md를 **목차(map, ~100줄)** 로 줄이고, 상세 지식은 구조화된 **`docs/` 기록 시스템**으로 옮겨 점진적 공개(progressive disclosure)가 되게 한다.

```
CLAUDE.md            # ~100줄 map: 역할분담·핵심 안전규칙·명령어·docs 목차
AGENTS.md            # CLAUDE.md를 가리키는 포인터
docs/
├── index.md         # 지식 베이스 목차 (네비게이션 허브)
├── architecture.md  # 기술스택·Dashboard 라우팅·라우트·API·컴포넌트·유틸·타입
├── conventions.md   # Advisor/Worker 상세·행동 가이드라인 10개·코딩 스타일
├── database.md      # 테이블·CASCADE 규칙·일괄서명 규칙·마이그레이션·MCP
├── auth.md          # 역할체계·조직구조·접근권한·인증 플로우
├── environment.md   # 개발 명령어·main push=배포·env 변수·API 키 위치
└── troubleshooting.md # 빌드캐시·refreshProfile·html2canvas PDF 버그
```

## Context Notes (결정 로그)

- **docs 위치**: 루트 `docs/` 신설. 글 예시와 동일 계층, 사람·에이전트 모두 발견성 최상. (`.claude/docs/`는 기존 가이드 유지)
- **이관 원칙**: 원본 내용은 손실 없이 옮긴다. map에는 "가장 중요한 제약"만 인라인으로 남기고 나머지는 링크.
- **.claude/rules 처리**: 이 디렉터리는 install.sh를 가진 이식형 룰셋이라 본문을 통째로 지우면 룰셋이 깨진다. 따라서 본문은 보존하되 각 파일 상단에 "이 프로젝트의 canonical 출처는 docs/…" 포인터를 추가하는 방식으로 통합(=단일 진실 출처는 docs, rules는 미러). 이 절충은 사용자에게 보고한다.
- **map에 인라인 유지할 핵심 안전규칙**: (1) main 푸시=자동 배포, (2) prod 빌드 무단 시작 금지, (3) Advisor/Worker 역할분담, (4) 한국어 출력·마침표 규칙.
