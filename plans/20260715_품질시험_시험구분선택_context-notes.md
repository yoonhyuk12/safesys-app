# 품질시험 실시대장 시험구분 선택 컨텍스트 노트

- 대상은 `safesys-app/src/components/project/quality/QualityTestRecordsTab.tsx`의 헤더 및 빈 상태 `추가` 버튼이다.
- 시험구분의 단일 기준은 기존 `TEST_CATEGORY_OPTIONS` 상수이며 값은 `자체(관리)시험`, `의뢰(수탁)시험`, `확인시험`이다.
- 기존 신규 등록 함수는 자체시험을 기본값으로 가진 `createEmptyQualityTestCommon`을 사용하므로, 선택한 시험구분을 초기 객체에 명시적으로 덮어쓴다.
- 수정 진입은 선택 창을 거치지 않고 기존 동작을 유지한다.
- 대상 컴포넌트에는 감독 서명과 저장 필드 관련 기존 미커밋 변경이 있으므로 해당 줄을 재작성하거나 되돌리지 않는다.
- 별도 범용 모달 추상화 없이 대상 컴포넌트 안에 최소 UI를 추가한다.
- 시험구분 설명은 사용자가 비교하기 쉬운 한 문장 정의만 유지하며 공사감독 역할 설명은 표시하지 않는다.
- 시험구분 카드는 자체시험은 앰버, 의뢰시험은 스카이, 확인시험은 에메랄드 계열 아이콘 카드로 구분한다.
- 프리셋은 기존 자동 입력 로직을 그대로 사용하고 표시 구조만 이전 기록·토공·콘크리트로 정돈한다.
- 콘크리트 프리셋은 기본 5개 항목과 슈미트해머 1개 항목을 먼저 선택한 뒤, 강도·골재·슬럼프가 표시된 규격 카드를 선택한다.
- `npx tsc --noEmit`, 대상 파일 ESLint, `git diff --check`가 통과했다.
- 브라우저에서 시험구분 선택 카드와 프리셋 카드가 표시되는 것을 확인했으며 실제 저장은 수행하지 않았다.
- 대상 파일에 다른 동시 작업의 미커밋 변경이 겹쳐 있어 해당 변경을 섞지 않도록 별도 커밋은 만들지 않는다.
