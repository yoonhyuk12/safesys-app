# AI 작업계획서 보완 1 — 확인 어려운 정보 지연 입력

> [본 계획서](./20260711_AI작업계획서_서류철.md)의 보완. Phase 1 구현 완료 후 추가된 요구다. 체크리스트는 [기존 파일](./20260711_AI작업계획서_서류철_checklist.md)의 "보완 1" 섹션을 사용한다.

## 요구사항

작업계획서 항목 중 **작성자 개인이 당장 확인하기 어려운 정보**(장비 제원·검사유효기간·보험·줄걸이 절단하중 등)는 작성 흐름을 막지 않도록 한다.

1. 해당 필드들을 마법사 **맨 마지막 입력 스텝**("나중 확인 정보")으로 분리한다.
2. 전부 **공란 허용** — 비워둔 채 저장·PDF 출력 가능(원본 양식도 빈칸 서식이므로 출력 후 수기 기입과 동일한 효과).
3. 저장된 등록건을 목록에서 다시 열어 **이어서 입력(재편집)** 할 수 있다.

## 설계

### 1. 필드 분류 (구현된 `src/lib/work-plan/types.ts` 기준)

**즉시 입력 그룹(기본정보 스텝 유지)** — 작업명·기간·시간·업체·작업자·지휘자/운전원/유도자·작업내용·차량번호·작업방법/순서·사전조사(현장 확인 사항)·안전보건교육·보호구/사용장비·체크리스트 등 현장에서 바로 아는 정보.

**나중 확인 그룹(마지막 스텝으로 이동, 전 필드 공란 허용)**

| 서식 | 이동 대상 |
|------|-----------|
| loading (2-1) | `equipment`(LoadingEquipmentSpec 12필드 — 모델명/생산년도·보험기간·소유회사·검사유효기간·차체중량·장비폭·선회반경·인양높이·작업반경·인양하중 등), `liftingReview`, `riggingReview` |
| construction (2-2) | `equipment`(ConstructionEquipmentSpec — 등록번호·차체중량·능력), `operatorLicense`(운전원 면허) |
| electric (2-3) | `workers[].qualification`(보유자격 — 명단·근로형태는 즉시 그룹 유지, 자격만 공란 허용) |
| heavy (2-4) | `machine`(HeavyMachineSpec 10필드), `load`의 `dimensions`·`weightKg`·`transportWeightKg`(품명·형상·고정방법은 즉시 그룹 유지), `liftingReview`, `riggingReview` |

분류가 애매한 필드는 "현장에서 즉시 알 수 있는가"를 기준으로 구현 중 조정 가능. 단, 이동하더라도 공란 허용 원칙은 동일.

### 2. 마법사 스텝 재배치

기존 5단계에서 "나중 확인 정보" 스텝을 저장 직전에 삽입.

서류선택 → 기본정보(즉시 그룹) → 지도 → AI 검토 → **나중 확인 정보** → 저장/다운로드.

- "나중 확인 정보" 스텝에는 **"건너뛰고 저장"** 버튼을 두어 전부 비운 채 통과 가능.
- 필수 검증은 작업명(title)과 서류 선택(plan_types)만 유지. 나머지는 전부 공란 허용(숫자 필드 null, 문자열 빈값).
- AI 초안 생성은 나중 확인 정보 없이 동작해야 함(작업내용·작업명 기반 — 이미 그렇게 설계됨, 회귀 확인만).
- 인양·줄걸이 안전율 자동계산은 입력값이 채워진 경우에만 계산, 아니면 공란(타입이 이미 nullable이므로 계산·표시 로직만 확인).

### 3. 재편집(이어서 입력)

- 목록의 등록건에 **"수정"** 진입 추가 — `WorkPlanRecord`를 로드해 마법사(또는 편집 폼)에 프리필하고, 저장 시 UPDATE.
- 목록 행에 나중 확인 그룹이 비어 있으면 "입력 대기" 배지를 표시해 나중에 채울 건을 구분(간단한 필드 존재 검사 수준, 과설계 금지).

### 4. PDF 출력 (Phase 4에 반영)

- 공란 필드는 원본 양식과 동일하게 **빈칸으로 출력**(placeholder 텍스트 넣지 않음). 숫자 서식 `( )t`·`( )mm` 등은 괄호 안 공란 유지.
- 안전율 미계산 시 산식 칸도 공란.

## 완료 기준

- 나중 확인 그룹을 전부 비운 채 저장 → 목록 표시 → 재편집으로 채우기 → 다시 저장이 동작한다.
- 필수는 작업명·서류선택뿐임을 확인(그 외 어떤 공란도 저장을 막지 않음).
- `npx tsc --noEmit`·`npm run lint`(신규 파일 엄격 린트 포함) 통과.
