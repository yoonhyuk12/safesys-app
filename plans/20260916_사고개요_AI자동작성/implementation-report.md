# 사고 개요 AI 자동 작성 구현 보고.

제품 변경은 safesys-app/src/lib/accident-report-extraction.ts 한 파일의 system/prompt/schema 설명에 한정했다. 별도 경위가 없어도 보고요지·작업내용·사고원인 속 발생 경위·피해사실을 확인된 사실만으로 1~3문장 개요로 작성한다. 원문 없는 요소는 생략하고 사고 사실이 없으면 null을 유지한다. 원인 단순 복사·참조 문구·중복 라벨 묶음을 금지하며 cause는 명시된 사고 기전·발생 요인으로 구분한다.

테스트 파일에는 합성 개요의 중복 정리·재정규화 보존 및 입력 불변성 회귀와 프롬프트 상충 규칙 제거 검증을 추가했다. RED에서 신규 지시문 회귀 1개 실패, GREEN에서 추출 36개 통과했다.

- npx tsc --noEmit 통과.
- npm run lint 통과. 저장소 기존 경고가 존재한다.
- npm run test:accident-report 통과. 236개 중 235 pass, 기존 TODO 1, fail 0이다. 사용자 기존 입력 보호·UI·라우트·import·HWPX 테스트를 포함한다.
- git diff --check 통과. 정규화/helper/초안 병합/모델/API 로직은 변경하지 않았다.

기존 TODO는 계정 삭제 시 created_by 불변 트리거와 SET NULL의 충돌이다. 원격 SQL이나 프로덕션 빌드는 실행하지 않았다. 실제 AI 실측 및 브라우저·저장·한글 검증은 부모 담당이며 Worker 변경은 freeze 상태다.

부모 최종 검증을 완료했다. 원본 PDF 및 HWPX 모두 현재 Gemini API 실제 호출에서 문서 사실에 근거한 사고 개요가 생성됐다. 두 결과를 사용한 브라우저 자동 채움과 PDF 결과의 가상 저장·실제 HWPX 다운로드에서 개요 보존을 확인했다. HWPX 원본에 명시 원인이 없는 경우 원인을 비워 두며, 이 샘플은 입력 화면까지만 검증했다. 한글2022에서 생성 파일 열기·저장·재열기·PDF 변환이 통과했고 출력 3쪽 전체를 확인해 개요와 사진 2컷 표시를 검증했다. 부모 추출 회귀 36개 재실행과 diff 검토가 통과했다. 운영 데이터에는 쓰지 않았으며 기존 저장 행을 자동 변경하지 않는다. Worker는 검증 완료 후 회수했다.
