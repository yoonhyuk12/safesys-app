# 지급자재 박스 드래그 앤 드롭 자리이동 기능

**작성일**: 2026-03-24
**대상 파일**: `safesys-app/src/app/project/[id]/material-ledger/page.tsx`

## 현황 분석

### 현재 동작
- 롱프레스(500ms) → 드래그 시작 → 화면 상단 쓰레기통에 드롭하면 삭제
- 자재 순서: `created_at ASC` (생성순 고정, 변경 불가)
- DB `materials` 테이블에 순서 컬럼 없음

### 목표
모바일 앱 아이콘 이동처럼 롱프레스 후 드래그로 자재 박스의 위치를 자유롭게 변경 가능하게 함.
쓰레기통 삭제 기능도 유지.

---

## 구현 계획

### Phase 1: DB 스키마 변경

**`materials` 테이블에 `sort_order` 컬럼 추가**

```sql
ALTER TABLE materials ADD COLUMN sort_order INTEGER DEFAULT 0;

-- 기존 데이터에 순서 부여 (created_at 순)
WITH ordered AS (
  SELECT id, ROW_NUMBER() OVER (PARTITION BY project_id ORDER BY created_at ASC) AS rn
  FROM materials
)
UPDATE materials SET sort_order = ordered.rn
FROM ordered WHERE materials.id = ordered.id;
```

- Supabase 웹 콘솔에서 직접 실행 필요 (MCP 읽기 전용)
- 마이그레이션 파일: `database/add_materials_sort_order.sql`

### Phase 2: 프론트엔드 수정

#### 2-2. 자재 추가 시 sort_order 설정


#### 2-3. 드래그 동작 변경 (핵심)

**현재**: 롱프레스 → 드래그 → 쓰레기통에 놓으면 삭제
**변경**: 롱프레스 → 드래그 → **다른 박스 위에 놓으면 자리교환** / **쓰레기통에 놓으면 삭제**

구현 방식:

1. **드래그 중 hover 대상 감지**
   - `handleDragMove`에서 현재 커서 아래의 자재 박스를 감지
   - 각 자재 박스에 `data-material-id` 속성 부여
   - `document.elementFromPoint(x, y)`로 hover 대상 식별
   - hover된 박스에 시각적 피드백 (빈자리 표시 또는 밀림 애니메이션)

2. **드롭 시 순서 변경**
   - 쓰레기통 위: 기존과 동일하게 삭제
   - 다른 박스 위: 드래그한 아이템을 해당 위치로 이동 (나머지는 밀림)
   - DB `sort_order` 업데이트

3. **시각적 피드백**
   - 드래그 중인 박스: 플로팅 (기존과 동일)
   - 원래 자리: 빈 슬롯 표시 (현재 `opacity-30`)
   - hover 대상: 좌우로 밀리는 애니메이션 (삽입 위치 표시)
   - 전체 그리드: 드래그 중 약한 진동(wobble) 효과 (모바일 앱 느낌)

#### 2-4. 상태 추가

```typescript

const [draggingMaterialId, setDraggingMaterialId] = useState<string | null>(null)
const [dragPosition, setDragPosition] = useState<{ x: number; y: number } | null>(null)
const [isOverTrash, setIsOverTrash] = useState(false)

// 신규 상태
const [dropTargetIndex, setDropTargetIndex] = useState<number | null>(null)  // 드롭 대상 위치
```

#### 2-5. 순서 저장 함수

```typescript
const handleReorder = async (fromIndex: number, toIndex: number) => {
  // 1. 로컬 상태 즉시 업데이트 (optimistic)
  const newMaterials = [...materials]
  const [moved] = newMaterials.splice(fromIndex, 1)
  newMaterials.splice(toIndex, 0, moved)
  setMaterials(newMaterials)

  // 2. DB 순서 업데이트
  const updates = newMaterials.map((m, i) => ({
    id: m.id,
    sort_order: i + 1
  }))

  for (const u of updates) {
    await supabase.from('materials')
      .update({ sort_order: u.sort_order })
      .eq('id', u.id)
  }
}
```

#### 2-6. handleDragEnd 수정

```typescript
const handleDragEnd = useCallback(() => {
  if (draggingMaterialId) {
    if (isOverTrash) {
      // 쓰레기통에 드롭 → 삭제
      handleDeleteMaterial(draggingMaterialId)
    } else if (dropTargetIndex !== null) {
      // 다른 위치에 드롭 → 자리 이동
      const fromIndex = materials.findIndex(m => m.id === draggingMaterialId)
      if (fromIndex !== -1 && fromIndex !== dropTargetIndex) {
        handleReorder(fromIndex, dropTargetIndex)
      }
    }
  }
  // 상태 초기화
  setDraggingMaterialId(null)
  setDragPosition(null)
  setIsOverTrash(false)
  setDropTargetIndex(null)
  // ...기존 코드
}, [draggingMaterialId, isOverTrash, dropTargetIndex, materials])
```

### Phase 3: 시각적 피드백

#### 3-1. 드래그 중 그리드 아이템 애니메이션

```tsx
// 각 자재 박스에 transition 적용
<div
  data-material-index={idx}
  className={`
    relative group select-none
    transition-transform duration-200
    ${isDragging ? 'opacity-30 scale-95' : ''}
    ${dropTargetIndex === idx && !isDragging ? 'translate-x-2' : ''}
  `}
>
```

#### 3-2. 삽입 위치 인디케이터

드래그 중 hover된 박스 옆에 빛나는 세로선 표시:
- 좌측 절반 hover → 왼쪽에 삽입선
- 우측 절반 hover → 오른쪽에 삽입선

#### 3-3. 모바일 앱 스타일 wobble 효과 (선택사항)

```css
@keyframes wobble {
  0%, 100% { transform: rotate(0deg); }
  25% { transform: rotate(-1deg); }
  75% { transform: rotate(1deg); }
}
```

드래그 모드 진입 시 모든 박스에 미세한 흔들림 적용.

## 고려사항

- **Optimistic UI**: 드래그 즉시 로컬 상태 업데이트, DB는 비동기 저장
- **실패 시 롤백**: DB 저장 실패 시 원래 순서로 복원
- **쓰레기통과 공존**: 상단 쓰레기통 영역은 기존대로 삭제, 그리드 내 드롭은 자리이동
- **성능**: 자재 수가 많지 않으므로 (일반적으로 10~30개) 전체 순서 업데이트 OK
- **외부 라이브러리 불필요**: 기존 드래그 인프라를 확장하므로 추가 의존성 없음
