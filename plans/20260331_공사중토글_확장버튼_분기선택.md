# 공사중토글 확장 버튼 — 분기별 선택 활성화

## 배경

### 현재 동작
- 플로팅 "공사중토글" 버튼 클릭 → 단순 ON/OFF
- ON이면 프로젝트 카드의 모든 분기(1Q~4Q, 준공) 편집 가능
- OFF이면 모든 분기 편집 불가
- `editableQuarter`(단수)로 현재 날짜 기준 분기만 편집 가능 제한 (`currentQuarterKey`)

### 문제점
- 담당자가 원하는 분기만 골라서 활성화할 수 없음
- 전체 ON/OFF만 가능하여, 불필요한 분기까지 편집 가능 상태가 됨
- 날짜 기반 자동 제한(`currentQuarterKey`)으로 유연성 부족

## 목표

공사중토글 버튼을 클릭하면 **버튼이 확장**되어 1분기, 2분기, 3분기, 4분기, 준공을 **개별 선택**할 수 있는 UI 제공.
기존 `currentQuarterKey` 기반 날짜 자동 제한을 **사용자 선택 방식으로 대체**.

## UI 설계

### 상태 1: 접힌 상태 (기본)
```
[📅 공사중토글]          ← 현재와 동일한 플로팅 버튼
```

### 상태 2: 펼친 상태 (버튼 클릭 후)
```
┌─────────────────────────────────────┐
│  1분기   2분기   3분기   4분기   준공  │  ← 분기 선택 버튼들
├─────────────────────────────────────┤
│           [✕ 닫기]                   │  ← 접기 버튼
└─────────────────────────────────────┘
```

### 상태 3: 분기 선택됨
```
┌─────────────────────────────────────┐
│ [1분기]  2분기   3분기   4분기   준공  │  ← 1분기가 초록색(활성)
├─────────────────────────────────────┤
│           [✕ 닫기]                   │
└─────────────────────────────────────┘
```
- 활성화된 분기: 초록색 배경 + 흰 글씨
- 비활성화된 분기: 회색 배경 + 어두운 글씨
- 여러 분기 동시 선택 가능 (토글 방식)

### 동작 흐름
```
[공사중토글 클릭]
  ├─ 패널 펼침 (isQuarterPanelOpen = true)
  ├─ 현재 활성화된 분기 표시 (quartersToggleMap에서 조회)
  │
  ├─ [1분기 클릭] → 해당 분기 토글 (ON↔OFF)
  │     ├─ 서버 저장 (updateQuartersToggleSetting)
  │     ├─ 로컬 상태 업데이트
  │     └─ 프로젝트 카드의 해당 분기만 편집 가능/불가 반영
  │
  ├─ [닫기 클릭] → 패널 접기
  │
  └─ OFF→ON 전환 시 (어떤 분기든 처음 활성화할 때)
        └─ TBM 주소 일괄 반영 (기존 구현 유지)
```

### DB 테이블 변경 (ui_settings)

**현재 테이블 스키마:**
| 컬럼명 | 타입 | 설명 |
|--------|------|------|
| `id` | uuid | PK (gen_random_uuid()) |
| `hq_division` | text | 본부명 (UNIQUE) |
| `show_quarters_toggle` | boolean | 전체 ON/OFF (기본값: true) |
| `created_at` | timestamptz | 생성일시 |
| `updated_at` | timestamptz | 수정일시 |

**변경 방안:** `show_quarters_toggle` (boolean) → `quarters_toggle_state` (jsonb) 컬럼 추가

```sql
-- 마이그레이션: quarters_toggle_state jsonb 컬럼 추가
ALTER TABLE ui_settings
  ADD COLUMN quarters_toggle_state jsonb
    DEFAULT '{"q1": false, "q2": false, "q3": false, "q4": false, "completed": false}'::jsonb;

-- 기존 boolean 데이터 마이그레이션
UPDATE ui_settings
SET quarters_toggle_state = CASE
  WHEN show_quarters_toggle = true
    THEN '{"q1": true, "q2": true, "q3": true, "q4": true, "completed": true}'::jsonb
  ELSE '{"q1": false, "q2": false, "q3": false, "q4": false, "completed": false}'::jsonb
END;

-- 이후 show_quarters_toggle 컬럼은 유지 (하위호환) 또는 제거
```

```typescript
export type QuarterToggleState = {
  q1: boolean
  q2: boolean
  q3: boolean
  q4: boolean
  completed: boolean
}

// UISettings 인터페이스 확장
export interface UISettings {
  id: string
  hq_division: string
  show_quarters_toggle: boolean           // 기존 (하위호환)
  quarters_toggle_state: QuarterToggleState | null  // 신규
  created_at: string
  updated_at: string
}

// getQuartersToggleMap 반환 타입 변경
// Map<string, boolean> → Map<string, QuarterToggleState>
export async function getQuartersToggleMap(): Promise<Map<string, QuarterToggleState>> {
  const settings = await getAllUISettings()
  const map = new Map<string, QuarterToggleState>()
  const defaultOff: QuarterToggleState = { q1: false, q2: false, q3: false, q4: false, completed: false }
  const defaultOn: QuarterToggleState = { q1: true, q2: true, q3: true, q4: true, completed: true }

  settings.forEach(setting => {
    if (setting.quarters_toggle_state) {
      map.set(setting.hq_division, setting.quarters_toggle_state)
    } else {
      // 하위 호환: 기존 boolean 값을 QuarterToggleState로 변환
      map.set(setting.hq_division, setting.show_quarters_toggle ? defaultOn : defaultOff)
    }
  })
  return map
}

// updateQuartersToggleSetting 시그니처 변경
// (hqDivision: string, showQuartersToggle: boolean)
// → (hqDivision: string, state: QuarterToggleState)
export async function updateQuartersToggleSetting(
  hqDivision: string,
  state: QuarterToggleState
): Promise<{ success: boolean; error?: string }>
```

```typescript
// 변경 전 (라인 1497-): 단순 ON/OFF 토글 + TBM 주소 반영
const handleQuartersToggleClick = async () => { ... }

// 변경 후: 패널 열기/닫기
const handleQuartersToggleClick = () => {
  setIsQuarterPanelOpen(prev => !prev)
}

// 신규: 개별 분기 토글 핸들러
const handleQuarterSelect = async (quarter: keyof QuarterToggleState) => {
  if (!userProfile?.hq_division) return
  const currentHq = userProfile.hq_division
  const currentState = quartersToggleMap.get(currentHq) ||
    { q1: false, q2: false, q3: false, q4: false, completed: false }

  const wasAllOff = Object.values(currentState).every(v => !v)
  const newState = { ...currentState, [quarter]: !currentState[quarter] }
  const isNowSomeOn = Object.values(newState).some(v => v)

  // 옵티미스틱 업데이트
  setQuartersToggleMap(prev => {
    const newMap = new Map(prev)
    newMap.set(currentHq, newState)
    return newMap
  })

  try {
    const result = await updateQuartersToggleSetting(currentHq, newState)
    if (!result.success) {
      // 롤백
      setQuartersToggleMap(prev => {
        const newMap = new Map(prev)
        newMap.set(currentHq, currentState)
        return newMap
      })
      return
    }

    // 모든 분기 OFF → 하나라도 ON 전환 시: TBM 주소 일괄 반영
    if (wasAllOff && isNowSomeOn) {
      // 기존 TBM 주소 반영 로직 유지
      await bulkUpdateActualWorkAddress(currentHq)
    }
  } catch (error) {
    // 롤백
    setQuartersToggleMap(prev => {
      const newMap = new Map(prev)
      newMap.set(currentHq, currentState)
      return newMap
    })
  }
}
```
