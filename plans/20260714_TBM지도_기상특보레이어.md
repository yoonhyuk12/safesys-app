# TBM 지도 기상특보 레이어

## 목표

`/map`의 TBM 지도에 기상청 현재 특보를 행정구역 폴리곤과 라벨로 표시한다. 첨부 예시처럼 발효 지역을 반투명하게 채우고 `연천 호우` 형태의 라벨을 제공한다.

## 범위

1. 서버 전용 API 라우트에서 기상청 특보현황을 조회하고 키를 클라이언트에 노출하지 않는다.
2. 공개 ArcGIS 행정구역 경계를 조회해 특보구역명과 시·도/시·군·구 경계를 매칭한다.
3. 카카오 지도에 특보 폴리곤, 지역 라벨, 상세 툴팁을 표시한다.
4. 데스크톱 지도 좌측 상단과 모바일 범례에 `기상특보` 드롭다운을 두고 전체 표시와 특보 종류별 복수 선택, 로딩·오류 상태를 제공한다.
5. 해상특보는 지도 목적과 맞지 않아 제외하고 육상특보만 표시한다.
6. 프로젝트 상세의 안전 캐비넷에는 해당 사업 주소에 발효 중인 특보를 작은 스티커로 표시한다.

## 구현 원칙

- 기상청 데이터는 5분, 행정경계는 24시간 캐시한다.
- 행정안전부 원천의 2026년 7월 공개 경계는 서버에서 필요한 지역만 추리고 좌표를 단순화해 응답 크기를 줄인다.
- 동일 지역에 특보가 여러 개면 한 폴리곤에 묶고 라벨에는 특보명을 함께 표시한다.
- 경보를 주의보보다 높은 우선순위로 표현하고, 현상별 색상을 사용한다.
- 세분 특보구역을 직접 표현할 경계가 없으면 상위 시·군 경계로 대체하며 응답에 대체 여부를 남긴다.
- 특보 선택은 기존 프로젝트·TBM 마커 기준 지도 중심과 확대 수준을 바꾸지 않으며 특보 오버레이는 마커보다 뒤에 표시한다.
- 캐비넷 스티커 조회는 주소의 유일한 행정구역을 우선하고, 모호하면 저장된 좌표를 ArcGIS 행정경계에 1점 공간질의해 판정한다.
- 위치 조회 응답에는 지도 형상을 포함하지 않고 지역명·특보·표시 색상만 반환한다.

## 검증 기준

- 유효한 `KMA` 키로 `/api/weather/warnings`가 육상 특보와 GeoJSON 형상을 반환한다.
- `/map`에서 기상특보 토글을 켜면 폴리곤과 라벨이 표시되고 끄면 모두 제거된다.
- 지도 이동·확대와 기존 프로젝트/TBM 마커 동작이 유지된다.
- `npm run lint`와 `npx tsc --noEmit`이 통과한다.
- 개발 서버에서 콘솔 오류 없이 지도 화면을 직접 확인한다.
- 프로젝트 상세의 안전 캐비넷 오른쪽 문에서 현재 위치 특보가 자간을 확보한 세로형 LED 전광판으로 표시되고, 글자 밝기가 은은하게 점멸하며 무특보·조회 실패 시 숨겨진다.
