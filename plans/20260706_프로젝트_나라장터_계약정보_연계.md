# 프로젝트 — 나라장터 계약정보 연계 (계약번호·공고번호 자동입력)

## 배경

SafeSys 프로젝트 등록·수정 시 공사명, 총사업비, 공사기간 등을 전부 수기로 입력한다. 한국농어촌공사 등 발주기관의 공사는 나라장터에서 계약이 체결되므로, 조달청 오픈API로 계약번호(확정계약번호) 또는 공고번호 하나만 입력하면 프로젝트 기본 정보를 자동으로 채우고 나라장터 계약과 프로젝트를 연계할 수 있다.

## API 검증 결과 (2026-07-06 Swagger 확정)

- 서비스: 조달청_나라장터 계약정보서비스 (data.go.kr 15129427)
- 엔드포인트: `https://apis.data.go.kr/1230000/ao/CntrctInfoService`
- 핵심 오퍼레이션: `getCntrctInfoListCnstwkPPSSrch` (공사 계약현황, 나라장터 검색조건)
  - 검색 파라미터: `ntceNo`(공고번호), `dcsnCntrctNo`(확정계약번호), `cntrctRefNo`(계약참조번호), `insttNm`(기관명), `cnstwkNm`(공사명) 등
- 응답 필드(주요): `cnstwkNm`(공사명), `totCntrctAmt`(총계약금액), `cntrctPrd`(계약기간), `cbgnDate`(착공일자), `ttalCcmpltDate`(총준공일자), `cntrctInsttNm`(계약기관명), `dminsttList`(수요기관목록), `corpList`(업체목록), `ntceNo`, `dcsnCntrctNo`, `untyCntrctNo`, `cntrctInfoUrl`
- **미확정**: `inqryDiv`(조회구분)의 번호별 값 — 실호출로 확인 필요 (유사 서비스 관례: 1=일자, 2=번호 조회)
- 인증키: 기존 `DATA_GO_KR_API_KEY` 그대로 사용. 단, **data.go.kr에서 "조달청_나라장터 계약정보서비스" 활용신청 필요** (자동승인) — 사용자 액션

## 필드 매핑

| 나라장터 응답 | SafeSys projects |
| --- | --- |
| cnstwkNm | project_name |
| totCntrctAmt | total_budget |
| cbgnDate | construction_start_date |
| ttalCcmpltDate | construction_end_date |
| dcsnCntrctNo / ntceNo | g2b_cntrct_no / g2b_ntce_no (신규 컬럼, 연계 유지용) |
| corpList·dminsttList·cntrctInsttNm | 미리보기 표시용 (저장 안 함) |

## 범위 (이번 작업)

1. **DB 마이그레이션** `database/20260706-0926_add_g2b_contract_link_to_projects.sql`
   - `projects.g2b_cntrct_no TEXT`, `projects.g2b_ntce_no TEXT` (nullable)
   - Supabase MCP는 읽기전용이므로 웹 콘솔에서 적용 — 사용자 액션
2. **API 라우트** `src/app/api/g2b/contract/route.ts`
   - GET `?no={번호}` → `dcsnCntrctNo`로 조회, 0건이면 `ntceNo`로 재조회
   - 여러 건(차수·공동수급 등)이면 목록 전체를 정규화해 반환, 프론트에서 선택
   - 키는 서버 전용, 응답 포맷 `{ success, data, error }`
3. **공용 조회 컴포넌트** `src/components/project/G2bContractLookup.tsx`
   - 번호 입력 → 조회 → 계약 미리보기(공사명·금액·기간·기관·업체) → "적용" 버튼
   - 적용 시 부모 폼 콜백으로 매핑 필드 전달 (기존 입력값이 있으면 덮어쓰기 전 확인)
4. **폼 연결**: ProjectRegistrationForm, ProjectEditForm에 컴포넌트 삽입 + 저장 페이로드에 g2b 컬럼 포함, `Project` 타입에 필드 추가

## 범위 밖 (후속 단계)

- 계약변경이력(`getCntrctInfoListCnstwkChgHstry`) 감지로 금액·기간 자동 갱신
- 공고번호 기반 입찰공고정보(기초금액 등) 연계
- 농산어촌지역개발사업 API(사업지구·좌표) 연계

## 검증 방법

- `npm run lint` 통과
- 활용신청 승인 후 실제 계약번호·공고번호로 조회 → 미리보기 → 적용 → 프로젝트 저장 → DB 컬럼 확인
- 잘못된 번호·미존재 번호·키 미승인(401) 오류 메시지 확인
