# 특별점검770 점검결과 탭

점검개요 → 굴착기 점검표 → 점검결과의 세 단계로 구성한다. 마지막 단계는 HWPX의 2. 점검결과에 대응하며 실제 굴착기 수와 부적정 항목만 표시한다.

1. 대상 파일을 저장소 외부에 백업하고 UI·상태 회귀 테스트를 먼저 작성해 실패를 확인한다.
2. 기존 inspectionFindings, updateItem, Special770PhotoSlot을 재사용하여 지적사항·조치 전 사진·조치예정일 입력과 지적 없는 현장사진을 결과 탭으로 이동한다. 조치사항과 조치 후 사진은 입력 UI에서 제외하며 기존 저장값은 보존한다.
3. 편집 및 읽기 전용의 세 단계 탐색을 연결하고 도메인 테스트를 실행한다.

저장 스키마, HWPX, DB, 저장소 로직은 변경하지 않는다. 안전핀 증빙과 기타 위험요인 정의는 점검표에 남긴다. 판정 변경 시 기존 상세 값은 보존한다. 외부 의존성은 필요하지 않으며 기존 구현을 재사용한다. 브라우저·린트·타입 점검은 코디네이터가 수행한다. 빌드·커밋·푸시는 실행하지 않는다.

## 굴착기 선택 탭 변경.

굴착기 번호를 44px 탭으로 표시하고 선택한 카드 한 개만 렌더한다. 선택은 배열 위치가 아닌 ID로 유지하며 최초/삭제 후 첫 유효 항목, 추가 직후 새 항목을 선택한다. 기존 카드와 부모 데이터를 재사용하고 방향키·Home·End 및 ARIA 연결을 검증한다.

## 탭 행의 삭제·추가 버튼 정정.

각 탭 제목 바로 오른쪽에 X 삭제 버튼, 같은 행 끝에 아이콘만 있는 + 버튼을 둔다. 기존 확인문을 유지하며 비활성 삭제는 선택 ID를 보존하고 활성 삭제는 남은 첫 항목으로 전환한다. 마지막 삭제 후 빈 상태와 +를 유지한다. Card의 중복 삭제와 하단 추가를 제거하고 closest tablist 기반 키보드 탐색, 읽기 전용·ARIA·44px 크기를 회귀 검증한다. 이번 수정은 작업자가 테스트·린트·타입 검사를 수행하며 브라우저·빌드·커밋·푸시·위임을 하지 않는다.
