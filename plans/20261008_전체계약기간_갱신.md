# 전체계약기간 갱신 오류 수정

## 목적
프로젝트 상세의 나라장터 갱신이 연차 착공일로 전체 계약기간을 축소하지 않도록 한다.

## 계획
1. 기존 `g2b-contract-period.ts`, 계약 조회 API와 상세 갱신 경로를 재사용해 원인을 확인한다.
2. 공고번호 누락·보조 조회 실패에서도 전체 기간을 보존하고, 확인 가능한 최초 착공일과 총 준공일을 반영한다.
3. 기존 나라장터 테스트에 재현 사례를 추가하고 린트·타입 점검·관련 테스트 및 diff를 검증한다.

## 범위와 제약
외부 라이브러리 신규 도입 없이 기존 계약 조회 흐름을 수정한다. 금액·업체 갱신은 유지한다. 사용자 작업 중인 `SignUpForm.tsx`와 `log.md`는 수정하거나 커밋하지 않는다. 빌드·푸시는 수행하지 않는다.
