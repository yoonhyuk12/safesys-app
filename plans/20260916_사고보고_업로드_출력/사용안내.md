# 사고보고 사용 안내

1. 프로젝트 안전캐비넷의 A(조치)에서 **사고보고**를 열고 **사고 등록**을 누른다.
2. 직접 작성하거나 **PDF·HWPX 업로드로 초안 채우기**를 누른다. PDF는 4MB, HWPX는 15MB까지 지원한다.
3. 문서에서 읽은 내용을 확인하고 빠진 항목을 보완한다. 기존 입력과 충돌하면 **빈 칸만 채우기** 또는 **문서 내용으로 덮어쓰기**를 선택한다.
4. PDF 업로드 시 앞 8쪽의 삽입 사진 후보를 표시 순서대로 최대 2장 자동으로 채운다. 사진대지에서 확인하고 설명을 적으며, 필요하면 삭제 후 다른 사진을 첨부한다. 기존 사진과 업로드 처리 중 변경·삭제한 목록은 보존한다. 작은 로고·패턴·마스크와 스캔한 전체 쪽은 제외하며, 12MP를 넘는 그림이나 15초 처리 제한 등으로 추출하지 못한 사진과 HWPX 사진은 직접 첨부한다. 추출 사진은 최대 긴 변 1200px JPEG로 정규화하고, 사진 추출에 실패해도 성공한 본문 초안은 유지한다. 업로드만으로 저장하지 않는다.
5. 저장하면 해당 프로젝트 사고보고 목록과 안전대시보드 사고현황에 같은 사고가 반영된다.
6. 보고서 상세 화면의 **한글 다운로드**로 평택지사 사고보고 원본 양식에 본문과 첨부 사진을 채운 편집 가능한 HWPX를 받는다.

보고자 성명·직책·연락처, 보고일, 사고 시각, 피해자 인적사항, 인명·재산 피해, 책임 소재, 신고처, 미신고 사유, 피해자 조치, 보상·처리 내용, 기타 사항, 관계자 연락처를 추가로 기록할 수 있다. 사고일과 보고일은 별도 항목이다.

**산재요양 예상 일수**는 사고 시각·피해 영역에서 일 단위의 0 이상 정수로 입력한다. 미정이면 비워 두며 빈값은 0일로 바뀌지 않는다. 휴업일수와 별도 항목이고, 자동 채움은 문서에 요양기간이 일 단위로 명시된 경우만 옮긴다. 진단 주수나 휴업일수에서 계산하지 않는다. 상세화면에는 일 단위로, 한글 보고서에는 피해자 인적사항 다음에 `산재요양 예상 N일`로 표시된다.

작성·수정은 해당 프로젝트 접근 권한이 있는 소유자·공유자·관할 발주청이 할 수 있다. 삭제는 기존 작성자 또는 관할 본부급 이상 권한을 따른다.

운영 사용 전 [SQL 적용 안내](SQL적용안내.md)의 파일을 순서대로 적용하고 앱을 배포해야 한다.
