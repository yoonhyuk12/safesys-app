# 공사 계약 현황 카드 (/business 사업현황 그리드)

## 목표

/business 사업현황 카드 그리드에 "공사 계약 현황" 카드를 추가한다. 클릭 시 본부별 → 지사별 → 사업별(프로젝트) 3단 드릴다운 테이블을 보여준다. 컬럼은 건수 · 총계약건 · 금년계약건 · 비고.

## 컬럼 의미 (장기계속계약 차수 특성 반영)

- **건수** — 공사 건수. `contract_type='공사'` 계약을 차수 병합 키(`nameGroupKey` 규칙)로 묶은 그룹 수.
- **총계약건** — 차수를 포함한 전체 계약 체결 건수 (`project_contracts` 행 수, 공사만).
- **금년계약건** — 그중 금년(현재 연도) 귀속 건수. 귀속 연도는 contract-status 페이지의 `contractYear()` 로직과 동일 (총액≠금차이고 `thtm_end_date` 있으면 금차 준공 연도, 아니면 계약체결일 연도).
- **비고** — 공란(-).

## 구현 설계

1. **새 컴포넌트** `safesys-app/src/components/dashboard/BusinessConstructionContractView.tsx`
   - `BusinessDisasterPreventionView.tsx`를 원형으로 복제·개조. 단, 드릴다운을 2단(지사→사업)에서 3단(본부→지사→사업)으로 확장 (`viewLevel: 'hq' | 'branch' | 'project'`).
   - fetch — `project_contracts` + `projects!project_id!inner(...)` FK 힌트, `contract_type='공사'`만, 재해예방 뷰와 동일한 역할/관할 필터.
   - 정렬 — 본부(`Object.keys(BRANCH_OPTIONS)` 순) → 지사(`BRANCH_OPTIONS[hq]` 순) → `display_order` → 사업명. Map 삽입 순서 = 표 순서 패턴 유지.
   - 각 표 상단 소계 행. 행 클릭으로 드릴다운, 사업 행 클릭 시 `/project/{id}/contract-status`로 이동(returnUrl로 복귀 상태 유지).
2. **Dashboard.tsx** — `selectedBusinessCard === 'construction'` 분기 + 재해예방 카드 뒤에 새 카드 추가. `?card=construction&hq=…&branch=…` URL 복원 지원.

## 컨텍스트 노트

- 카드 그리드는 라우팅이 아니라 `Dashboard.tsx` 내부 state(`selectedBusinessCard`) 뷰 전환 패턴 — 기존 패턴 유지가 요구사항.
- 지사 표 순서는 표 렌더가 아닌 detailRows 정렬(BRANCH_OPTIONS 순)에서 제어 — 커밋 7187439 패턴.
- 사용자가 지정한 컬럼명 "총계약건/금년계약건"은 금액이 아닌 건수로 해석 — 차수(별개 계약) 개념이 있어 건수 구분이 자연스럽고 문자 그대로의 해석이기도 함.
- 엑셀 다운로드는 요청에 없어 이번 범위에서 제외.
- 프로젝트(사업) 행에서도 동일 컬럼 유지 — 건수는 대개 1이지만 일관성 우선.
