# 기상특보 JSON 응답 호환 수정

## 문제와 목표

`/map`의 기상특보 API가 HTTP 200 JSON 배열을 CSV로 파싱하여 502를 반환한다. JSON과 기존 CSV를 공통 특보 모델로 변환하고, 해상만 존재하거나 정상 빈 JSON 배열인 경우 육상 특보 0건을 반환한다. 오류 응답은 계속 실패로 처리한다.

## 구현과 검증

1. 실제 응답 구조를 반영한 파서·라우트 회귀 테스트를 먼저 작성하고 실패를 확인한다.
2. `src/lib/weather-warnings.ts`에 JSON 필드 정규화를 추가하고 기존 육상 필터·중복 병합을 재사용한다. `api/weather/warnings/route.ts`는 유효한 빈 배열과 오류 응답을 구분한다.
3. JSON·CSV·해상 전용·빈 배열·깨진 응답·필드 공백·특보 수준·해제 및 중복 사례를 검증한다.
4. 린트·타입체크·테스트, 로컬 GET/POST 및 지정된 `/map` 브라우저 확인 후 원자적 커밋을 만든다. 운영 푸시와 프로덕션 빌드는 이번 범위에 없다.

## 범위와 위험

UI·인증키·경계 서비스는 변경하지 않는다. 잘못된 upstream 데이터를 정상 0건으로 오인하지 않는 것이 핵심이다. 새 의존성 없이 기존 파서와 Node 테스트를 재사용한다.
