# 정기점검 지적사항 연동

770의 기존 inspectionFindings를 재사용하여 부적정 항목만 관리대장과 카드에 연결한다. 굴착기 id와 항목코드로 원본을 찾아 조치 내용·사진을 갱신하고 최신 JSON의 다른 필드를 보존한다.

1. 기존 집계·Storage·조치 구조 조사 및 회귀테스트 실패 확인.
2. 관리대장 변환과 최신 JSON write-back 구현, 카드 집계 및 다운로드 연결.
3. 관련 테스트·린트·타입 검사와 diff 직접 리뷰. 실제 데이터 및 브라우저 검증은 Advisor가 수행한다.

770 행은 조치 해당없음 버튼을 숨기고 원본의 완료 판정 규칙을 유지한다. 기존 N/A도 미조치로 표시한다. 빌드·커밋·푸시는 실행하지 않는다.
