# 굴착 작업계획서(5번째 서식) 추가 계획

작성 2026-07-18. 표준 양식: `[2021-교육혁신실-835] 굴착 작업계획서 샘플(예시).pdf` (42쪽).
분석 보고서: `safesys-app/scratch/excavation-plan-analysis.md` (Codex 워커 산출, 코디네이터가 p.1~2·9·16 원문 스팟체크로 검증).

## 목표

42쪽짜리 굴착 작업계획서 표준 양식을 작업계획서 마법사의 5번째 서식(`excavation`)으로 추가한다. 소규모 현장 소장이 작성할 수 있도록, 법정 문구·안전수칙·표준 절차는 전부 기본값(상수)으로 내장하고 **사용자는 현장 고유 정보만 입력**한다. 위치도·작업계획도는 기존 지도 드로잉 에디터를 재사용한다.

## 설계 원칙

1. 기존 4종과 동일한 플러그인 패턴 — 새 아키텍처를 만들지 않는다.
2. 사용자 실입력 최소화. 42쪽 → 단일값 20여 개 + 반복표 + 조건부 섹션 3종(발파·흙막이·계측, 기본 꺼짐).
3. 보일러플레이트는 분석 보고서의 원문 발췌를 기초로 상수화하되, HWP 변환 오탈자(예: "친공위치"→"천공위치", "발생먹제"→"발생억제")는 교정한다. 의미 변경 금지.
4. 7단계 마법사에 그대로 편입한다.

## 코디네이터 결정 사항 (분석 보고서 5.6의 8건)

1. **결재란**: 원문 4단(작성자·검토자1·검토자2·현장소장) 재현. `WorkPlanSignatureRole`에 `approvalReviewer1`·`approvalReviewer2` 추가. 작성자→`approvalManager`, 현장소장→`approvalApprover`. 서명은 전부 선택(공란이면 출력 후 수기 결재).
2. **지도 드로잉**: 기존과 동일하게 1장(운행·작업 배치도 — 경로·장비·신호수·지휘자·통제구역 겹쳐 표시). 전문 도면(굴착 평면·단면, 흙막이 구조도, 계측도 등)은 v1에서 구조화하지 않고 생략 — 필요 시 추후 첨부 기능 확장.
3. **이미지 페이지 문구**: 원본 HWP 재추출 생략. 보고서 화상 판독(4.8) 기반으로 오탈자 교정해 SafeSys 기본 문구로 수록.
4. **운행속도 20km 등 수치**: 편집 가능한 기본값(잠그지 않음).
5. **계측 관리치**: 전용 승인 필드 없음. 반복행+비고로 두고 "구조기술자 승인값 기재" 안내 문구만 표시.
6. **지반조사(p.5~8)**: 구조화 재현 안 함. 기존 `CONSTRUCTION_SURVEY_ITEMS.excavation` 5항목 finding으로 간소화.
7. **사전조사 상수**: 건설기계 서식과 공용 유지(이동하지 않음).
8. **법정 기준 최신성**: 사용자 제시 2021 양식 기준으로 구현. 개정 시 상수만 교체.

## 필드 설계 (확정)

`ExcavationWorkPlanFormData extends CommonWorkPlanFields` (title·기간·업체·작업자·지휘자·운전원·유도자·작업내용·riskControls·signatures 재사용).

| 블록 | 내용 | 분류 |
|------|------|------|
| `overview` | 현장 전화번호·공사규모·협력업체(명·전화)·작업담당자(PersonContact)·굴착 기간·깊이·면적·물량·굴착방법·사용장비 요약 | C (기간은 공사기간 자동 인입 후 수정) |
| `utilities` | 매설물 반복행(종류·확인결과·조치·담당기관), 기본 4행(도시가스·상수도·전기·통신) + '해당없음' 퀵 선택 | C |
| `surveyEntries` | 굴착 사전조사 5항목 결과 (`ConstructionSurveyEntry` 재사용) | C |
| `equipmentRows` / `manpowerRows` | p.9 장비·인원 반복행(항목·규격·수량·용도·기간·비고) | C |
| `drainagePlan` | 배수방법 텍스트 1개 (양수량 계산표는 채택 안 함 — 소규모 현장 과부담) | C |
| `blasting` | 적용 토글(기본 꺼짐) + 공법·구역·발파량·화약관리자·통제방법 | C 조건부 |
| `shoring` | 적용 토글(기본 꺼짐) + 흙막이공법·수량·지보공법·수량 + 재료 반복행 | C 조건부 |
| `instrumentation` | 적용 토글(기본 꺼짐) + 계측기 반복행(항목·위치·수량·시기·빈도·비고) | C 조건부 |
| `emergencyContacts` | 기관 프리셋(B) + 전화번호(C) 반복행 | B+C |
| `checklist` | `EXCAVATION_CHECKLIST` 신규(~15항목, p.16·35·40~42 기반) | B |
| 표준 절차·안전수칙·경보표 | 전부 상수(B) — 입력 없음, PDF에 자동 수록 | B |
