# 장비 점검 안내 이미지

- 요청. 원본 PDF의 장비 안내 사진·도해를 작성/상세 점검표 상단과 HWPX 출력에 표시한다.
- 자산. 추출한 21종 장비의 이미지 22개를 public 정적 자산으로 보관하고 장비 ID로 연결한다. 준설선·쇄석기는 이미지가 없다.
- 화면. 기존 공통 디자인으로 원본 비율을 유지해 기본정보 아래·점검 항목 위에 표시한다. 덤프트럭의 이미지 2개도 모두 표시한다.
- 출력. HWPX 첫 페이지의 점검 항목 위에 이미지를 포함한다. 이미지 높이를 페이지 예산에 반영하여 기존 글꼴·서명 겹침·세로 가운데 정렬·균등 점검행·종합 비고 최소 높이·A4 본문 채움을 유지한다.
- 검증. 정적 자산 매핑, 브라우저 작성/상세, 다운로드, 23종과 장문 표본의 HWPX XML 및 실제 한글 열기·PDF 전체 페이지 확인을 수행한다.
- SQL 변경은 필요하지 않다. 빌드·푸시하지 않고 검증 뒤 커밋한다.
