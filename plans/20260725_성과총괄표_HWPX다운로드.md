# 품질검사 성과 총괄표 HWPX 다운로드

## 목표

성과총괄표 목록/폼의 다운로드를 엑셀뿐 아니라 한글문서(`.hwpx`)로도 받을 수 있게 한다.

## 배경

- 대상 UI. `QualitySummaryTab` 목록 행의 녹색 다운로드 버튼(현재 엑셀 전용) 및 폼 하단 엑셀 버튼.
- 정본 양식. 별지 2호 — 기존 `quality-summary-export.ts` 엑셀 레이아웃과 동일 구조.
- 구현 방식. 코드 조립(OWPML). 로컬 템플릿 없음(헤더의 "HWP 양식"은 구글 드라이브 빈 양식 링크).
- 정본 참고. `safesys-app/src/lib/hwpx/tbm-submission-hwpx-export.ts` 헬퍼 복사·일반화.

## 범위

1. `safesys-app/src/lib/hwpx/quality-summary-hwpx-export.ts` 신규
2. `QualitySummaryTab.tsx` — 엑셀 유지 + HWPX 추가

## 비범위

- 실시대장·확인시험 의뢰서 HWPX
- 빈 양식 로컬 템플릿 교체
- 엑셀 레이아웃 변경

## 설계 요약

- 레이아웃. 엑셀과 동일 섹션 순서(별지 태그 → 제목 → 공사명/기간 → 기성표 → 품질실적 → 확인시험 → 작성일시 → 작성/검토/확인자 → 기입요령).
- 서명. `ImageCollector` raw PNG + `buildFloatingPicXml`로 `(인)` 문구 위에 겹침(핵심 제약 #5).
- UI. 목록 행·폼 하단에 엑셀/HWPX 각각 버튼(또는 format 인자). 파일명 `품질검사성과총괄표_${date}.hwpx`.

## 완료 기준

- tsc·lint 통과
- 로컬 HWP 있으면 크래시 테스트 ALIVE
- 서명 있으면 `(인)` 위 겹침, 성명·직책 비가림
