# 산재 신청 건 분석 필터.

사용자가 선택한 기존 산재 신청 상태 `applied`를 대상으로 사고 분석 화면에 기본 해제 체크박스를 추가한다. 화면 라벨은 `산재승인건`, 설명은 `신청 건 기준`으로 표시한다.

- 기존 `filteredAccidents`의 유형·중대도·조직·프로젝트 조건에 AND 조건을 추가한다.
- KPI·상세·유형 순위·월별 차트는 기존 공통 사고 데이터 흐름을 유지한다.
- 점검수와 상시근로자 분모, 기간 처리, DB/API는 변경하지 않는다.
- 초기화 시 체크 해제하며 8개 필터를 작은 화면 1열, 중간 2열, 큰 화면 4열로 정렬한다.
- 기존 Node 테스트와 TypeScript를 재사용하여 실제 필터 콜백의 동작을 검증하고 변경 파일 린트·타입 검사를 실행한다.

추가 의존성·빌드·커밋·푸시 없이 부모가 diff와 브라우저 검증을 마무리한다.
