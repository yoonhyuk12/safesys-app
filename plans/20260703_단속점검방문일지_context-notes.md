# 단속·점검방문 일지 — 컨텍스트 노트

작업 중 내린 결정과 근거를 기록한다. (2026-07-03)

## 요청 배경

- 사용자 요청: "시공캐비넷에 서류 하나 추가" + PDF 원본 (`단속방문점검 일지.pdf` — 건설기술 진흥법 시행규칙 제48조, 별지 제9호 서식).
- 자율 진행 세션 — 세부 결정은 기존 관례를 따르고 여기 기록한다.

## 결정 사항

1. **참조 구현체**: 시공 캐비넷의 검사/검측 대장(`inspection-request`)과 품질시험 결과 관리대장(`quality-test-ledger`, 2026-07-02) 패턴을 그대로 따름. 새 패턴 발명 없음.
2. **PDCA 분류 — C(점검)**: 외부 기관의 단속·점검 방문 기록이므로 Check. 검사/검측 대장과 같은 그룹에 배치.
3. **방문자는 JSONB 배열**: 서식은 ㉠㉡㉢ 3칸이지만 "3명 초과 시 별지" 규정이 있어 고정 컬럼 대신 배열로 유연하게. 엑셀 출력은 서식대로 3칸 + 초과분 별도 처리.
4. **⑦ 확인 서명 → supervisor.targets 등록**: 서식상 확인자는 "공사감독원(책임건설사업관리기술자) 또는 현장 배치 건설기술자"로 양쪽 다 가능하지만, 이 시스템의 주 사용 시나리오(발주청 감독 확인)에 맞춰 감독 일괄서명 대상으로 등록. ⑥ 방문자 서명은 이름 특정 개인 서명이라 일괄서명 제외 (CLAUDE.md 규칙).
5. **① 공사 정보는 스냅샷 저장**: 공사명·현장위치·발주기관·공사규모를 레코드 TEXT 컬럼으로 저장하고 프로젝트 정보로 프리필. 문서가 법정 서식이라 작성 시점 값 보존이 맞음.
6. **출력은 Excel**: 표 중심 단건 서식 — 확인시험 의뢰서(1건 1시트)와 동일 패턴. html2canvas 텍스트 버그 회피 측면에서도 유리.
7. **프리필 범위**: 공사명(프로젝트명)·현장위치(site_address + site_address_detail)·확인자 성명(supervisor_name)만. 발주기관은 프로젝트 데이터에 대응 필드가 없어 수동 입력 (기관명 하드코딩 지양 — coding-style 규칙).
8. **엑셀 방문자 초과분**: 서식 규정은 "3명 초과 시 별지"지만 별도 시트 대신 같은 표에 행을 이어서 출력 (㉣㉤… 마크). 실무 편의 우선, 폼에 안내 문구로 규정을 표기.

## 구현 후 검증 메모

1. **제어문자 스캔**: 신규 파일 6개 전부 NUL(0x00) 등 제어문자 0건 (이전 세션의 Write 도구 사고 재발 방지 체크).
2. **타입·린트**: `npx tsc --noEmit` 신규 파일 오류 0건. ESLint `no-explicit-any` 4건은 `(supabase as any)` 패턴 — 참조 구현체(inspection-request/page.tsx)도 정확히 동일한 4건으로, 프로젝트가 수용 중인 관례라 그대로 둠.
3. **마이그레이션 미적용**: supabase-safesys MCP는 읽기 전용 (CLAUDE.md 문서화된 제약, 2026-07-02 세션에서 재확인됨). `database/add_inspection_visit_logs.sql`을 사용자가 Supabase SQL Editor에서 직접 실행해야 기능이 동작한다. 테이블 없어도 페이지·캐비넷은 안전 (count 조회 에러 시 건수 미표시, 목록 빈 상태, 저장 시 에러 알림).
4. **일괄서명 안내 문구**: ⑥ 방문자 서명 제외는 기존 supervisor note의 "점검자·감시인 등 개인 지정 서명은 각 문서에서 개별 서명해주세요" 문구가 포괄하므로 문구 수정 없음.
5. **프로덕션 빌드 미실행**: CLAUDE.md 규칙(동의 없이 빌드 금지) — 타입 검사로 대체.

## 페이지 피드백 반영 (2026-07-03)

`/project/{id}/inspection-visit-log` 페이지 피드백 5건 반영.

1. **③④⑤ 빠른 입력 버튼 6종**: 안전 / 시공 / 품질 / 환경 / 공종협의 / 민원협의 — 클릭 시 ③ 방문 근거 및 목적, ④ 업무 수행내용, ⑤ 지시사항을 형식적인 기본 문구로 채움 (덮어쓰기, 이후 자유 수정). 문구는 간단·형식적 요청에 맞춰 1줄씩. 안전·품질은 근거 법조문(건진법 제62조·제55조) 포함.
2. **발주기관 기본값 '한국농어촌공사'**: 사용자가 명시 요청 — createEmptyInspectionVisitLog 기본값으로 하드코딩 (기존 "기관명 하드코딩 지양" 결정을 사용자 지시로 뒤집음).
3. **⑦ 확인자 프리필 보강**: 성명(프로젝트 감독명)은 기존 구현 유지, 소속 '한국농어촌공사'·직책 '공사감독' 기본값 추가.
4. **방문 일시 기본값 = 접속 시각(한국시간) ~ 1시간 뒤**: 기존 `toISOString()`(UTC)은 KST 00~09시에 날짜가 하루 밀리는 버그 — 로컬 시간 포맷 함수(localDateStr/localTimeStr)로 교체하며 함께 해결. 브라우저 로컬 시간 = 한국 사용자 기준 KST.
