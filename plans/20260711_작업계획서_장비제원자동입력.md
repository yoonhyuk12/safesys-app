# 작업계획서 장비 제원 자동입력

## 목표

작업계획서 작성자가 장비 종류·규격급·제조사 모델을 선택하면 제조사 공식 제원에 근거한 장비 고정값을 자동 입력한다. 등록번호·보험·검사기간처럼 실제 개별 장비에서만 확인 가능한 값은 유지하거나 수기로 입력한다.

## 대상 장비

- 굴삭기
- 덤프트럭
- 화물차
- 이동식 크레인
- 트럭탑재형 크레인
- 다짐롤러(탠덤 진동·단드럼 진동·타이어 롤러)

## 설계

1. `src/lib/work-plan/equipment-catalog.ts`에 공식 제조사 자료 기반 대표 모델 시드를 둔다.
2. 규격급은 검색·분류에만 사용하고 자동입력 값은 `제조사 + 모델 + 세부 사양 + 출처 기준일`에 귀속한다.
   - 굴삭기는 톤급 대신 버킷 용량(㎥)을 규격 선택 기준으로 사용한다.
3. `EquipmentCatalogSelector.tsx`에서 장비군 → 규격급 → 모델의 3단계 선택을 제공한다.
4. 하역운반기계 양식에는 차체중량·폭·회전반경·인양높이·작업반경·하중을 매핑한다.
5. 건설기계 양식에는 장비명·차체중량·능력 요약을 매핑한다.
6. 중량물 양식에는 기계명·형식번호·기계규격·정격하중을 매핑한다.
7. 기존 수기 입력란은 유지하고 자동입력 후 사용자가 수정할 수 있게 한다.
8. 크레인 최대능력은 대표 조건과 함께 표시하며 현장 작업반경별 허용하중은 정격하중표 확인 대상으로 안내한다.

## 제외 범위

- 제조사 사이트 실시간 스크래핑
- 등록번호·제작연도·보험기간·검사유효기간 자동 추정
- 축거에서 최소회전반경 추정
- 크레인 정격하중표 전체와 현장 인양능력 자동 판정
- 원격 데이터베이스 마이그레이션

## 완료 기준

- 6개 장비군 모두 대표 모델을 선택할 수 있다.
- 굴삭기는 버킷 용량을 선택하면 해당 모델 후보가 표시된다.
- 모델 선택 시 현재 양식의 대응 제원이 자동 입력된다.
- 실제 장비 고유값은 자동입력으로 지워지지 않는다.
- 출처와 기준일이 선택 UI에 표시된다.
- `npx tsc --noEmit`, `npm run lint`, 대상 엄격 ESLint가 통과한다.
