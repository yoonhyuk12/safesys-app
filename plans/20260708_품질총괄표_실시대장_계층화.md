# 품질검사 성과총괄표–실시대장 계층화 (2026-07-08)

## 배경 (사용자 피드백)

실시대장을 등록한 뒤 총괄표를 만들면, 이후 추가된 실시대장이 총괄표에 반영되지 않아 총괄표를 처음부터 다시 만들어야 한다. 프리미어의 "씬 아래 클립"처럼 총괄표를 부모, 실시대장을 하위로 두는 구조를 요청.

- 실시대장 추가 시 총괄표가 없으면 자동으로 총괄표가 하나 생기고, 그 하위로 실시대장이 쌓인다.
- 총괄표를 열면 하위 실시대장 기준으로 실적(④·⑤)이 기본 집계되어 있고, 나머지 정보만 입력한다.
- 새 총괄표를 원하면 실시대장 등록 시 "새 총괄표 생성 / 기존 총괄표 하위 등록"을 고른다. 총괄표가 여럿이면 그중 하나를 선택한다.

## 설계

### 1. 데이터 모델

`quality_test_records`에 `summary_id UUID REFERENCES quality_summary_reports(id) ON DELETE SET NULL` 추가 + 인덱스.

- CASCADE가 아닌 SET NULL — 총괄표 삭제가 실시대장 기록(법정 서식)을 지우면 안 된다. 삭제 시 하위 기록은 "총괄표 미지정"으로 남는다.
- 기존 레코드는 backfill 없이 `NULL`(미지정) 유지. 수정 화면에서 총괄표를 지정해 옮길 수 있다.
- 마이그레이션: `database/20260708-0633_add_quality_test_records_summary_id.sql`.

### 2. 실시대장 탭 (QualityTestRecordsTab)

- 총괄표 목록(id·report_date·writer_name·created_at)을 함께 로드.
- **등록/수정 폼에 "총괄표" 선택 UI 추가.**
  - 총괄표가 하나도 없으면 선택 UI를 숨기고 저장 시 자동으로 총괄표를 생성해 연결 (사용자 제안 그대로).
  - 총괄표가 있으면 드롭다운 — 기존 총괄표들 + "새 총괄표 생성". 신규 등록 기본값은 최신 총괄표, 수정 시 기본값은 해당 제출건의 현재 총괄표.
  - "새 총괄표 생성" 선택 시 저장 시점에 총괄표 행을 먼저 insert(작성일=오늘, 공사기간·공정률·작성자/확인자 기본값은 페이지에서 내려줌)하고 그 id로 연결.
- **목록을 총괄표 그룹으로 표시.** 각 총괄표마다 헤더 행(작성일·작성자 표시, 클릭 시 해당 총괄표 열기), 그 아래 소속 실시대장 행. `summary_id`가 NULL인 기존 기록은 "총괄표 미지정" 그룹으로 표시.

### 3. 성과총괄표 탭 (QualitySummaryTab)

- **총괄표를 열면 하위 실시대장을 자동 집계해 ④·⑤를 채운다** (기존 `aggregatePerformanceRows` 재사용 — 계획·비고·확인시험구분 입력값은 보존). 하위 기록이 0건이면 저장된 값을 그대로 둔다 (레거시 총괄표 보호).
- 수동 "자동집계" 버튼은 유지하되 하위 기록 범위로 축소. 하위 기록이 없으면 기존처럼 프로젝트 전체 기록으로 폴백 (레거시 워크플로 보존).
- 삭제 확인 문구에 "하위 실시대장 기록은 총괄표 미지정으로 남습니다" 안내 추가.

### 4. 페이지 (quality-test-ledger/page.tsx)

- 탭 간 연결: 실시대장 탭에서 총괄표 헤더 클릭 → `openSummaryId` 상태 설정 + 총괄표 탭으로 전환 → QualitySummaryTab이 해당 리포트를 자동으로 연다.
- RecordsTab에 총괄표 자동 생성용 기본값(공사기간·공정률·작성자/확인자)을 props로 전달.

### 변경하지 않는 것

- `serial_no`는 프로젝트 전역 유지 (별지 42호 대장은 누적 문서).
- 엑셀 대장 출력·사진대지는 기존대로 전체 기록 대상.
- 프로젝트 병합·일괄서명 레지스트리 — 새 테이블/서명 컬럼이 없으므로 무관.

## 검증

- `npm run lint`, `npx tsc --noEmit` 통과.
- 수동 시나리오: (a) 총괄표 0개에서 실시대장 등록 → 총괄표 자동 생성·그룹 표시, (b) 총괄표 존재 시 등록 폼에서 선택/새로 생성, (c) 총괄표 헤더 클릭 → 총괄표 탭에서 ④·⑤ 자동 집계 확인, (d) 레거시(미지정) 기록·총괄표 동작 유지.
