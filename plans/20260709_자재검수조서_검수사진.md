# 자재 원장 — 검수 사진 업로드 + 검수조서/사진대지 엑셀 출력

## 요구사항 (사용자 피드백)

1. 내역 등록/수정 모달의 합격량 필드 아래에 검수 사진 업로드 필드 추가.
   - 회전·크롭·압축 업로드 지원, 고화질 불필요, **선택 항목** (필수 아님).
2. 출력 버튼 → 엑셀 4시트 구성 ([별지 제11호 서식] PDF 기준).
   - 시트1 검수조서: 자재 검사(검수)조서. "계약 내용 그대로 검수한다" 개념 — 내역은 계약(발주) 품목 그대로, 금회 검수량 = 계약량. 일자는 출력 버튼 누른 일자.
   - 시트2 사진대지: 검사(검수) 사진대지. 해당 계약건(자재)의 검수 사진을 행 순서대로 1페이지당 2컷.
   - 시트3 수불부(기존), 시트4 출고요청서(기존).
3. 모든 시트 인쇄 시 가로 중앙(horizontalCentered) 배치.

## 컨텍스트 노트 (결정 사항)

- **사진 저장 위치**: `safety-inspection-photos` 버킷 `{projectId}/` 평면 경로. 프로젝트 삭제 라우트가 이 폴더를 통째로 정리하므로 별도 정리 코드 불필요 (검측요청서 사진과 동일 패턴, InspectionPhotoTab 참고).
- **DB 스키마**: 별도 테이블 대신 `material_ledger_entries.inspection_photos JSONB` (URL 문자열 배열). 행 삭제 시 Storage 파일 best-effort 삭제.
- **압축**: WorkerRegistrationModal의 compressImage 패턴 — canvas 리사이즈 최대 1280px, JPEG 0.8. A4 반 페이지 인쇄 기준 충분.
- **검수조서 값 채우기**: 계약명=납품요구 건명(캐시/조회, 실패 시 자재명), 납품요구번호·납품기한·공급자=자재 연계 정보, 납품완료일·검사요청일·검사완료일·보고일=출력일, 인도조건=행들의 dlvrCndtn 유니크 조인, 납품장소=프로젝트명, 완성정도="납품 완료", 의견="계약(납품요구) 내용과 같이 검수함". 내역은 규격당 1줄 — 수량=유효 발주량(calcEffectiveOrderQty), 금액=품대 합. 전회·잔량 공란, 금회=계약량.
- **사진대지 설명**: 자동 채움 — `{품명 첫 줄} 검수 (반입일 YYYY-MM-DD)`. 별도 설명 입력 UI는 요청에 없어 생략.
- **Advisor 직접 구현 사유**: 별지 서식 레이아웃(PDF)과 기존 패턴이 모두 현재 컨텍스트에 로드되어 있어 Worker 브리프 작성 비용이 구현 비용을 초과. lint·tsc로 직접 검증.
- **엑셀 사진 삽입**: quality-excel-utils의 `addPhotoImageInArea`(URL→base64, 비율 유지 중앙 배치) 재사용. 사진대지 상수(열 6개×15, 행 22pt, 사진 12행)는 inspection-photo-report와 동일.
