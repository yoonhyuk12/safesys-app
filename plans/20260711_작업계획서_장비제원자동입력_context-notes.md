# 작업계획서 장비 제원 자동입력 컨텍스트 노트

## 2026-07-11 초기 결정

- **실시간 검색 대신 검증 시드** — 작성 중 제조사 사이트 상태나 네트워크에 의존하지 않도록 공식 제품 페이지·카탈로그에서 확인한 대표 모델을 정적 카탈로그로 제공한다.
- **톤급은 분류값** — 같은 톤급도 캡·축거·붐·버킷·차대 조합에 따라 제원이 달라 실제 자동입력 키는 제조사·모델·세부 사양으로 한다.
- **굴삭기 규격 예외** — 굴삭기는 사용자 요구에 따라 장비중량 톤급이 아니라 버킷 용량(㎥)을 2단계 규격 선택값으로 사용한다. 장비중량은 선택 모델의 자동입력 제원으로만 유지한다.
- **개별 장비값 보존** — 등록번호, 제작연도, 보험기간, 소유회사, 검사유효기간은 모델 표준값이 아니므로 자동입력하지 않는다.
- **미공개값은 공란** — 제조사 공식 자료에 최소회전반경이나 차량총중량이 없으면 계산·추정하지 않고 공란으로 둔다.
- **크레인 하중 분리** — 최대 인양능력은 특정 최소반경·장비 설정의 대표값이다. 카탈로그 기본 제원과 작업반경별 정격하중표를 구분하고 사용자가 현장 조건의 허용하중을 확인하게 한다.
- **현재 스키마 우선** — 1차 구현은 DB 변경 없이 현재 `LoadingEquipmentSpec`과 `ConstructionEquipmentSpec`에 매핑한다. 추가 세부 제원은 능력 요약과 선택 UI 설명으로 제공한다.

## 2026-07-11 구현 결과

- **대표 모델 49종** — 굴삭기 9, 덤프트럭 7, 화물차 9, 이동식 크레인 5, 트럭탑재형 크레인 9, 다짐롤러 10종을 공식 제조사 자료와 확인일과 함께 시드했다.
- **다짐롤러 분류** — 탠덤 진동, 단드럼 진동, 타이어 롤러를 규격급에 명시했다. 타이어 롤러는 비진동으로 표시하고 밸러스트에 따른 실제 운전중량은 현장 확인 대상으로 남겼다.
- **3단계 즉시 적용** — 장비군 → 규격급 → 모델을 선택하면 별도 적용 클릭 없이 제원이 즉시 입력된다. 적용 후에도 기존 수기 입력란에서 수정할 수 있다.
- **양식별 매핑** — 하역운반은 장비명·모델·중량·폭·회전반경·인양높이·작업반경·정격하중, 건설기계는 모델명·차체중량·능력 요약, 중량물은 기계명·형식번호·기계규격·정격하중을 채운다.
- **안전 경계** — 크레인의 카탈로그 최대능력은 인양능력 검토의 `maxCapacityTon`에 자동 반영하지 않는다. 사용자는 실제 붐 길이·작업반경·아웃트리거 조건에 맞는 정격하중표를 확인해 직접 입력한다.
- **회귀 호환** — DB 타입이나 저장 JSON 구조를 바꾸지 않고 기존 폼 필드에 patch만 불변 병합하므로 기존 저장 레코드는 그대로 재편집할 수 있다.
- **데이터 검증** — 카탈로그 ID 중복 없음과 6개 장비군 49종 수량을 검사하고 GR-250N, 3.5t 화물차, HC 119i의 양식별 매핑 결과를 확인했다. 공식 페이지 재대조로 DX400LC-7과 타다노 이동식 크레인 제원을 교정했다.
- **검증 결과** — `npx tsc --noEmit`, `npm run lint`, 대상 파일 ESLint `--max-warnings=0`, `git diff --check`가 종료 코드 0으로 통과했다. 전체 lint 출력에는 기존 저장소 경고만 남았다.
