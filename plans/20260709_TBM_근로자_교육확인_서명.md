# TBM 근로자 교육 확인 서명 (일일안전교육 서명부)

## 요구사항

- `/tbm-view/[id]` (QR 공개 페이지)의 "외국인 근로자 지원 (음성 읽기)" 카드 바로 아래에 **"교육 확인 서명"** 진입점 추가.
- 근로자(비회원·익명)가 6개 항목 체크 후 본인 이름 입력 → 서명하기 → 손글씨 서명 → 제출.
  1. TBM·위험성평가 교육 확인
  2. 음주여부 (음주 안 함)
  3. 혈압여부 (수축기 150 미만)
  4. 보호구 착용여부
  5. 안전 CCTV 촬영 동의여부
  6. 몸(부상) 이상여부
- 그 날(제출 건)마다 "일일안전교육 서명부 — 작업장 출입 전 근로자 작업가능상태 점검" 양식(참조: `15. 작업장 출입 전후 근로자 작업가능상태 점검.pdf`)을 TBM일지와 함께 다운로드 가능하게.

## 참조 양식 구조 (PDF)

- 제목: 일일안전교육 서명부 / 부제: 작업장 출입 전 근로자 작업가능상태 점검
- 일자: YYYY-MM-DD(요일)
- 표 컬럼: NO. | 성 명 | TBM 위.평확인 | 음주여부 | 혈압여부 | 보호구 착용여부 | CCTV 촬영동의 | 몸(부상) 여부 | 서 명
- 예시 값: (확인) / X / 150미만 / 착용 / 동의 / 이상없음
- 하단 주석: ※ 작업가능 혈압(수축기 150미만, 의사 소견서 첨부 시 작업 가능), CCTV 촬영(개인정보 보호법 제15조 1항)

## 설계

1. **DB** — `tbm_worker_signatures` 테이블 신설 (`database/20260709-HHMM_add_tbm_worker_signatures.sql`).
   - `tbm_submission_id UUID NOT NULL REFERENCES tbm_submissions(id) ON DELETE CASCADE` — projects 직접 참조 없음(전이 CASCADE, merge_projects 가드 영향 없음).
   - 체크 6개 BOOLEAN NOT NULL, `worker_name TEXT`, `signature TEXT`(base64 — Storage 미사용), `created_at`.
   - RLS: SELECT `USING (true)` (기존 패턴), 쓰기 정책 없음 → INSERT는 service-role API 전용.
2. **API** — `src/app/api/tbm-view/[id]/signatures/route.ts`
   - GET: 서명 목록(id, worker_name, created_at — 이미지 제외). draft 차단.
   - POST(익명): 제출 존재·draft 검증, 이름/체크/서명 data URL 검증 후 supabaseAdmin insert.
3. **UI** — `src/components/tbm-view/WorkerEducationSignModal.tsx` 신설 + `tbm-view/[id]/page.tsx`에 서명 카드 섹션 추가(페이지 번역 `t()` 키 확장, 기존 `WorkerSignaturePad` 재사용).
4. **엑셀 서명부** — `src/lib/excel/tbm-worker-signature-export.ts` 신설 (A4 세로 1장, 서명 이미지 임베드).
5. **다운로드 통합** — `project/[id]/tbm-submission/page.tsx` 제출 건별 다운로드 메뉴에 "서명부 다운로드" 항목 추가 (supabase 클라이언트로 서명 조회 → 엑셀 생성).

## 완료 기준

- `npx tsc --noEmit`·`npm run lint` 통과 (신규·수정 파일 오류 0).
- 마이그레이션은 사용자가 Supabase 콘솔에서 실행 (MCP 읽기 전용) — 실행 전 main 푸시 금지.
