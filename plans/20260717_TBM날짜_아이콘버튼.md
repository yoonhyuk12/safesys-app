# TBM 날짜·아이콘 버튼 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** TBM 데스크톱 기록 헤더의 날짜를 `YY.MM.DD`로 표시하고 복사·단체문자 버튼을 아이콘 전용으로 만든다.

**Architecture:** `TBMStatus.tsx`의 기존 네이티브 날짜 입력을 유지하면서 표시 텍스트만 오버레이한다. 같은 헤더의 두 액션에서 텍스트 노드를 제거하고 `aria-label`로 접근성 이름을 보존한다.

**Tech Stack:** Next.js 15, React 19, TypeScript, Tailwind CSS 4, PowerShell 정적 계약 검사.

## Global Constraints

- 변경 대상은 `safesys-app/src/components/project/TBMStatus.tsx`의 데스크톱 TBM 기록 헤더로 제한한다.
- 날짜 선택 값과 `onChange` 동작은 기존 네이티브 `input[type="date"]`가 계속 담당한다.
- 표시 날짜 형식은 정확히 `YY.MM.DD`다.
- 복사·단체문자 버튼은 화면 폭과 관계없이 아이콘만 표시한다.
- JavaScript 너비 측정, 리사이즈 상태, 반응형 라벨 조건은 추가하지 않는다.
- `npm run build`는 사용자 동의 없이 실행하지 않는다.

### Task 1: TBM 기록 헤더 표시 정리

**Files:**
- Modify: `safesys-app/src/components/project/TBMStatus.tsx:2974-3107`

**Interfaces:**
- Consumes: `selectedDate: string`, `setSelectedDate`, `smsCopied: boolean`, `phoneNumbers: string[]`, `smsHref: string`.
- Produces: 기존 날짜 선택 동작을 유지하는 `YY.MM.DD` 표시와 접근성 이름이 있는 아이콘 전용 복사·단체문자 액션.

- [ ] **Step 1: 변경 전 정적 계약 검사를 실행해 실패를 확인한다.**

```powershell
$source = Get-Content -Raw 'src/components/project/TBMStatus.tsx'
$start = $source.IndexOf('/* 단체문자 버튼 - 현재 조회중인 TBM 기록 소장 전원에게 문자 */')
$end = $source.IndexOf('/* 엑셀 다운로드 버튼 - 본부 단위에서만 표시 */', $start)
$toolbar = $source.Substring($start, $end - $start)
$checks = @(
  $toolbar.Contains('aria-label={smsCopied ? ''복사 완료'' : `연락처 ${phoneNumbers.length}건과 문자내용 복사`}'),
  $toolbar.Contains('aria-label="TBM 소장님들께 단체문자 보내기"'),
  -not $toolbar.Contains('{smsCopied ? ''복사됨'' : `복사(${phoneNumbers.length})`}'),
  -not $toolbar.Contains("`n                              단체문자`n"),
  $source.Contains('[&::-webkit-datetime-edit]:opacity-0'),
  $source.Contains("selectedDate ? selectedDate.slice(2).replace(/-/g, '.') : ''")
)
if ($checks -contains $false) { throw 'TBM 데스크톱 도구 모음 표시 계약 미충족' }
```

Expected: `TBM 데스크톱 도구 모음 표시 계약 미충족` 오류로 실패한다.

- [ ] **Step 2: 복사·단체문자 액션을 아이콘 전용으로 변경한다.**

```tsx
<button
  type="button"
  onClick={async () => {
    const text = `${phoneNumbers.join(',')}\n\n[문자 내용]\n${smsBody}`
    try {
      await navigator.clipboard.writeText(text)
      setSmsCopied(true)
      setTimeout(() => setSmsCopied(false), 2000)
    } catch {
      const textarea = document.createElement('textarea')
      textarea.value = text
      document.body.appendChild(textarea)
      textarea.select()
      document.execCommand('copy')
      document.body.removeChild(textarea)
      setSmsCopied(true)
      setTimeout(() => setSmsCopied(false), 2000)
    }
  }}
  className={`inline-flex items-center justify-center p-1.5 rounded-md shadow-sm transition-colors ${
    smsCopied ? 'bg-green-100 text-green-700' : 'bg-orange-100 text-orange-700 hover:bg-orange-200'
  }`}
  title={`연락처 ${phoneNumbers.length}건 + 문자내용 복사`}
  aria-label={smsCopied ? '복사 완료' : `연락처 ${phoneNumbers.length}건과 문자내용 복사`}
>
  {smsCopied ? <Check className="h-4 w-4" /> : <Copy className="h-4 w-4" />}
</button>
<a
  href={smsHref}
  className="inline-flex items-center justify-center p-1.5 rounded-md bg-blue-100 text-blue-700 hover:bg-blue-200 shadow-sm transition-colors"
  title="TBM 소장님들께 단체문자 보내기"
  aria-label="TBM 소장님들께 단체문자 보내기"
>
  <MessageSquare className="h-4 w-4" />
</a>
```

    </span>
  </div>
</div>
