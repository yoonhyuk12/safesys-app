# 사고보고 목록 요양일과 인명 피해 표시.

- 인명 피해는 양수만 단위 없이 구분점으로 연결하고 모두 0이면 `-`를 표시한다.
- 산재신청 바로 오른쪽 요양일 열에 기존 저장값을 표시한다. 명시 0과 미입력을 구분한다.
- 프로젝트 목록 조회에만 JSONB scalar alias를 추가하고 사진 JSON lazy 조회와 저장 계약을 유지한다.
- 기존 목록 렌더링·데이터 계층 테스트를 보완한 뒤 타입 검사, 린트, 관련 테스트를 실행한다.
- 공식 Supabase 문서·실제 REST·브라우저 검증과 최종 리뷰·커밋은 코디네이터가 담당한다.

세부 진행은 [체크리스트](./20260916_사고보고_목록요양일/checklist.md)와 [컨텍스트 노트](./20260916_사고보고_목록요양일/context-notes.md)에 기록한다.
