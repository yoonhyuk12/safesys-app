# 품질시험 월례보고서 기능 계획

작성일: 2026-07-02
근거 양식: 「(14) 금월 품질시험실적 및 다음월 시공계획」(公社시험업무지침 별지 제3호서식, 지침 제15조 관련)

## 목표

프로젝트 상세 페이지의 **품질 캐비넷**에 "품질시험 월례보고서" 서류철을 추가하고, 종이 양식을 대체하는 월 단위 작성·조회·PDF 출력 기능을 구현한다.

## 양식 분석 (PDF 원본)

제목: "이번 월 품질시험 실적 및 다음월 시공계획"

- 헤더: 작성자(00건설 현장대리인 (인)), 확인자(00지사 공사사무소장 (인)), 지구명
- 표 열 구조 (행 = 공종/시험항목 단위)
  1. 공종
  2. 시험항목
  3. ( )년 시공계획
  4. ( )월 시공내역 — 시공물량 / 계(①+②) / 시험회수[품질시험① / 확인시험②(소계·전문기관확인·기타확인)]
  5. 이번 월까지 시공누계 — 위와 동일한 하위 구조
  6. ( )월 시공계획 (다음월)
  7. 시공잔량③ = 년시공계획 − 이번 월까지 시공누계
- 기입요령
  - ① 건설업자가 실시한 품질시험·검사 회수
  - ② 확인시험 회수 — 제17조 시험은 전문기관확인란, 제18~21조 시험은 기타확인란
  - ③ 시공잔량 = 년시공계획 − 이번월까지 시공누계

## 설계 결정

1. **서류철 위치**: 품질 캐비넷에 `C (점검)` 그룹을 신설하고 그 안에 배치 (검사/검측대장이 시공 캐비넷 C에 있는 것과 동일한 분류 논리). `bottomLabel="품질"`, `pdcaCategory="C"`.
2. **라우트**: `/project/[id]/quality-monthly-report` — 월 목록 + 작성/수정 폼.
3. **데이터 모델**: `quality_monthly_reports` 단일 테이블, 행 데이터는 JSONB 배열.
   - `project_id UUID REFERENCES projects(id) ON DELETE CASCADE` (필수 규칙)
   - `report_year`, `report_month`, `(project_id, report_year, report_month)` UNIQUE
   - `district_name`(지구명), `author_name`(작성자), `confirmer_name`(확인자)
   - `rows JSONB` — 행별 {공종, 시험항목, 년시공계획, 월시공물량, 월품질시험, 월전문기관확인, 월기타확인, 누계시공물량, 누계품질시험, 누계전문기관확인, 누계기타확인, 다음월시공계획}
   - 소계(전문기관+기타), 계(①+②), 시공잔량(년계획−누계)은 저장하지 않고 화면·PDF에서 계산.
4. **자동화 포인트**
   - 새 달 보고서 작성 시 직전 보고서가 있으면 행(공종·시험항목·년시공계획)을 복사하고, 누계 = 직전 누계 + 이번달 입력값으로 자동 계산 제안(수정 가능).
   - 지구명은 프로젝트명으로 기본값 채움.
5. **PDF 출력**: A4 가로, html2canvas + jsPDF. `applyHtml2canvasTextFix()` 적용 (CLAUDE.md 문제해결 항목 준수). 상하 패딩은 대칭으로.
6. **권한**: 기존 프로젝트 상세 서류철과 동일 — 별도 게이팅 없음 (프로젝트 접근 가능자라면 사용).

## 구현 단계

1. DB 마이그레이션 SQL 작성 (`database/`) → 적용
2. 데이터 접근 함수 (기존 패턴에 맞춰 lib 또는 페이지 내 supabase 호출)
3. 페이지: 월 목록 + 작성/수정 폼 (행 추가/삭제, 자동계산)
4. PDF 생성기 (`src/lib/reports/quality-monthly-report.ts`)
5. 품질 캐비넷에 서류철 추가 (`src/app/project/[id]/page.tsx`)
6. lint + 수동 검증
