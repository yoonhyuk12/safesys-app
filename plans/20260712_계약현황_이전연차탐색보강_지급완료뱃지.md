# 계약현황 — 이전 연차 계약 탐색 보강 + 대금지급 완료 뱃지

날짜: 2026-07-12
요청: (1) 조달청 조회에서 3차년도 차수 계약이 잡히면 그 계약을 단서로 이전 차수(연차) 계약까지 자동으로 불러오고 싶다. (2) 계약건별 대금지급 완료 여부를 표시하는 "완료처리" 뱃지를 달고 싶다.

## 배경 — 실호출 검증 결과 (2026-07-12)

원곡지구 수리시설개보수사업 토목공사(한국농어촌공사)로 조달청 계약정보 API를 실호출해 확인한 사실.

1. 확정계약번호 끝 2자리는 연차가 아니라 **변경차수**(상세 URL `ctrtChgOrd`)다. `R26TA0132368600`~`03`은 2026년 연차 계약 1건의 변경 이력 4건.
2. 연차별 계약은 **완전히 별개의 계약번호**를 갖는다(2025년 연차 = `R25TA0003785100`). 응답에 원계약·공고번호(ntceNo)·이전차수 연결 필드가 전부 빈 값 — 번호 기반 역추적 경로가 API에 없다. (기존 코드 주석의 2026-07-07 확인 사실과 일치)
3. 연차 계약명의 실데이터 패턴에 **연도 접두사형**("2025년 원곡지구 …")과 **괄호 연도 접미사형**("…(2026년)")이 존재한다. 기존 `nameGroupKey`가 처리하는 차수 접미어형("(3차년도, 2026년)"·"2차년도")과 다르다.
4. 계약명 필터(`nm`)를 붙인 월 조회는 10초 수준(기관명 단독 28~36초 대비)으로 역방향 다개월 탐색이 실용적이다.
5. **대금지급 완료 여부는 공개 API가 없다.** 공공데이터포털에서 "대금지급" API 검색 결과 0건. 나라장터 대금청구·지급 정보는 계약 당사자 로그인 영역. → 수동 토글로 구현.

## 현재 코드 상태

`safesys-app/src/app/project/[id]/contract-status/page.tsx`

- `handleRefreshAll`("업데이트" 버튼)에 이전·신규 연차 역탐색이 **이미 구현**돼 있다 (①번호 재조회 갱신, ②월별 목록 조회로 미등록 연차 탐색).
- 갭 A — 그룹핑: `nameGroupKey`가 연도 접두사·괄호 연도 접미사 패턴을 안 벗겨 연차들이 딴 그룹이 되고, 탐색 후보 필터에서도 걸러진다.
- 갭 B — 탐색 시작월: 차수 접미어가 없으면 `missingPast=false`라 시작월이 최신 체결월이 되어 과거로 안 거슬러간다. `amountShort`(금차합<총액)만으로는 미래 방향만 탐색.
- 갭 C — 대금지급 완료 표시 수단 없음.

## 변경 설계

### 1. 이전 연차 탐색 보강 (page.tsx만 수정)

- `nameGroupKey(type, name, stripYearAffix)` — 세 번째 인자가 참일 때만 연도 접두사(`2025년 `)·괄호 연도 접미사(`(2026년)`)를 추가로 제거. **차수분 계약(총액≠금차)에만 적용**해 단년도 반복 계약("2025년 정기점검"·"2026년 정기점검" 같은 별개 계약)이 잘못 병합되는 것을 방지.
- `isThtmPartial(tot, thtm)` 헬퍼 — 총액·금차 둘 다 양수이고 다르면 차수분 계약으로 판별.
- 호출부 3곳에 판별값 전달: 그룹 빌드(records), 탐색 후보 필터(items), 조회 모달 차수 동시선택(items).
- `scanPlans`의 탐색 시작월 — `amountShort`일 때 `cntrct_prd`의 "총공사 N일"을 파싱해 최종 준공일에서 역산한 사업 시작월(여유 1개월)로 확장. 기존 36개월 캡 유지.
- 조회 모달 등록 완료 alert에 장기계속 차수 포함 시 "업데이트로 이전 연차 자동 탐색" 안내 추가.

### 2. 대금지급 완료 뱃지

- 마이그레이션: `project_contracts.payment_completed BOOLEAN NOT NULL DEFAULT false` 추가.
- 그룹(계약건) 단위 토글 — 클릭 시 그룹 멤버(차수 행) 전체에 동일 값 UPDATE. 그룹 완료 판정 = 멤버 전원 완료. 새 차수가 나중에 추가되면 그 행이 false라 뱃지가 자동 해제됨(계약이 아직 안 끝났다는 의미와 부합).
- UI: 계약명 셀 하단에 토글 뱃지 — 미완료는 점선 회색 "지급완료", 완료는 초록 채움(대표 버튼과 같은 디자인 언어). 
- RLS 제약: UPDATE는 본인 등록 행만 가능 — 변경된 행 수가 멤버 수보다 적으면 안내 alert.

## 검증 기준

1. `npx tsc --noEmit` 통과.
2. `npm run lint` 통과.
3. 연도 접두·접미 제거 정규식을 실데이터 계약명으로 단위 확인(node 스크립트).
4. 의미 단위 커밋 2건(탐색 보강 / 지급완료 뱃지+마이그레이션). 푸시는 사용자 확인 후(main=운영 배포).
