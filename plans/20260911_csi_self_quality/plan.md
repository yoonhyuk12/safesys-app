# CSI 자체 품질시험 가져오기.

기존 시료봉인 탭을 자체 품질시험 목록·상세 가져오기로 교체한다. 발급 성적서 검색은 유지한다.

1. 실제 CSI 사업별 목록·시험 상세 HTML과 요청 조건을 확인한다.
2. 로그인·인증·파싱·페이지 순회 구조를 재사용하여 사업 선택, 자체시험 목록, 상세 조회를 구현한다.
3. 시험완료일·재료·생산자·시험장소·시험 기준·측정값·판정을 실시대장 작성 폼으로 전달한다. 저장은 기존 저장 동작을 사용한다.
4. 회귀 테스트, 린트, 타입 검사와 실제 조회·브라우저 입력 확인을 수행한다.

DB 변경은 없다. 자격증명은 소스·테스트·문서에 남기지 않는다. 외부 CSI 데이터는 조회만 한다.
