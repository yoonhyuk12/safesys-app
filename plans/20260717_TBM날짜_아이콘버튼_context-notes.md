# TBM 날짜·아이콘 버튼 컨텍스트 노트

## 2026-07-17

- 사용자 선택 요소는 `TBMStatus.tsx`의 데스크톱 TBM 기록 헤더에 있는 날짜 입력이다.
- 날짜 값은 `YYYY-MM-DD`로 유지하고 표시만 `YY.MM.DD`로 바꾼다.
- 초기 반응형 라벨 안은 사용자 요청에 따라 폐기했다.
- 복사·단체문자 버튼은 화면 폭 계산 없이 항상 아이콘만 표시한다.
- 사용자 소유의 미추적 PDF는 작업 범위에서 제외한다.
- 변경 전 버튼·날짜 표시 계약이 각각 예상한 이유로 실패했고 구현 후 모두 통과했다.
- `npx tsc --noEmit`은 오류 없이 통과했다.
- 대상 파일 ESLint는 오류 없이 통과했으며 기존 경고 9건만 확인됐다.
- 자동화 브라우저에서 `/tbm` 로드, 본문 렌더링, 오류 오버레이 부재를 확인했다. 자동화 세션에는 등록 현장이 없어 대상 헤더 렌더링은 정적 계약 검사로 보완했다.
