# 품질시험 실시대장 삭제 권한 확대

## 목표

품질시험 실시대장 기록을 프로젝트 소유자와 모든 발주청 사용자가 삭제할 수 있게 하되, 화면 표시뿐 아니라 서버에서도 동일한 권한을 검증한다.

## 구현 계획

1. 프로젝트 소유자 또는 발주청 여부를 페이지에서 계산해 실시대장 탭에 전달한다.
2. 삭제 버튼 노출과 클라이언트 사전 검사를 해당 권한 기준으로 변경한다.
3. 인증 토큰, 프로젝트 소유권, 발주청 역할을 재검증한 뒤 같은 일련번호 기록 삭제와 잔여 일련번호 재정렬을 수행하는 서버 라우트를 추가한다.
4. 타입 검사·린트와 diff 검토로 기존 미커밋 변경 보존 및 권한 우회 방지를 확인한다.

## 완료 기준

- 프로젝트 소유자는 다른 사용자가 작성한 실시대장 기록도 삭제할 수 있다.
- 소유자가 아닌 발주청 사용자도 실시대장 기록을 삭제할 수 있다.
- 감리단·시공사 중 프로젝트 소유자가 아닌 사용자는 삭제 버튼과 서버 삭제 권한이 없다.
- 삭제 후 동일 일련번호의 모든 시험항목이 제거되고 남은 일련번호가 연속으로 재정렬된다.
- TypeScript 타입 검사와 ESLint 검사가 통과한다.
