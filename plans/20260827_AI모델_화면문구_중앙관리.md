# AI 모델 화면 문구·폴백을 중앙관리에 맞추기

작성일 2026-08-27. 관리자 `/admin/ai-usage`가 실제 호출 모델의 단일 출처다. 코드 기본값과 화면 문구가 예전 모델명을 그대로 들고 있어 어긋난다.

## 목표

사용자에게 보이는 모델명과 DB 조회 실패 시 폴백이 관리자 설정과 어긋나지 않게 한다. 모델 교체는 관리자 화면에서만 한다.

## 하지 않는 것

- 이미 적용된 시드 마이그레이션 `database/20260813-1400_ai_model_settings.sql` 수정
- 옛 계획서·스펙 문서 수정
- `RISK_AI_MODELS` 폴백 체인 자체 제거(위험성평가 API 장애 시 예비 모델)
- TTS 제공자 안내 `powered by OpenAI TTS` 문구(모델명이 아니라 제공자 표시)
- `ai-models.ts`를 클라이언트용으로 쪼개는 리팩터

## 변경

1. `DEFAULT_AI_MODELS` 폴백을 2026-08-27 DB 실값에 맞춘다.
2. 화면에 박힌 모델명을 `useAiModel(featureKey, 폴백)`으로 바꾼다.
3. 이미 `useAiModel`을 쓰는 곳의 예쁜 이름 폴백(`GPT-5.6 Luna`, `GPT-5.4 nano`)을 모델 id로 맞춘다.
4. 특정 모델명을 가리키는 코드 주석을 일반화한다.

## 검증

- `cd safesys-app && npm run lint`
- `cd safesys-app && npx tsc --noEmit`
- 본부점검 모달 문구가 하드코딩 `GPT-4o mini`가 아닌지 확인
- 위험성평가 작업입력 단계가 `RISK_AI_MODELS[0]`을 그대로 그리지 않는지 확인
