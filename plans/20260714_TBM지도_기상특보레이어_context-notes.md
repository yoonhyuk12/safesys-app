# TBM 지도 기상특보 레이어 컨텍스트 노트

## 확인된 사실

- 현재 `KMA` 키는 ASOS와 기상특보 구형·신형 API 모두 `HTTP 200`으로 응답한다.
- 특보현황 신형 API는 `REG_UP_KO`, `REG_ID`, `REG_KO`, 발표·발효시각, 특보종류, 수준, 명령을 CSV로 반환한다.
- `TBMRecord`에는 주소와 위·경도가 있고 기존 지도는 TBM 마커와 `CustomOverlay`를 이미 사용한다.
- 기상청 특보현황 응답에는 폴리곤 좌표가 없다.
- VWorld 공식 예제는 `LT_C_ADSIDO_INFO`, `LT_C_ADSIGG_INFO`를 Data API 2.0으로 조회해 GeoJSON 폴리곤을 표시한다.
- 프로젝트의 VWorld 키는 주소 API에는 사용되지만 Data API 경계 조회에서 `INCORRECT_KEY`를 반환한다.
- 공개 ArcGIS `SGG_view`와 `SIDO_view`는 2026년 7월 9일 갱신됐으며 행정안전부 주소기반산업지원서비스를 원천으로 한다.
- 최종 조합 API 검증 시점에는 원본 338행, 육상 301행, 활성 특보구역 188개를 읽고 경계 중복을 병합한 130개 지역을 반환했다. 경계를 찾지 못한 5개 구역은 전체 응답을 실패시키지 않고 생략했다. 특보 현황에 따라 이 수치는 계속 달라진다.
- `/map` 실제 브라우저 컨텍스트에서 `기상특보 (130개)` 렌더링을 확인했고, 데스크톱 토글은 요청에 따라 전체화면 버튼 바로 아래로 이동했다.
- 기상청 수준 값은 `주의`와 `경보`로 내려오며, 해제예고는 시각 숫자가 아니라 `15일 오전(09시~12시)` 같은 문구일 수 있다.

## 결정

- 기상청 키는 새 Route Handler 안에서만 사용한다.
- 행정경계는 별도 키가 필요 없는 공개 ArcGIS FeatureServer를 사용한다.
- 클라이언트는 조합 완료된 특보·경계 JSON만 받는다.
- 해상 코드와 해제 명령은 제외한다.
- 시·군 이름은 `시`, `군`, `구` 접미사를 제거해 기상청 이름과 매칭한다.
- 광역시·도 단위 특보는 시·도 레이어를 사용한다.
- 특보 세분구역은 정확한 세분 경계가 없을 때 상위 시·군으로 대체한다.
- 수원·안산처럼 구 단위로 나뉜 시는 같은 시의 여러 SGG 형상을 하나의 `MultiPolygon`으로 합친다.
- 같은 상위 경계를 공유하는 세분 특보는 경계 기준으로 특보를 병합하고 `approximate`를 표시한다.
- 전국 축척의 라벨 과밀을 막기 위해 카카오 지도 레벨 8보다 멀리 축소하면 라벨만 숨기고 폴리곤은 유지한다.
- 드롭다운은 현재 응답에 포함된 특보 종류와 지역 수를 동적으로 만들고, 전체 또는 여러 종류를 동시에 선택할 수 있게 한다. `전체`는 다시 누르면 모든 종류가 해제되는 토글로 동작한다.
- 특보 필터 변경은 지도 범위를 재계산하지 않으며 지도 범위는 현재 표시 중인 프로젝트·TBM 마커만으로 계산한다.
- 프로젝트·TBM 마커의 z-index를 특보 폴리곤·라벨보다 높게 유지하고 특보 채움 농도를 낮춰 마커 가독성을 우선한다.
- 프로젝트 상세 안전 캐비넷은 `actual_work_address`를 우선하고, 주소 매칭이 모호하면 프로젝트 위·경도로 SGG/SIDO 1점 공간질의를 수행한다.
- 위치 특보 응답은 GeoJSON을 제외한 경량 JSON이며, 최고 우선 특보를 `폭염주의보`처럼 표시하고 나머지는 `+N`으로 압축한다.
- 위치 API 검증에서 고양 좌표는 호우·강풍 2건을 geometry 없이 반환했고, 서울 주소와 기존 전국 지도 API도 `HTTP 200`, 위치가 없는 요청은 `HTTP 400`을 반환했다.
- 기상청 응답은 5분, ArcGIS 속성·형상 응답은 24시간 재검증하며 Route Handler 응답은 5분 CDN 캐시한다.

## 주의점

- 기존 미추적 이미지·엑셀·scratch 파일은 사용자 자산이므로 건드리지 않는다.
- `npm run build`는 사용자 동의 없이 실행하지 않는다.
- `main` 푸시는 운영 배포이므로 수행하지 않는다.
