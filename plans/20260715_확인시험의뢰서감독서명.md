# 확인시험 의뢰서 감독서명 작업 계획

## 목표

확인시험 의뢰서 목록에 품질검사 실시대장과 같은 감독서명 선택 흐름을 추가하고, 저장한 서명이 엑셀의 공사감독 이름 오른쪽에 출력되도록 한다.

## 단계

1. 실시대장 감독서명 UI와 일괄서명 API 대상, 확인시험 의뢰서 엑셀 출력 구조를 비교한다.
2. 발주청 사용자에게만 확인시험 의뢰서 감독서명 버튼과 미서명 행 선택 UI를 제공한다.
3. 선택한 의뢰서의 `sender_signature`를 기존 일괄서명 API로 저장한다.
4. 엑셀 생성 시 감독 이름 오른쪽에 저장된 서명 이미지가 포함되는지 확인한다.
5. 린트, 타입체크, 브라우저 시나리오를 검증한다.
