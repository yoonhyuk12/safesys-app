# 프로젝트 합치기 목록 선택 흐름

## 목표

프로젝트 목록에서 합치기를 시작하면 먼저 삭제될 현장을 고르고, 다음 단계에서 데이터를 유지할 현장을 고르게 한다.

## 범위

1. 기존 병합 API의 `source → target` 의미는 유지한다.
2. 선택 모달의 작은 목록을 제거하고 실제 프로젝트 카드 목록을 두 단계 선택 화면으로 사용한다.
3. 두 번째 단계에서는 첫 번째로 고른 현장을 선택할 수 없게 한다.
4. 최종 확인에서 삭제될 현장과 유지될 현장을 다시 보여준다.
5. 유지될 현장의 빈 선택사항을 삭제될 현장 값으로 보충하되 기존 값은 덮어쓰지 않는다.
6. 타입 검사와 린트, 브라우저 동작을 검증한다.

## 성공 기준

- 합치기 버튼을 누르면 고정 안내와 함께 삭제될 현장 카드 선택 단계가 시작된다.
- 현장을 고르면 같은 목록에서 유지될 현장 카드 선택 단계로 넘어간다.
- 최종 병합 요청에 첫 선택은 `sourceId`, 두 번째 선택은 `targetId`로 전달된다.
- target의 선택사항이 비어 있을 때만 source의 선택사항이 이전된다.
- 취소하거나 모달을 다시 열 때 이전 선택이 남지 않는다.
