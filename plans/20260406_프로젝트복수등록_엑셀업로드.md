# 프로젝트 복수 등록 (엑셀 업로드) 계획서

**작성일**: 2026-04-06

## 1. 개요

리스트 뷰(`/list`)의 플로팅 `+` 버튼을 누르면 "단일추가" / "복수추가" 선택 메뉴가 나타나도록 변경한다.
- **단일추가**: 기존 `/project/new` 이동 로직 유지
- **복수추가**: 엑셀 파일 업로드 → 컬럼 매칭 → 주소 기반 좌표 변환 → 일괄 프로젝트 등록

## 2. 변경 범위

### 2-1. 플로팅 버튼 UI 변경 (`Dashboard.tsx`)

**현재** (4206~4212줄, `viewMode === 'list'`일 때만 표시):
```
[+] 버튼 클릭 → handleSiteRegistration() → router.push('/project/new')
```

**변경**:
```
[+] 버튼 클릭 → 팝오버 메뉴 표시
  ├── 📋 단일추가  → router.push('/project/new')  (기존 동작)
  └── 📊 복수추가  → 엑셀 업로드 모달 열기
```

**구현 방식**:
- `+` 버튼 클릭 시 상단으로 팝오버(2개 버튼)가 뜨는 형태
- 팝오버 바깥 클릭 시 닫힘
- state: `isBulkMenuOpen` (boolean)
- 기존 `handleSiteRegistration()` 함수는 유지 — 팝오버의 "단일추가"에서 호출

### 2-2. 엑셀 업로드 & 컬럼 매칭 모달 (신규 컴포넌트)

**파일**: `src/components/project/BulkProjectUploadModal.tsx`

#### Step 1: 엑셀 업로드
- 파일 드래그&드롭 또는 파일 선택 (`.xlsx`, `.xls`)
- `xlsx` 라이브러리로 파싱 (이미 프로젝트에 설치됨 — `xlsx@^0.18.5`)
- **시트 선택**: 여러 시트가 있는 경우 드롭다운으로 시트 선택 가능 (기본값: 첫 번째 시트)
- 1행을 헤더로, 2행부터 데이터로 인식
- **엑셀 템플릿 다운로드** 링크 제공 (헤더만 있는 빈 xlsx 파일 — 클라이언트에서 xlsx로 생성)

#### Step 2: 컬럼 매칭
- 엑셀 헤더 목록을 보여주고, 아래 필드에 대해 드롭다운으로 매칭 선택:

| # | 필드명 | DB 컬럼 (`CreateProjectData`) | 필수 | 비고 |
|---|--------|-------------------------------|------|------|
| 1 | 프로젝트명 | `project_name` | ✅ | |
| 2 | 본부 | `managing_hq` | ✅ | `HEADQUARTERS_OPTIONS` 값과 매칭 |
| 3 | 지사 | `managing_branch` | ✅ | `BRANCH_OPTIONS[본부]` 값과 매칭 |
| 4 | 현장주소 | `site_address` | ✅ | 좌표 변환에 사용 |
| 5 | 상세주소 | `site_address_detail` | ❌ | 미매칭 시 빈 문자열(`""`) |
| 6 | 사업분류 | `project_category` | ❌ | `PROJECT_CATEGORY_OPTIONS` 값 |
| 7 | 총사업비 | `total_budget` | ❌ | 문자열 타입, 쉼표 자동 제거 |
| 8 | 직급(감독) | `supervisor_position` | ❌ | |
| 9 | 감독명 | `supervisor_name` | ❌ | |
| 10 | 감독 연락처 | `supervisor_phone` | ❌ | |

- **자동 매칭**: 헤더명이 필드명과 유사하면 자동 선택 (예: "사업명" → 프로젝트명, "주소" → 현장주소)
- 나머지 엑셀 컬럼은 무시
- "매칭 안 함" 옵션 제공 (선택 해제)

#### Step 3: 미리보기 & 유효성 검증
- 매칭 완료 후 데이터 테이블 미리보기 표시
- 유효성 검증:
  - 필수 필드(프로젝트명, 본부, 지사, 현장주소) 누락 행 표시
  - 본부값이 `HEADQUARTERS_OPTIONS`에 없는 경우 경고
  - 지사값이 해당 본부의 `BRANCH_OPTIONS`에 없는 경우 경고
  - **중복 검사**: 동일 프로젝트명이 엑셀 내에서 중복되거나, DB에 이미 존재하는 경우 경고 (등록은 허용하되 주의 표시)
- 유효하지 않은 행은 빨간색 표시, 등록 대상에서 제외 가능
- 행별 체크박스로 등록 대상 개별 선택/해제 가능

#### Step 4: 좌표 변환 & 일괄 등록
- "일괄 등록" 버튼 클릭
- 각 행의 `현장주소`로 `/api/geocoding` API 호출하여 위경도 추출
  - 기존 geocoding API가 V-World API 4단계 fallback을 이미 지원
  - **응답 형식**: `{ success: boolean, coords?: { lat: number, lng: number } }`
  - 동시 요청 제한: **2건** 병렬 처리 (V-World API가 주소당 최대 4회 fallback 호출하므로 보수적 설정)
  - 좌표 변환 실패 시 해당 행은 좌표 없이(null) 등록
- `createProject()` 함수를 각 행마다 호출하여 등록
  - `createProject()`가 내부적으로 `is_active` 기본값(`{q1:false,...}`)과 `created_by`를 자동 설정
  - `site_address_detail`이 미매칭인 경우 빈 문자열로 전달 (필수 필드)
- 진행률 표시 (프로그레스 바)
- 결과 요약: 성공 N건 / 실패 N건 / 좌표변환실패 N건
- **완료 후 데이터 새로고침**: `refreshProjects()` 콜백을 props로 받아 리스트 갱신

## 3. 데이터 흐름

```
[엑셀 파일]
    ↓  xlsx.read()
[시트 선택 (기본: 첫 번째)]
    ↓  sheet_to_json()
[raw 데이터 + 헤더 배열]
    ↓  사용자 컬럼 매칭 (자동 매칭 + 수동 조정)
[매칭된 데이터 배열: {project_name, managing_hq, managing_branch, site_address, ...}[]]
    ↓  유효성 검증 + 중복 검사
[유효 데이터 배열 (사용자가 행별 선택/해제)]
    ↓  /api/geocoding (현장주소 → lat/lng, 2건씩 병렬)
[좌표 포함 데이터 배열]
    ↓  createProject() × N (기존 함수 재사용)
[등록 결과]
    ↓  refreshProjects() 콜백
[리스트 뷰 갱신]
```

> **참고**: `createBulkProjects()` 별도 함수를 만들지 않고, 기존 `createProject()`를 순차 호출한다.
> 이유: `createProject()`가 내부적으로 `is_active` 기본값과 `created_by`(인증 사용자)를 설정하므로, 이 로직을 중복 구현하지 않는 것이 안전하다.
> 건수가 50건 이하인 일반적 사용 시나리오에서 성능 이슈는 미미하다.

### 자동 컬럼 매칭 로직
```typescript
const FIELD_KEYWORDS: Record<string, string[]> = {
  project_name: ['프로젝트명', '사업명', '현장명', '공사명', '프로젝트'],
  managing_hq: ['본부', '관리본부'],
  managing_branch: ['지사', '관리지사'],
  site_address: ['현장주소', '주소', '소재지', '현장위치'],
  site_address_detail: ['상세주소', '상세'],
  project_category: ['사업분류', '분류', '카테고리'],
  total_budget: ['총사업비', '사업비', '예산'],
  supervisor_position: ['직급', '감독직급'],
  supervisor_name: ['감독명', '감독자', '담당자명', '감독'],
  supervisor_phone: ['연락처', '전화번호', '감독연락처', '휴대폰']
}

// 매칭 로직: 정확 매칭 우선, 부분 포함(includes) 차선
function autoMatchColumns(headers: string[]): Record<string, number | null> {
  const result: Record<string, number | null> = {}
  for (const [field, keywords] of Object.entries(FIELD_KEYWORDS)) {
    // 1차: 정확 매칭
    const exactIdx = headers.findIndex(h => keywords.includes(h.trim()))
    if (exactIdx !== -1) { result[field] = exactIdx; continue }
    // 2차: 부분 포함
    const partialIdx = headers.findIndex(h =>
      keywords.some(kw => h.trim().includes(kw))
    )
    result[field] = partialIdx !== -1 ? partialIdx : null
  }
  return result
}
```

### 데이터 전처리
```typescript
// 총사업비: 쉼표/공백 제거, 숫자만 추출
function cleanBudget(value: unknown): string {
  if (!value) return ''
  return String(value).replace(/[,\s]/g, '')
}

// site_address_detail: 미매칭 시 빈 문자열 (CreateProjectData에서 필수)
function buildProjectData(row: Record<string, unknown>): CreateProjectData {
  return {
    project_name: String(row.project_name || '').trim(),
    managing_hq: String(row.managing_hq || '').trim(),
    managing_branch: String(row.managing_branch || '').trim(),
    site_address: String(row.site_address || '').trim(),
    site_address_detail: String(row.site_address_detail || '').trim(),
    project_category: row.project_category ? String(row.project_category).trim() : undefined,
    total_budget: row.total_budget ? cleanBudget(row.total_budget) : undefined,
    supervisor_position: row.supervisor_position ? String(row.supervisor_position).trim() : undefined,
    supervisor_name: row.supervisor_name ? String(row.supervisor_name).trim() : undefined,
    supervisor_phone: row.supervisor_phone ? String(row.supervisor_phone).trim() : undefined,
  }
}
```

### 좌표 변환 (병렬 제한)
```typescript
// 2건씩 병렬 처리 (V-World API가 주소당 최대 4회 fallback하므로 보수적)
for (let i = 0; i < rows.length; i += 2) {
  const batch = rows.slice(i, i + 2)
  const results = await Promise.allSettled(
    batch.map(row =>
      fetch(`/api/geocoding?address=${encodeURIComponent(row.site_address)}`)
        .then(res => res.json())
    )
  )
  // results[n].value = { success: true, coords: { lat, lng } } 또는 { success: false, error: '...' }
  // 진행률 업데이트: setProgress((i + batch.length) / rows.length * 100)
}
```

## 9. 주의사항

1. **`site_address_detail`은 `CreateProjectData`에서 필수 필드** (optional 아님). 엑셀에 상세주소 컬럼이 없으면 빈 문자열(`""`)로 전달해야 함.
2. **`total_budget`은 문자열 타입**. 엑셀에서 숫자로 읽힌 경우 문자열 변환 + 쉼표 제거 필요.
3. **geocoding API는 주소당 최대 4회 V-World 호출** (원본 → 번지제거 → 동리제거 → 시군단위). 대량 등록 시 병렬 수를 2건으로 제한.
4. **등록 후 반드시 리스트 새로고침** 필요. Dashboard의 프로젝트 목록 데이터를 다시 fetch.
5. **빈 행 필터링**: 엑셀 하단의 빈 행이 데이터로 인식되지 않도록 전처리 필요.
