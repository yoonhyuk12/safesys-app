# 현장 AI 비서 챗봇 경로 안내 링크 (2026-07-20)

## 목표

챗봇에 "자재 수불부 어디야?", "어디서 서명해?" 같은 위치 질문을 하면 답변에 클릭 가능한 내부 링크가 포함되고, 클릭 시 해당 화면(`/project/[id]/*` 하위 라우트)으로 이동한다.

## 설계

1. **공유 라우트 지도** — `src/lib/project-assistant/route-map.ts` 신설. 한국어 화면명 라벨 ↔ 라우트 세그먼트 목록의 단일 출처. API 시스템 프롬프트와 프론트 화이트리스트가 함께 사용.
2. **API 프롬프트 주입** — `/api/chat/project-assistant` chat 모드 시스템 프롬프트에 라우트 지도와 링크 출력 지침(마크다운 형식 `[라벨](/project/{projectId}/세그먼트)`) 추가. briefing 모드는 변경 없음.
3. **프론트 링크 렌더러** — `ProjectAssistantBot.tsx` 어시스턴트 메시지에서 마크다운 링크를 파싱해, 화이트리스트(`/project/${projectId}/<허용 세그먼트>`)와 일치할 때만 클릭 가능 링크로 렌더링. `router.push`로 이동. 불일치 링크는 텍스트로 강등.

## 범위 제외

- 모달로만 열리는 서류철의 자동 오픈(쿼리 파라미터) — 추후 필요 시.
- 라우트 이동 후 대화 상태 유지 — 챗봇은 프로젝트 상세 페이지 전용이라 이동 시 언마운트 허용.
