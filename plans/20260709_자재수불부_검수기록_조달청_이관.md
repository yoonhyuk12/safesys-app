# 자재 수불부 — 조달청 일괄 조회 2단계 "검수 기록 이관" (드래그앤드랍)

## 배경·목표

판부지구처럼 지급자재를 수기로 먼저 등록한 프로젝트가 있다. 수기 자재의 행에는 반입·검수·불출 실적이 살아 있지만, 발주량·단가는 사용자가 임의 입력한 값이라 조달청 데이터와 어긋난다.

사용자 결정 사항.
- **사용자가 등록한 발주량은 건너뛴다** — 조달청 납품요구의 발주량·단가·품대가 유일한 발주 데이터가 된다.
- **검수한 건(반입·검수·불출 실적 행)만 살린다** — 조달청 계약건의 어느 품목에 넣을지 **드래그앤드랍**으로 사용자가 직접 배정한다.
- **Ctrl(토글)·Shift(범위) 다중 선택** 후 한 번에 드래그해 일괄 배정도 가능해야 한다.

## 사용자 흐름

1. (기존) 수불부 헤더 "조달청 일괄 조회" → 수요기관·기간 조회 → 건 목록에서 체크 선택.
2. (신규) 하단에 기존 "⚔ 선택 건 등록" 버튼과 나란히 **"⚒ 등록 + 검수기록 이관 (N)"** 버튼 추가. 클릭 시 선택 건들의 상세(품목·발주량·단가)를 조회한 뒤 모달이 **2단계 매핑 화면**으로 전환된다 (이 시점까지 DB 쓰기 없음).
3. 매핑 화면.
   - **좌측 패널** — 미연계 수기 자재(자재·행 모두 `dlvr_req_no` 없음)의 행 목록을 자재별 그룹으로 표시. 각 행 카드에 규격·반입일·반입량·합격량·불출량을 표시하고, 사용자 입력 발주량은 취소선 회색으로 "건너뜀"을 시각화.
   - **우측 패널** — 선택한 납품요구 건별 카드(건명·번호·납품기한) 안에 품목별 **드롭 존**(품명·규격·단위·발주량·단가). 드롭 존 아래에 배정된 행 리스트 + 개별 해제(×).
   - 선택 — 클릭 단일, Ctrl+클릭 토글, Shift+클릭 범위(좌측 리스트의 표시 순서 기준). 선택된 행을 드래그하면 선택 전체가 함께 이동, 미선택 행 드래그는 그 행만.
   - 드롭 존에 **"선택 행 배정"** 소형 버튼도 병행(선택이 있을 때만 활성) — 터치·접근성 대체 수단.
   - 행의 소속 자재 단위와 품목 단위가 다르면 경고 아이콘 표시(배정은 막지 않음).
4. 하단 옵션 **"이관 후 빈 수기 자재 삭제"** 체크박스(기본 켬) — 이관으로 행이 전부 빠져나가는 자재 이름을 나열해 보여준다. 원래부터 행이 없던 자재는 삭제 대상이 아니다.
5. **"⚔ 이관 적용"** — 아래 순서로 실행.

## 적용(쓰기) 로직

건별 try/catch(기존 `handleBulkImport` 패턴)로 부분 실패를 보고한다.

1. 선택 건마다 `insertMaterialFromDlvrReq` 재사용 — 자재 1건 + 품목별 발주 행 생성 (발주량·단가·품대·수수료·인도조건은 조달청 값).
2. 배정된 기존 행을 UPDATE로 **재배치**한다 (INSERT/DELETE 아님 — 검수 사진 등 다른 컬럼 보존).
   - `material_id` → 새 G2B 자재 id.
   - `name_or_spec` → 해당 품목의 `formatG2bSpec` 문자열 (그룹핑 일치 필수).
   - `order_qty` → **null** (사용자 발주량 폐기 — 유효 발주량 계산 오염 방지).
   - `dlvr_req_no`·`dlvr_req_prdct_sno` → 품목 값.
   - `created_at` → 적용 시각 이후로 순차 재부여 (G2B 발주 행보다 뒤에 정렬되도록. 행 순서는 좌측 표시 순서 = 기존 created_at 순서 유지). 수불부에서 created_at은 정렬 키로만 쓰이고 화면에 노출되지 않는다.
   - 저장된 `pass_qty_total`·`remain_qty`는 그룹이 바뀌어 낡은 값이 된다 — 렌더가 계산값을 쓰는 컬럼은 그대로 두고, 저장값을 그대로 표시하는 컬럼이 있으면 이관 후 대상 그룹 기준으로 재계산해 UPDATE (구현 시 렌더 코드로 판별).
3. 체크박스가 켜져 있으면, 이관으로 행이 0개가 된 수기 자재를 삭제 — 삭제 직전 해당 자재의 남은 행 수를 DB에서 재확인(0건일 때만 삭제).
4. 전체 완료 후 `loadData()` 리로드, 결과 알림(등록 n건·이관 m행·삭제 k자재·실패 목록).

## 구현 파일

| 파일 | 작업 |
|------|------|
| `safesys-app/src/app/project/[id]/material-ledger/page.tsx` | 일괄 조회 모달에 step 상태 추가, 선택 건 상세 일괄 조회, 이관 적용 핸들러, 2단계 렌더 분기 |

- 드래그앤드랍은 네이티브 HTML5 (기존 Dashboard·ProjectCard 사례와 동일, 라이브러리 추가 금지).
- 스타일은 기존 일괄 조회 모달의 다크+앰버 게임풍 테마를 그대로 따른다.
- DB 마이그레이션 불필요 — `dlvr_req_no`·`dlvr_req_prdct_sno`는 이미 행 단위 컬럼.
