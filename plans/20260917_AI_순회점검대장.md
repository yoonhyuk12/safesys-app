# (AI) 순회점검대장.

발주청 캐비닛 C(점검) 그룹에 `︵AI︶ 순회점검대장` 폴더를 추가한다. 입력 화면은 사용자가 준 양식 `공사감독_순회점검.hwpx`(작업장 순회 점검표)의 구조를 그대로 따르고, 점검사항 10건은 당일 TBM 제출의 `today_work`를 읽어 `gpt-5.6-luna`가 정한다. 출력은 그 양식 hwpx를 템플릿으로 열어 값만 채운 HWPX다.

## 양식 구조 (정본 = `safesys-app/public/순회점검 양식.hwpx`).

- 표 1(5열 14행). r0 제목 `작업장 순회 점검표(시공사명)`, r1 빈 줄, r2 머리글 `No. | 점검사항 | 점검결과`, r3~r12 점검사항 10행(앞 5행 `(작업장 공통)`, 뒤 5행 `(테마)`, 결과 `양호`/`미흡`), r13 `지적사진 | (없는 경우 점검사진) | 지적사항 | 내용`.
- 표 2(8열 3행). `점검일자`, `지구명`, `점검자 | 소속 | _ | 직급 | _ | 성명 | _ | (서명)`.
- 상단에 농어촌공사 로고 그림 2개가 떠 있다. 템플릿을 그대로 쓰므로 손대지 않는다.
- 용지 A4, 여백 상하좌우 4251, 머리말·꼬리말 2834.

## 설계 결정.

- 이름. 라우트 `/project/[id]/patrol-ledger`, 테이블 `patrol_ledger_inspections`, 라이브러리 `src/lib/patrol-ledger/`, AI 라우트 `/api/ai/patrol-ledger`(feature key `ai.patrol-ledger`), HWPX `src/lib/hwpx/patrol-ledger-hwpx-export.ts`, 화면 컴포넌트 `src/components/project/patrol-ledger/`.
- 공용 계약은 `src/lib/patrol-ledger/types.ts` 하나다. 모든 모듈이 이 타입만 import 한다.
- 데이터 모델은 장비 일일점검 대장(`20260914-2245`, `20260915-0448`)을 본뜬다. 점검자 서명은 PNG dataURL CHECK, 항목은 JSONB CHECK 함수, RLS는 projects 조회 정책에 얹고 INSERT는 `created_by = auth.uid()`, UPDATE는 작성자 본인만(열 단위 권한), DELETE는 작성자·현장 소유자·발주청.
- AI는 모델을 `gpt-5.6-luna`로 고정한다(패트롤 점검 라우트 `src/app/api/ai/patrol-inspection/route.ts` 선례). Bearer 인증 후 사용자 토큰 클라이언트로 프로젝트·TBM을 읽어 RLS를 그대로 적용한다. strict json_schema로 정확히 10건(공통 5 + 테마 5)을 받고, 개수·카테고리 순서가 어긋나면 부분 성공 없이 실패로 돌린다.
- TBM 조회는 공사감독일지 페이지와 같은 두 갈래(project_id 일치 OR 사업명+본부+지사 일치), `status = 'submitted'`, `today_work`가 비었거나 `작업없음`이면 제외.
- HWPX는 템플릿 기반이다. JSZip으로 열어 셀 텍스트만 치환하고, 지적사진은 TBM 정본의 완전한 `hp:pic` XML로 셀 안에 인라인 삽입, 서명은 `(서명)` 문구 위에 PAPER 절대좌표 떠 있는 그림으로 겹친다(핵심 제약 signature-overlay).
- 사진 저장은 기존 공개 버킷 `safety-inspection-photos`의 `patrol-ledger/{projectId}/` 경로를 쓴다. 새 버킷을 만들지 않는다.

## 단계.

1. Advisor. 타입·계획서·템플릿 복사. (완료)
2. Worker A. 마이그레이션 + `records.ts`/`tbm-work.ts` + AI 라우트 + 테스트.
3. Worker B. HWPX 템플릿 치환 모듈 + 테스트 + 한글 2022 크래시·PDF 렌더 검증.
4. Worker C. 페이지·폼·목록·상세 컴포넌트, 캐비닛 폴더·건수.
5. Advisor. diff·테스트·브라우저 검증, 마이그레이션 적용, 문서 갱신, 커밋.

## 완료 기준.

- `npm run lint`, `npx tsc --noEmit`, `npm run test:patrol-ledger` 통과.
- 생성 hwpx가 한글 2022에서 열리고(ALIVE) PDF 렌더에서 양식과 같은 배치·서명 겹침이 확인된다.
- 브라우저에서 TBM이 있는 날짜를 골라 AI 생성 → 결과 체크 → 서명 → 저장 → 목록 → HWPX 다운로드가 이어진다.
