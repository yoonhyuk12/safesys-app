# 프로젝트 삭제 연관 건수 표시 계획

## 목표

`/list`의 프로젝트 삭제 모달에서 프로젝트 기본정보를 제외한 연관 입력정보 건수를 삭제 전에 확인할 수 있게 한다.

## 구현 계획

1. 삭제 API와 동일한 인증·권한 기준을 적용한 연관 건수 조회 API를 추가한다.
2. 사용자 입력 성격의 프로젝트 종속 테이블을 안전·점검, 근로자, 작업·TBM, 품질·자재·계약 범주로 집계한다.
3. 삭제 모달에 총 건수와 범주별 건수를 표시하고 조회가 끝나기 전 삭제 확정을 막는다.
4. 타입체크와 린트로 검증하고 변경 범위를 검토한다.

## 완료 기준

- 프로젝트 기본정보 1건은 집계에 포함되지 않는다.
- 연관 데이터가 0건이어도 명확한 안내가 표시된다.
- 조회 실패 시 오류와 재시도 수단이 표시되고 삭제 확정은 비활성화된다.
- `npx tsc --noEmit`과 `npm run lint` 결과를 확인한다.
