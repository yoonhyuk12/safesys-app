# 품질시험 반려 뱃지 탭·목록 표시

## Plan

- 품질시험 결과 관리대장 페이지에서 미확인 반려 총건수를 조회한다.
- 성과총괄표 탭에 프로젝트의 미확인 반려 총건수 파란 뱃지를 표시한다.
- 성과총괄표 목록의 작성자 셀에 해당 문서의 미확인 반려 `1` 뱃지를 표시한다.
- 반려 통보·확인 후 탭 뱃지가 즉시 갱신되도록 상위 페이지와 콜백을 연결한다.

## Checklist

- [x] 페이지 단위 미확인 반려 건수 조회
- [x] 성과총괄표 탭 파란 뱃지 표시
- [x] 목록 작성자 셀 파란 반려 뱃지 표시
- [x] 반려·확인 후 실시간 로컬 갱신
- [x] 정적 검사 통과

## Context

- 뱃지는 `rejected_at IS NOT NULL AND rejection_read_at IS NULL`인 총괄표만 집계한다.
- 목록의 한 총괄표는 활성 반려 상태를 하나만 가지므로 행 뱃지는 `1`로 표시한다.
- 관련 페이지와 컴포넌트에는 다른 품질 기능 변경이 있으므로 필요한 부분만 추가한다.
- `npx tsc --noEmit`, `npm run lint`, 대상 파일 `git diff --check`가 통과했다. lint에는 기존 저장소 경고만 남아 있다.
