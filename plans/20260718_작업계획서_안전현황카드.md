# 작업계획서 안전현황 카드

## 목표

`/safe` 안전현황 그리드에 **작업계획서** 카드를 추가하고, 본부·지사·프로젝트 3단 테이블로 작성현황을 파악할 수 있게 한다.

## 확정 설계

- **패턴.** `LegalComplianceView`와 동일. 뷰 컴포넌트가 프로젝트·`work_plans`를 자체 로드.
- **드릴다운.** 본부 테이블 → 지사 테이블 → 프로젝트 테이블.
- **연도 필터.** `created_at` 기준 연도(PTW와 동일). 분기 없음.
- **집계 컬럼 (본부·지사).**
  - 프로젝트 수
  - 작성 프로젝트 (1건 이상)
  - 미작성 프로젝트
  - 작성 건수 (`work_plans` 레코드 수)
  - 서식별 건수(하역/건설기계/전기/중량물) — 한 레코드의 `plan_types[]`를 각각 카운트
- **프로젝트 테이블.**
  - 프로젝트명 · 작성 건수 · 서식 종류 · 최근 작성일
  - 행 클릭 → `/project/{id}/work-plan?returnUrl=...`
- **라우트.** `/safe/work-plan`, `/safe/branch/[branch]/work-plan`
- **카드 UI.** 법적이행확인 앞(또는 옆). "현황 / 확인하기" 고정 문구(조회 버튼 없음, 법적이행확인과 동일).
- **권한.** 발주청 전용. `getProjectsByUserBranch` 스코프.
