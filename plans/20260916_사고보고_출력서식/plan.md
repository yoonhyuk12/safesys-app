# 사고보고 출력 서식 개선 계획

본문 1쪽과 사진대지 1쪽, 총 2쪽으로 고정한다. 본문 기본값은 휴먼명조 14pt, 장평 100%, 자간 0, 줄간격 130%이며, 넘칠 때 줄간격 100% → 장평 85%·자간 -5 → 본문 13pt·12pt 균일 축소 순서로 맞춘다. 가독성 하한에서도 넘치는 입력은 내용 생략 없이 축약 요청 오류로 알린다. 제목·항목 제목·체크 기호·연락처·사진설명의 역할별 위계와 원본 표 격자 및 사진 두 칸은 유지한다.

1. 원본/정제 양식의 header 및 section 서식을 조사한다.
2. 동일 역할 글꼴, CRLF/CR/LF 및 빈 문단, 자동/수동 이어쓰기, 쪽 경계 보존 회귀를 RED로 확인한다.
3. 기존 치환·XML·쪽 분할을 재사용하며 공백 패딩을 내어쓰기 문단으로 교체한다.
4. 사고보고 전체 테스트·타입체크·린트를 실행하고 코드 변경을 동결한다.
5. 부모가 Hancom COM/PDF/브라우저에서 시각 검증한다.

작업 범위는 생성기, 레이아웃, 템플릿 정제 스크립트/정제파일, 관련 테스트와 이 계획 문서다. 원본 public/사고 및 사용방법.md, 부모 scratch, API/AI/DB는 건드리지 않는다. 추가 라이브러리·Worker·build·commit·push는 하지 않는다.
검증은 과다 장문 거부·전체 내용 보존·총 2쪽 구조와 자동·수동 줄바꿈 정렬을 포함한다. 부모의 실제 한글/브라우저 기본 작업 검증 결과와 후속 검증 범위는 implementation-report.md에 구분하여 기록한다.
