# 컨텍스트 노트

cp17은 휴먼명조 14pt 장평100 자간0이며 cp38 사고내용은 바탕체13pt 장평98 자간-2였다. 요지 pp44, 사고내용 pp43, 재산피해/조치 pp42 모두 기존 내어쓰기 값과 공백 패딩이 섞여 있다. valueLines가 빈 줄을 삭제하고 CR을 처리하지 않으며 쪽 분할이 문단 내어쓰기 폭을 무시한다.

기존 XML 스캐너와 조립기를 재사용한다. 신규 외부 구현/라이브러리가 필요하지 않다. feature-workflow의 별도 superpowers 스킬은 제공되지 않았으며 해당 절차는 계획·RED·직접 diff 검증으로 수행한다. 사용자 지시에 따라 추가 Worker·커밋·COM은 수행하지 않는다.

연락처 cp36 11pt와 사진설명 cp28 13pt는 보조 역할로 보존한다. header의 기존 font/char/para 정의를 보존하고 신규 문단 정의를 추가한다. 입력 본문을 cp17로 선택적으로 통일한다.

한컴 공식 문단 설명은 내어쓰기가 첫 줄을 제외한 나머지 줄에 적용된다고 명시한다. https://help.hancom.com/hoffice120/ko-KR/Hwp/format/paragraph/paragraph_general.htm . 기존 case/default 좌표 배율1/2를 유지했다.

최신2쪽 요구 반영으로 기존 다쪽 분할 코드를 제거했다. 부모는 14pt가 사용자 고정값이 아닌 기본 가정이므로 최종13/12pt 균일 축소를 승인했다. 첫 내용/이어쓰기 사이 미세한 실제 글꼴폭차이는 남지만 자동/수동 이어쓰기는 PDF실측 x=142.56으로 일치하여 부모가 추가보정을 하지 않도록 지시했다.

원본/정제 header 동일 검증은 유지했다. 생성header는 fontfaces/기타charPr/표스타일 원본보존과 본문cp17의허용범위·추가문단 수/여백·PUAfontRef 동일을 별도로 검증한다.

최종 부모 리뷰에 따라 연락처 빈줄높이 RED→GREEN 보완과200자 캡션2개 회귀를 추가했다. 제품코드 동결 후 검증은 전체237개 중236PASS/TODO1/FAIL0, HWPX47PASS, tsc와lint exit0이다.
