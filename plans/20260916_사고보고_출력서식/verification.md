# 부모 검증.

실제 생성기와 브라우저 저장·다운로드 경로를 검증했다. 브라우저의 Supabase 응답만 가로채 운영 데이터에는 쓰지 않았다. 원본 PDF/HWPX 및 기존 저장 내용은 수정하지 않았으며 개인정보를 포함한 검증 산출물은 ignored scratch에만 보관했다.

- 기존 사용자 다운로드에서 복원한 보고서의 재출력을 한글2022에서 열기·저장·재열기·PDF 변환했다. 본문 1쪽과 사진 1쪽을 확인했고 이전 출력과 공백·글머리 제외 807자가 같았다.
- 파주 원본에서 실제 AI로 추출했던 결과를 브라우저에 자동 입력하고 가상 저장 후 HWPX를 다운로드했다. 한글에서 실제 2쪽이며 입력 문장 13개 전부 1쪽, 사진 2컷은 2쪽에 있었다.
- 여러 줄과 중간 빈 줄을 포함한 합성 입력을 브라우저에서 저장·다운로드했다. 한글에서 실제 2쪽이며 입력 25줄 전부 보존됐다. 사고 개요 자동 줄바꿈·수동 줄바꿈·빈 줄 뒤 문단의 시작 좌표는 모두 x=142.56이었다. y=377.28/389.28/413.28로 12pt 빈 줄도 유지됐다.
- 200자 사진 설명 2개가 있는 합성 보고서를 최종 생성기로 만들고 한글에서 열기·저장·재열기·PDF 변환했다. 실제 2쪽이며 사진 2컷과 두 설명의 끝 문구가 모두 보존됐다.
- 위 출력은 모든 페이지를 렌더링해 글꼴·테두리·텍스트·사진의 배치를 확인했다. 입력이 지나치게 길 때는 브라우저에서 안내가 표시되고 다운로드나 데이터 변경이 발생하지 않았다.
- 부모가 HWPX 회귀 47개를 직접 실행해 모두 통과했다. 연락처 빈 줄의 높이 과소계산을 리뷰에서 찾아 수정했고, 독립적인 긴 사진 설명 회귀를 유지했다.

최종 체크줄 정렬 후속 검증도 완료했다. 피해자 머리와 신고·사고자 조치 체크줄이 길 때 이어지는 줄의 왼쪽 여백을 확인했다. 최종 코드의 긴 사진 설명 표본과 브라우저에서 저장한 합성 보고서를 한글2022에서 다시 열기·저장·재열기·PDF 변환했으며 각각 2쪽 전체를 확인했다. 합성 보고서의 입력 25줄과 사진 2컷이 보존됐고 페이지 밖으로 나간 텍스트가 없었다.

부모가 최종 코드에서 사고보고 전체 테스트를 실행해 238개 중 237 PASS, FAIL 0, 기존 TODO 1로 종료 0을 확인했다. HWPX 테스트는 48개다. 후속 Worker의 타입체크·린트도 통과했다. 두 Task 모두 성공으로 종료하고 Worker를 회수했으며 회수 대기 대상은 0이다. 운영 SQL·빌드·푸시는 실행하지 않았다.
