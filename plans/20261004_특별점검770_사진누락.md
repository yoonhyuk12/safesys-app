# 특별점검 770 결과 HWPX 사진 누락 수정

## 범위와 완료 기준

지적 없는 점검의 현장 사진 누락 원인을 사진 수집과 XML 렌더링으로 나누어 확인한다. 대상 export·parts·테스트를 조사하고, 코디네이터가 확인한 저장 전 원본 삭제 결함에 따라 `Special770PhotoSlot.tsx`와 `Special770LedgerRows.tsx`까지 수정 범위를 확장한다. 실패 회귀 테스트를 먼저 실행한 뒤 통과를 확인한다. 기존 미추적 파일은 저장소 밖에 백업하며 커밋·푸시·빌드는 하지 않는다.

1. 기존 코드와 TBM 정본, 실제 템플릿의 셀·문단 설정을 비교한다.
2. 코디네이터의 실제 다운로드 조사와 수집 경로 테스트로 원인을 좁힌다.
3. 증거가 확보된 결함에 실패 테스트를 추가하고 최소 수정한다.
4. 특별점검 테스트를 실행하고 변경 경로와 검증 한계를 보고한다.

브라우저·한컴 육안 확인·린트·타입 검사는 코디네이터가 수행한다. 진행 기록은 [checklist.md](./20261004_특별점검770_사진누락/checklist.md)와 [context-notes.md](./20261004_특별점검770_사진누락/context-notes.md)에 남긴다.
