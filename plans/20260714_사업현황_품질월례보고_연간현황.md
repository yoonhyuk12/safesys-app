# 사업현황 품질 월례보고 연간현황

## 계획

1. 프로젝트별 품질 월례보고 조회 결과에 제출 연월 목록을 포함한다.
2. `/business` 품질 월례보고의 본부·지사·프로젝트 표를 선택 연도의 1~12월 열로 표시한다.
3. 표 상단에 위·아래 버튼으로 조작하는 연도 선택기를 추가한다.
4. 타입체크와 린트로 변경 범위를 검증한다.

## 완료 기준

- 본부·지사·프로젝트 표에서 선택 연도의 1월부터 12월까지 제출 현황을 확인할 수 있다.
- 연도 위·아래 버튼을 누르면 표의 모든 월별 집계가 즉시 해당 연도로 바뀐다.
- 기존 사업현황 카드의 이번 달 제출 요약과 프로젝트 이동 흐름은 유지된다.

## 모바일 지사 표 개선

1. 지사명 열을 모바일에서 고정하고 폭을 제한한다.
2. 지사명은 모바일에서 세 글자 뒤에 말줄임표를 표시한다.
3. 월별 열은 가로 스크롤로 탐색할 수 있도록 표의 최소 너비를 유지한다.
4. 현재 연도를 조회할 때 지사별 표의 오늘이 속한 월 열을 별도 배경색으로 강조한다.
