# 재해예방 계약현황 카드 — 계획서 (2026-07-08)

## 요구사항

1. `/list` 페이지에 "재해예방 계약현황" 카드를 추가한다.
2. 카드 진입 시 지사별 → 지사 내 프로젝트별 계약 현황을 볼 수 있어야 한다.
3. 우측에 엑셀 다운로드 버튼 — `재해예방기술지도 계약현황.xlsx` 예시 양식(3단 헤더)으로 다운로드.

데이터 원천은 프로젝트별 계약현황 서류철(`project_contracts` 테이블, `/project/[id]/contract-status`)이다.

| 비고 | 공란 |

- 행 단위: `공사` 계약의 차수 병합 그룹(계약명 공백제거+구분 키, contract-status 페이지 `nameGroupKey`와 동일 로직) 1행.
- 정렬: 본부(HEADQUARTERS_OPTIONS 순) → 지사(BRANCH_OPTIONS 순) → 프로젝트 display_order → 계약 체결일.

## 구현 설계

1. **신규 페이지** `src/app/contract-overview/page.tsx` ('use client')
   - 발주청 전용(다른 롤은 안내 후 /list 이동).
   - `getProjectsByUserBranch(userProfile)`로 권한 범위 프로젝트 로드 → `project_contracts`를 project_id `.in()` 청크 조회.
   - UI: 헤더(뒤로가기, 제목, 우측 엑셀 다운로드 버튼) + 지사별 접이식 섹션.
     - 지사 헤더: 지사명 · 프로젝트 n · 계약 m건 · 총계약금액 합.
     - 펼치면 프로젝트별 블록: 사업명(클릭 → 해당 프로젝트 contract-status로 이동) + 계약 그룹 표(구분, 계약명, 계약상대자, 총계약금액, 계약기간).
   - 컴팩트·흰 배경 디자인(사용자 UI 선호 반영).
2. **엑셀 내보내기** `src/lib/excel/disaster-prevention-contract-export.ts`
   - ExcelJS로 예시 양식 재현(병합·열너비·테두리·가운데 정렬, 금액 #,##0).
   - 파일명 `재해예방기술지도 계약현황_YYYYMMDD.xlsx`.
3. **/list 카드**: Dashboard.tsx의 list 뷰(발주청) 검색바 위에 "재해예방 계약현황" 카드 추가 → 클릭 시 `/contract-overview` 이동.
