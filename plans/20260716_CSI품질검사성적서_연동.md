# CSI 품질검사 성적서 연동 — 실시대장 가져오기

## 목표

건설공사 안전관리 종합정보망(csi.go.kr)의 **품질검사 성적서 서비스**(QTM006, CSI-AN22-201)를 호출해
품질검사 실시대장(별지 제42호서식) 화면에서 성적서를 조회하고, 선택한 성적서를 대장 등록 폼에
프리필(가져오기)한다.

## API 명세 요약 (기술문서 PDF 기준)

- 엔드포인트. `GET https://api.csi.go.kr/api/service/qtm/qrptbReprtInfo`
- 인증. `serviceKey` 쿼리 파라미터 (자동승인 키, 일 30,000건 / 1회 최대 100건)
- 필수. `schStIssueYmd`, `schEndIssueYmd` (성적서 발급일자 범위, YYYYMMDD)
- 선택. `schConstNm`(공사명), `schInstType`(R:의뢰기관/Q:대행기관), `schCompanyNm`, `schTsNm`, `pageNo`, `numOfRows`, `returnType=JSON`
- 응답. `response.header.resultCode`('00'=성공) + `response.body.items[]` — 성적서×시험결과 항목 단위의 평탄화 행
- [발급완료] 단계 이후 성적서만 제공. 데이터 조회 기준 "기관".
- 오류 응답 실측(더미 키). `{"response":{"header":{"status":401,"resultCode":"30","resultMsg":"API 인증이 실패하였습니다."},"errors":[...]}}`

## 구현 범위

1. **환경변수** — `CSI_API_KEY` (.env.local + Vercel). 키 값은 사용자가 직접 기입.
2. **공유 타입** — `src/lib/quality/csi-report-types.ts`. 정규화된 성적서 그룹 타입.
3. **API 라우트** — `src/app/api/csi/quality-reports/route.ts`.
   서버에서 CSI 호출(키 은닉), 평탄화 행을 성적서번호(issueNo) 기준으로 그룹핑해 반환.
4. **조회 모달** — `src/components/project/quality/CsiReportImportModal.tsx`.
   발급일자 범위(기본 최근 3개월)·공사명(기본 프로젝트명) 필터 → 조회 → 성적서 카드 목록 → 가져오기.
5. **실시대장 연결** — `QualityTestRecordsTab.tsx` 헤더에 "CSI 성적서" 버튼 추가,
   가져오기 시 등록 폼 프리필(직접 DB 삽입 아님 — 사진·서명 필수값은 사용자가 채운 뒤 저장).

## 필드 매핑 (CSI → 실시대장 폼)

| 실시대장 | CSI 성적서 |
|---|---|
| 연월일(test_date) | tsiEndDt → cmptnYmd → issueYmd 순 폴백 |
| 시험·검사구분 | '의뢰(수탁)시험' 고정 (외부 대행기관 성적서이므로) |
| 대상 재료(target_material) | sampleNm(시료명) |
| 시험·검사 장소(test_place) | companyNm(대행기관명) → labNm(시험실) 폴백 |
| 시험·검사 종목(test_item) | teNm(종목) → tsNm(종별) 폴백 |
| 시험 기준(test_standard) | testMthd(시험검사 방법) |
| 시험 결과(test_result) | itmRslt + itmUnit |
| 비고(note) | `CSI 성적서 {issueNo}` (추적용) |
| 공종·공급공장·판정·서명 | 프리필 없음 — 사용자가 입력(판정 기본 '합격') |
