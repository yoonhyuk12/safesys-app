## 프로그램의 특징 (약 1,450자)

```
「안전관리시스템(safesys)」은 한국 건설현장의 안전관리 업무를 통합 디지털화한 웹 기반 PWA 시스템이다. Next.js 15, React 19, Supabase 기반으로 PC·모바일·태블릿에서 즉시 접속 가능하고, 설치형 앱 수준의 오프라인 대응·푸시 알림·자동 업데이트를 지원한다.
본 프로그램은 발주청–감리단–시공사 3자 협업과 본부–지사 2단계 조직 구조를 전제로 설계되었고, 역할 기반 접근제어(RBAC)로 열람·입력·승인 권한을 세분화한다. 발주청(본부급)은 전사 데이터를, 감리단·시공사는 소속 지사 데이터만 조회·등록한다.
핵심 기능은 폭염점검·관리자점검·본부불시점검·TBM 일일점검의 4대 점검 체계이다. 현장에서 체크리스트·사진·좌표·전자서명을 모바일로 입력하면 PDF·Excel·HWPX 양식으로 즉시 자동 생성되고, 분기별 토글 및 지사별·공종별 통계로 집계된다.
지도 기능은 Kakao Maps, V-World, Leaflet을 결합하여 전국 현장을 지사별 색상·분기별 활성 상태·점검 종류별 아이콘으로 다층 표시하며, 마커 클러스터링과 주소 검색·좌표 기반 등록을 지원한다.
작업자 관리는 QR 기반 신규등록, 건강설문·안전서약 전자 동의, 카드 OCR 자동 입력, 다국어 번역(중국어·베트남어·태국어 등)과 음성 안내(TTS)를 제공한다. 자재관리는 품목·수량·검수를 원장 형태로 기록한다.
AI 기능은 LLM의 API를 연동하여 일일점검 생성, 장비 수량 OCR, 감독일지 요약, 위험분석 작성, TBM 안전조언, 번역·TTS 8종을 제공한다. Telegram 봇으로 점검 결과·긴급 알림을 실시간 전송한다.
화면은 중앙 대시보드가 safety·tbm·map·list·business 뷰 모드에 따라 전환되고, 안전현황은 카드 선택과 지사 필터로 계층적으로 드릴다운된다. 분기별 토글 UI, 지사별 그룹화 목록, 체크리스트+사진+좌표+서명 통합 입력 화면 등 건설안전 도메인에 특화된 독자적 화면 구성을 채택하였다.
본 프로그램은 한국 건설안전 법규·현장 업무 흐름·조직 계층 구조를 반영한 UI·UX 설계와 점검·문서·작업자·지도·AI를 단일 플랫폼에 통합한 아키텍처가 주요 창작적 표현이다.
```

## 주요 기능

```
1. 사용자 인증·권한 관리 - Supabase Auth 기반 이메일 로그인·회원가입·비밀번호 재설정·아이디 찾기를 제공한다. 사용자 역할(발주청·감리단·시공사)과 조직(본부·지사)을 연계한 RBAC로, 발주청 본부급은 전사 데이터, 감리단·시공사는 소속 지사 데이터만 자동 필터링된다.
2. 건설현장 관리 - 현장별 기본정보·행정구역·좌표·공사기간·계약금액·공종·담당자·진행률을 등록·수정·조회하며, 분기별 활성 상태 토글로 운영한다.
3. 안전점검 4대 체계 - 폭염점검(기온·체감온도·휴게시설·음용수·쿨링조끼), 공종별 관리자점검, 본부불시점검, TBM 일일점검을 제공한다. 각 점검은 체크리스트·현장 사진·GPS 좌표·전자서명을 모바일에서 입력하고, 양호·불량 판정과 특이사항을 저장한다.
4. 작업자 관리 - QR 기반 신규작업자 등록으로 인적사항·건강설문·안전서약을 전자 동의 수집하고, 카드 OCR로 신분증·자격증을 자동 입력하며, 교육·TBM 참여 이력을 관리한다.
5. 자재 원장·사업 관리 - 품목·수량·단가·납품일·검수·공급업체를 원장 형태로 기록하고, 사업관리 뷰에서 공사 진행·예산·계약 변동을 통합 조회한다.
6. 문서 자동 생성 - 점검 결과와 작업일지를 PDF, Excel, HWPX 세 포맷으로 자동 변환·다운로드한다. PDF 12종, Excel 10종, HWPX 3종 서식을 지원한다.
7. 지도 기반 현장 관리 - Kakao Maps·V-World·Leaflet을 결합하여 전국 현장을 지사별 색상·분기별 활성 상태·점검 종류별 아이콘으로 다층 시각화하며, 마커 클러스터링·주소 검색·좌표 기반 등록을 지원한다.
8. AI 업무 지원 - LLM의 API를 연동하여 8종 기능(일일점검 문안, 장비 수량 OCR, 카드 OCR, 감독일지 요약, TBM 안전조언, 위험분석 문안, 다국어 번역, TTS 음성 안내)을 제공한다.
9. 기상·외부 API 연동 - 기상청 ASOS·역사 기상·체감온도 API로 현장별 실시간 기상정보와 폭염경보를 제공하고, V-World·카카오 주소 검색으로 주소·좌표를 변환한다.
10. 실시간 알림 - Telegram 봇으로 점검 결과·긴급 이슈·서명 요청을 실시간 전송하며, 텍스트·사진 첨부를 지원한다.
11. PWA - 서비스 워커 오프라인 캐시, 홈 화면 설치, 자동 업데이트 알림으로 설치형 앱 수준의 사용성을 제공한다.
12. 대시보드·UI - 중앙 Dashboard가 safety·tbm·map·list·business 다섯 뷰 모드를 전환하며, 역할·카드 선택·지사 필터로 계층 드릴다운되는 안전현황 UI, 분기별 토글, 지사별 그룹화 목록, 체크리스트+사진+좌표+서명 통합 입력 화면 등 건설안전 특화 화면 구성을 채택하였다.
```

## 사용방법 (약 1,750자)

```
1. 접속·로그인 - 웹 브라우저 또는 PWA 앱으로 접속해 이메일·비밀번호로 로그인한다. 최초 이용자는 가입 후 관리자 승인으로 역할(발주청·감리단·시공사)·소속(본부·지사)을 부여받는다.
2. 대시보드 진입 - 로그인 시 역할별로 자동 분기되어 발주청·감리단은 안전현황(/safe), 시공사는 TBM(/tbm)으로 이동하며, 상단에서 안전현황·TBM·지도·목록·사업관리 뷰를 전환한다.
3. 현장 선택 - 지도 마커 또는 목록에서 현장을 선택하면 기본정보·담당자·점검 이력·작업일지·자재·작업자 메뉴가 제공된다.
4. 안전점검 등록 - 현장 상세에서 점검 종류(폭염·관리자·본부불시·TBM)를 선택 후 체크리스트 양호/불량, 현장 사진, GPS 좌표, 전자서명을 입력하여 저장한다.
5. AI 보조 입력 - "AI 자동작성"으로 LLM이 점검 문안·위험분석·감독일지 요약 초안을 생성하고, 카드 OCR·장비 수량 OCR로 이미지 텍스트·수량을 자동 추출한다.
6. 문서 생성 - 점검 이력에서 PDF/Excel/HWPX 내보내기를 선택하면 양식에 맞춰 자동 생성·다운로드된다.
7. 작업자 등록 - 신규 작업자가 현장 QR을 스캔해 인적사항·건강설문·안전서약에 전자 동의·서명하고, 카드 OCR로 신분증·자격증이 자동 입력되며, 외국인은 언어 선택 시 번역·TTS 안내가 제공된다.
8. 자재·사업 관리 - 사업관리 뷰에서 품목·수량·납품일·검수를 입력해 자재 원장을 관리하고 분기별·지사별 통계를 조회한다.
9. 알림 - 점검 완료·긴급 이슈·서명 요청 시 Telegram 봇이 담당자에게 실시간 전송한다.
10. 분기 전환·집계 - 안전현황의 분기 토글로 해당 분기 점검 현황·미이행 현장·지사별 완료율이 본부·지사별로 재집계된다.
```
