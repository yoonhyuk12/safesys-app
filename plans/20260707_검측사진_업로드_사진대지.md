# 검측 사진 업로드 + 엑셀 사진대지 출력

## 배경

`/project/[id]/inspection-request` (검사/검측 대장) 페이지 피드백.

> 검측 체크리스트(선택사항) 탭 옆에 사진 업로드 탭을 만들어 검측 사진을 올릴 수 있게 해달라.
> 최소 1컷, 최대 2컷. 그리고 엑셀로 사진대지 양식(자율)을 출력할 수 있게 해달라.

## 목표

1. 검측요청서 폼에 세 번째 탭 "검측 사진"을 추가하고 사진을 최대 2컷 업로드한다 (각 사진에 설명 입력 가능).
2. 엑셀 사진대지(자율 양식)를 출력한다.
   - 검측대장 헤더의 "사진대지" 버튼 — 사진이 있는 전체 검측건을 한 파일로 (건당 1페이지).
   - 기존 건별 엑셀 다운로드(요청서+체크리스트)에 사진이 있으면 시트3 "사진대지" 추가.

## 설계

### 데이터

- `inspection_requests.photos JSONB DEFAULT '[]'` 컬럼 추가 — `[{ url, caption }]` 최대 2개.
  - 새 테이블이 아니라 기존 CASCADE 자식 테이블의 컬럼 추가이므로 merge_projects 갱신 불필요.
- Storage는 기존 `inspection-photos` 버킷 재사용 (관리자점검이 쓰는 public 버킷). 경로: `inspection-request/{projectId}/{timestamp}_{rand}.{ext}`.
- 프로젝트 삭제 라우트(`/api/projects/[id]/delete`)의 URL 수집에 `inspection_requests.photos` 추가 (CLAUDE.md 규칙).
- 검측건 개별 삭제 시에도 Storage 사진을 함께 제거.

### UI

- `InspectionPhotoTab.tsx` 신규 — 업로드(카메라/갤러리), 미리보기, 설명 입력, 삭제. 2컷 초과 업로드 불가.
- `InspectionRequestForm.tsx`에 탭 버튼 추가, `projectId` prop 전달 (Storage 경로용).
- 저장 차단 검증은 하지 않는다 — 기존 레코드(사진 없음) 수정이 막히면 안 되고, 체크리스트와 동일하게 선택 입력으로 둔다. 안내 문구로 "최소 1컷, 최대 2컷"을 표기.

### 엑셀 사진대지 (자율 양식)

- `src/lib/excel/inspection-photo-report.ts` 신규.
- A4 세로 1페이지/검측건: 제목 "검측 사진대지", 헤더 표(공종·위치 및 공종·검측부위·검측일자·요청번호), 사진 영역 2칸(각각 설명 행 포함). 사진 1컷이면 두 번째 칸은 비움.
- 이미지 삽입은 `quality-excel-utils.ts`의 `addPhotoImageInArea` 재사용. 페이지 나눔은 `row.addPageBreak()` (safety-inspection-export.ts 선례).
