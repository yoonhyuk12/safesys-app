# 단속·점검방문 일지 기능 계획

작성일: 2026-07-03
근거 양식: 단속·점검방문 일지 — 건설기술 진흥법 시행규칙 제48조, 별지 제9호 서식 (PDF 원본 제공)

## 목표

프로젝트 상세 페이지의 **시공 캐비넷**에 "단속·점검방문 일지" 서류철 1개를 추가하고, 별지 제9호 서식의 작성·조회·엑셀 출력 기능을 구현한다.

## 양식 분석 (별지 제9호 서식)

1건의 일지 = 1회 방문 기록.

- ① 공사명 및 발주기관 등 — 공사명 / 현장위치 / 발주기관(건축주) / 공사규모 (공사감독원 또는 현장 배치 건설기술자가 작성)
- ② 방문 일시 — 년 월 일, 시:분 부터 ~ 시:분 까지
- ③ 방문 근거 및 목적 — 관계 법령·지시명령·행정계획과 방문 목적
- ④ 업무 수행내용 — 개략 기술
- ⑤ 지시사항 또는 특기사항
- ⑥ 방문자 — 최대 3명 (소속 / 직급 / 성명 / 서명), 3명 초과 시 별지
- ⑦ 공사감독원(책임건설사업관리기술자) 또는 현장 배치 건설기술자 확인 — 소속 / 직책 / 성명 / 서명

②~⑥은 방문자가, ①·⑦은 공사감독원(현장기술자)이 작성한다.

## 설계 결정

1. **서류철 위치**: 시공 캐비넷 `C (점검)` 그룹 — 검사/검측 대장 옆. 외부 기관의 단속·점검 방문 기록이므로 점검(Check) 분류. `pdcaCategory="C"`, `bottomLabel="시공"`, docCount는 일지 건수.
2. **라우트**: `/project/[id]/inspection-visit-log` — 목록 + 작성/수정 폼 단일 페이지 (탭 불필요, 양식 1종).
3. **데이터 모델** (1개 테이블, `project_id UUID REFERENCES projects(id) ON DELETE CASCADE` + RLS)
   - `inspection_visit_logs` — 1방문 = 1레코드.
   - ① 공사명·현장위치·발주기관·공사규모는 문서 스냅샷 성격이라 레코드에 TEXT로 저장, 프로젝트 정보로 프리필 (공사명=프로젝트명, 현장위치=주소).
   - ② `visit_date DATE`, `visit_time_from`/`visit_time_to` TEXT(HH:MM).
   - ③④⑤ TEXT.
   - ⑥ 방문자는 JSONB 배열 `visitors` — `{affiliation, position, name, signature}`. 서식은 3명 칸이지만 배열이라 유연 (기본 1명, 추가 버튼).
   - ⑦ 확인자는 평면 컬럼 — `confirmer_affiliation`, `confirmer_position`, `confirmer_name`, `confirmer_signature`(base64 TEXT).
   - 서명은 전부 base64 TEXT — cascade 삭제로 고아 파일 없음, Storage 수집 불필요.
   - RLS는 `inspection_requests` 동일 패턴: SELECT 전체 허용, INSERT/UPDATE/DELETE는 `auth.uid() = created_by`.
4. **일괄서명 등록**: ⑦ 확인 서명은 공사감독원(책임건설사업관리기술자) 서명이므로 `bulk-sign-targets.ts`의 `supervisor.targets`에 등록 (CLAUDE.md 필수 규칙). ⑥ 방문자 서명은 이름이 특정된 개인 서명이라 등록 제외 — 모달 안내 문구에 반영.
5. **출력**: ExcelJS 엑셀 출력, 1건 1시트 A4 세로 — 별지 제9호 서식 재현 (확인시험 의뢰서와 동일 패턴). html2canvas 계열 PDF는 사용하지 않음.
6. **권한**: 기존 서류철과 동일 — 프로젝트 접근 가능자 모두 사용, 수정·삭제는 작성자 본인 (RLS + UI).

## 구현 단계

1. `database/add_inspection_visit_logs.sql` 작성 → 사용자가 Supabase SQL Editor에서 실행 (MCP 읽기 전용)
2. 타입·CRUD — 검사/검측 대장 패턴 준수 (컴포넌트 내 supabase 직접 호출 or 타입 파일 분리, 조사 결과에 따름)
3. 페이지 `src/app/project/[id]/inspection-visit-log/page.tsx` + 폼 컴포넌트
4. 엑셀 출력 `src/lib/excel/inspection-visit-log-export.ts`
5. 시공 캐비넷 C(점검) 그룹에 서류철 추가 + 건수 표시 (`project/[id]/page.tsx`)
6. `bulk-sign-targets.ts` supervisor.targets 등록
7. 타입체크·lint → 시맨틱 커밋
