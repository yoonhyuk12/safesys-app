# 컨텍스트 노트 — 관급자재 납품요구번호 자동입력

## 2026-07-06 결정 사항

- **입력 방식 선택 위치는 "자재 등록 모달"** — 사용자가 "수불부 추가할 때 직접 입력/납품요구번호 선택" 요청. 내역(행) 추가 모달은 일별 수불 이벤트 입력이라 납품요구 개념과 맞지 않아 제외. 자재 등록 시점에 자재+품목별 발주 행을 한 번에 생성하는 게 자연스러움.
- **유효 수량 = incdecQty 합산** — 실데이터(R25TB00824197)에서 차수00 incdecQty=194.05(최초), 차수01 incdecQty=-194.05(취소)로 확인. prdctQty는 차수별 자체 수량이라 합산 대상이 아님. 품목 메타(규격·단가·기한)는 최신 차수 행 기준.
- **DB 스키마 변경 없이 구현** — dlvr_req_no 저장은 후속 단계로 미룸. Supabase MCP가 읽기전용이라 마이그레이션은 사용자 콘솔 적용이 필요해 이번 UI 작업을 막지 않도록 분리.
- **자재명/단위는 첫 선택 품목 기준** — 납품요구 하나에 품목 여러 개면 세부품명이 대개 동일(레미콘 규격들 등). 다르면 사용자가 등록 후 자재명 수정 가능.
- **수량 0(전량 취소) 품목은 기본 체크 해제** — 목록에는 표시하되 기본 선택에서 제외.
- **API 키 이름 확정: `DATA_GO_KR_API_KEY`** — 계정당 1키 구조 확인(사용자가 재발급 시도했으나 동일 키 발급됨). Vercel에도 같은 이름으로 등록됨.
- 엔드포인트 경로가 차세대 나라장터로 바뀜(`/1230000/at/...`). 구버전 경로(`/1230000/ShoppingMallPrdctInfoService`)는 500 반환. 명세는 data.go.kr 15129471 페이지 HTML 내 `var swaggerJson`에 내장.

## 미해결/주의

- 응답 `body.items`가 빈 결과일 때 `""`(빈 문자열)로 오는 케이스 가능성 — 라우트에서 Array 여부 방어 처리.
- D-1 제약: 당일 결재된 납품요구는 조회 안 됨 — UI 오류 문구에 안내 포함.
- 트래픽 제한: 개발계정 1,000건/일 — 운영 전환 시 활용사례 등록 필요할 수 있음.
