# 정기안전점검 보고서 벌크 PDF 다운로드

## 개요
지사(또는 본부) 단위로 소속 프로젝트들의 정기안전점검 보고서를 **하나의 PDF로 병합**하여 일괄 다운로드하는 기능

## 방식
**방식 B: 단일 PDF 병합** — 하나의 jsPDF 인스턴스에 모든 점검 페이지를 순차 추가 후 한 파일로 저장

## 사용자 흐름
1. 프로젝트별 테이블 헤더 영역에서 **PDF 벌크 다운로드 버튼** 클릭 (한글 버튼 좌측)
2. **점검유형 드롭다운** 표시 (전체/해빙기/우기/종합/특별) — 기존 `renderTypeSelectionMenu` 재활용
3. 유형 선택 시 **DownloadProgressModal** 표시 (진행률 업데이트)
4. 완료 시 PDF 자동 다운로드

## 수정 파일 및 작업 내역

### 1. `src/lib/reports/safety-inspection-report-pdf.ts` — 리팩토링

**현재**: `generateSafetyInspectionReportPdf()` 하나의 함수가 jsPDF 생성 → 페이지 렌더 → `pdf.save()` 까지 전부 수행

**변경**: 내부 로직을 분리하여 벌크에서 재활용 가능하게 함

```typescript
// 기존 함수는 그대로 유지 (단일 다운로드용)
export async function generateSafetyInspectionReportPdf(params): Promise<void>

// 새 함수: 외부에서 전달한 jsPDF 인스턴스에 페이지만 추가 (save 안 함)
export async function appendSafetyInspectionPages(
  pdf: jsPDF,
  params: SafetyInspectionReportPdfParams,
  isFirstInspection: boolean  // 첫 점검이면 newPage 추가 안 함
): Promise<void>
```

- `createPageDiv`, `renderPage`, HTML 템플릿 등 공통 로직을 내부 헬퍼로 분리
- 기존 `generateSafetyInspectionReportPdf`는 `appendSafetyInspectionPages`를 호출하도록 변경 (동작 변화 없음)

### 2. `src/lib/reports/safety-inspection-bulk-pdf.ts` — 신규 파일

벌크 다운로드 전용 함수:

```typescript
export async function generateBulkSafetyInspectionPdf(options: {
  branchName: string
  hqName?: string
  projectIds: string[]        // 지사 내 활성 프로젝트 ID 목록
  inspectionType?: string     // 점검유형 필터 (빈 값이면 전체)
  selectedYear: number        // 연도 필터
  onProgress: (current: number, total: number, stage: string) => void
}): Promise<void>
```

**내부 동작**:
1. `projectIds`로 `safety_inspections` 일괄 조회 (점검유형/연도 필터 적용)
2. 각 점검별 `safety_inspection_results` + `safety_inspection_photos` 조회
3. 각 점검별 `projects` 테이블에서 프로젝트 정보 조회 (1회 캐시)
4. 하나의 jsPDF 인스턴스에 `appendSafetyInspectionPages()` 순차 호출
5. `onProgress` 콜백으로 진행률 전달 (현재 점검 번호 / 전체 점검 수)
6. 모든 페이지 추가 완료 후 `pdf.save()` 호출

**파일명**: `정기안전점검_보고서_여주·이천지사_해빙기.pdf` 형태

## 성능 고려사항
- html2canvas 렌더링은 **반드시 순차 처리** (DOM 공유 문제)
- 점검 1건당 3~5페이지 × N건 → 시간 소요 예상
- `onProgress` 콜백으로 사용자에게 실시간 진행 상황 표시
- 사진 URL은 Supabase Storage의 public URL → CORS 이미 처리됨
