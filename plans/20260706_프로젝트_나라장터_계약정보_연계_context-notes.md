- **서비스 선정**: 조달청_나라장터 공공데이터개방표준서비스(15058815)는 날짜 범위 검색만 지원해 번호 직접 조회 불가. **계약정보서비스(15129427)의 `getCntrctInfoListCnstwkPPSSrch`**가 공고번호(ntceNo)·확정계약번호(dcsnCntrctNo) 직접 조회를 지원해 이쪽으로 확정. Swagger는 data.go.kr 상세 페이지 HTML의 `var swaggerJson`에서 추출해 확인함.

- **응답 형태 실측**: 날짜는 이미 `YYYY-MM-DD` 문자열, 금액은 원 단위 숫자 문자열. `corpList`/`dminsttList`는 `[순번^역할^구분^업체명^...]` / `[순번^기관코드^기관명^...]` 형태의 캐럿(^) 구분 문자열 — 업체명 index 3, 기관명 index 2로 파싱.

## 2026-07-06 추가 — 본부·지사 자동 매칭 + 등록 방식 탭

- **수요기관 → 관할 본부·지사 매칭**: dminsttNm(예: "한국농어촌공사 경기지역본부 여주.이천지사")을 `BRANCH_OPTIONS`와 대조해 managing_hq/managing_branch까지 자동 적용. 구분자 차이(G2B는 `.`, 상수는 `·`)와 공백을 제거해 비교하고, `{본부}지역본부`/`{본부}사업단`/`{본부}본부` 패턴으로 본부를 먼저 확정한 뒤 그 안에서 지사를 찾는다 (같은 지사명이 여러 본부에 있는 '지하수지질부' 오매칭 방지). 농어촌공사가 아닌 수요기관은 매칭하지 않음. 지사 없이 본부만 매칭되면 branch는 '{본부}본부' 옵션. 10개 케이스 node 스크립트로 검증 완료.
- **등록 폼 탭**: ProjectRegistrationForm 상단에 '직접 입력'/'나라장터 연계' 2버튼 탭 추가 (기본 '직접 입력'). 나라장터 탭에서만 조회 박스 노출. 수정 폼은 탭 없이 항상 노출 유지.
- **본부만 매칭되고 지사가 안 잡히면** 기존 지사 선택을 비운다 — 다른 본부의 지사가 남아 있으면 안 되기 때문.
- **수정 폼은 계약기간만 연동 (2026-07-06 사용자 결정)**: 기존 등록 프로젝트에 연계할 때는 사업명·총사업비·본부·지사를 덮어쓰지 않고 착공일·준공일·연계번호만 반영한다. 기존 데이터가 이미 정리되어 있는 프로젝트를 보호하기 위함. 전체 자동입력은 신규 등록(나라장터 연계 탭)에서만. 컴포넌트에 `subtitle` prop을 둬서 폼별 적용 범위를 안내 문구로 구분.
- **상세 페이지 갱신 버튼**: 프로젝트 상세(⋮ 메뉴 왼쪽)에 RefreshCw 버튼 — 연계 번호(g2b_cntrct_no/g2b_ntce_no)가 있을 때만 노출. 클릭 시 저장된 번호로 재조회해 착공·준공일만 supabase 직접 update 후 로컬 상태 반영. 드롭다운은 wrapper가 flex가 되면서 `top-full`로 위치 고정.
