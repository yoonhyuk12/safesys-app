# TBM 분석 OpenAI 전환 체크리스트

- [x] `OPENAI_API_KEY`와 `gpt-5.6-luna`를 사용한다.
- [x] OpenAI JSON 응답을 기존 결과 검증에 연결한다.
- [x] 모달 우측 상단에 `GPT-5.6 Luna`를 표시한다.
- [x] 분석 결과 단계의 데스크탑 모달 폭 제한을 해제한다.
- [x] 분석 요약과 메시지 컬럼에 충분한 폭을 배분한다.
- [x] 결과 헤더에 분석 대상 컬럼을 표시한다.
- [x] 현장명 셀을 현장명, 지사명, 소관사업명 3줄로 구성한다.
- [x] 분석 결과 표의 중복 소관사업 컬럼을 제거한다.
- [x] 대상 선택 표의 현장명 헤더와 셀에 지사명을 표시한다.
- [x] 화면에서 텔레그램 명칭을 제거하고 AI 분석과 메시지 발송으로 표기한다.
- [x] JSON이 아닌 API 오류 응답을 상태 코드가 포함된 사용자용 오류로 변환한다.
- [x] 새 개발 캐시에서 `/tbm` 200과 세 API의 JSON 오류 응답을 확인한다.
- [x] 인증 401에서 세션 갱신 후 요청을 한 번 자동 재시도한다.
- [x] 인증 서버 연결 오류와 무효 토큰 응답을 구분한다.
- [x] 실제 브라우저에서 재시도 후 대상 선택 표가 로드되는 것을 확인한다.
- [x] 변경 파일 ESLint와 전체 타입 검사를 통과한다.
