# 컨텍스트

- 기존 keyword=value 때문에 편집 시작 시 전체 저장 모델명이 필터로 작동한다.
- 클라이언트 새로고침은 기존 API URL을 재호출할 뿐 서버 캐시를 우회하지 않는다.
- 공급자별 정렬·관리자 인증·공급자 검증은 그대로 유지한다.
- 외부 구현이나 의존성 도입 없이 사용자가 지정한 ModelCombobox 및 기존 node 테스트 패턴을 재사용한다.
- superpowers 계획/TDD/리뷰 스킬은 제공된 카탈로그와 로컬 .claude 검색에 없다. 문서·RED/GREEN·직접 diff 검토를 수행하고 최종 리뷰는 지시대로 코디네이터가 담당한다.
- 기존 package-lock.json, log.md, .codex 및 이미지 파일 변경은 보존한다.
- 코디네이터가 GitHub ModelCombobox 검색 및 React input/Next fetch 공식 문서 조사를 완료했다고 전달했다. 새 라이브러리는 불필요하다.
- 검색어는 별도 로컬 상태로 관리한다. 포커스·닫힌 상태 클릭·방향키 재열기는 검색어를 지우며, 공급자 key 변경으로 이전 검색 상태를 폐기한다.
- 단가 입력은 label로 감싸 입력값이 있어도 단위가 노출된다. 가격 저장값과 PATCH 경로는 변경하지 않았다.
- API는 refresh=true만 캐시 우회로 인정하며 실패 시 이전 정상 캐시를 보존한다. 두 공급자 상위 fetch는 no-store이고 우선순위 정렬은 변경하지 않았다.
- 코디네이터가 독립 리뷰 워커를 실행했다. 이 작업자는 빌드·커밋·푸시를 수행하지 않는다.
