# 관리자 AI 모델 선택 개선

1. 기존 ModelCombobox를 재사용해 저장 값과 사용자 검색어를 분리한다. 포커스·재열기에는 전체 후보를 보여주고 직접 입력, 선택, Escape, 방향키를 유지한다.
2. 입력·출력 단가에 영구적으로 보이는 단위 라벨과 비용 추정용 안내를 붙인다. 가격 변경이나 자동 조회는 추가하지 않는다.
3. 새로고침은 refresh=true를 전송하고 두 공급자의 10분 서버 캐시를 우회한다. 상위 요청은 no-store로 실행하며 일반 요청 캐시는 유지한다.
4. 기존 TypeScript transpile + node:test 패턴으로 캐시·인증·검증 회귀를 검증하고 가능하면 기존 Playwright로 UI를 검증한다.

범위는 지정된 두 소스 파일, 관련 테스트와 이 디렉터리 문서다. 빌드·커밋·푸시는 수행하지 않는다.
