# 특별점검 770 조치 직접 편집

관리대장의 파란 조치·예정일 영역을 키보드로도 실행 가능한 버튼으로 바꾸고 같은 자리에서 내용과 날짜를 편집한다.

1. 기존 사진 저장, 상태 유틸리티, 디자인 시스템을 재사용한다.
2. textarea 자동 초점, 날짜 입력, 저장·취소, 저장 중 잠금과 오류 초안 보존을 구현한다.
3. 최신 JSON을 읽고 원본 항목 존재를 확인한 후 action/action_due_date만 병합한다. 갱신 반환 행으로 0건 저장을 감지한다.
4. 린트·타입체크·special-770 테스트와 기준 사본 diff를 검증한다. 실제 브라우저 검증은 조정자가 수행한다.

범위는 Special770LedgerRows.tsx와 이 계획 문서 묶음이며 기존 작업 보존, 커밋·스테이징·빌드 금지를 따른다.

추가 요청으로 SafetyInspectionForm.tsx, Special770Results.tsx, state.ts와 기존 결과 테스트까지 범위를 확장한다. 결과 진입 시 빈 부적정 항목의 조치기한일을 최신 점검일 +7일로 채우고 폼 저장에서도 보충한다. 수동 날짜는 유지하며 날짜를 지우면 기본 날짜로 복원한다. 읽기 전용에서는 보충하지 않는다.
