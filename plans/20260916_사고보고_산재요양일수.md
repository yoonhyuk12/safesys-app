# 사고보고 산재요양 예상 일수

`report_details.expectedTreatmentDays`를 선택 문자열로 추가한다. 빈 문자열은 미입력이며, 값이 있으면 0 이상 JavaScript 안전 정수 범위의 십진 숫자 문자열이다. 휴업일수와 복사하거나 서로 추정하지 않는다.

1. 기존 공통 문자열 키·검증·폼·병합 패턴을 재사용하고 회귀를 먼저 추가한다.
2. 상세화면과 HWPX 피해자 인적사항에 일 단위로 표시한다. 원본 격자·글꼴은 유지한다.
3. 1418 SQL 뒤에 1720 후속 SQL을 적용해 허용 키와 정수 검증을 확장한다. 기존 검증은 보존한다.
4. scoped tests·tsc·lint 결과를 기록하고 부모에게 브라우저·COM·독립 리뷰를 인계한다.

새 API·라이브러리 없이 로컬 공통 패턴을 재사용한다. 부모 UI 세 파일, scratch, public 양식은 수정하지 않는다. 빌드·커밋·푸시·원격 SQL·HWPX 디스크 출력은 수행하지 않는다.
