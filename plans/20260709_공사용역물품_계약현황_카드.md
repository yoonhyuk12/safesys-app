# 공사·용역·물품 계약 현황 카드 (사업현황 /business)

## 요구 (페이지 피드백)

공사 계약 현황 카드와 비슷하게, 우측에 "공사·용역·물품 계약 현황" 카드를 하나 만들어
본부별 테이블 → 지사별 테이블 → 프로젝트(사업별) 테이블로 합계 금액을 볼 수 있게 한다.

## 설계

- 새 컴포넌트 `src/components/dashboard/BusinessAllContractView.tsx`
  — `BusinessConstructionContractView`와 동일한 본부→지사→사업 드릴다운 구조.
- 테이블 컬럼: 구분(본부/지사/사업명) · 공사 · 용역 · 물품 · 합계 (모두 금액).
  본부·지사 표는 백만원, 사업 표는 천원 단위. 금액 셀은 기존 소계 대비 비중 게이지 재사용.
- 데이터 원천.
  - 공사·용역: `project_contracts` — 행 금액 = `thtm_cntrct_amt ?? tot_cntrct_amt` (기존 rowAmount 규칙).
  - 물품: `material_ledger_entries`의 `prdct_amt + fee_amt` 합 — 지급자재 계약현황 엑셀과 동일 규칙.
    `materials!inner(project_id)` 임베드 + `.in('materials.project_id', ids)` (공사감독일지 유틸의 검증된 패턴).
  - 행 원천: `getProjectsByUserBranch` 관할 프로젝트 (준공 제외) — 계약 미등록 사업도 노출.
- 카드: Dashboard 사업현황 그리드에서 공사 카드 다음(우측). `selectedBusinessCard === 'allContract'`.
  사업 행 클릭 → 계약현황 서류철(returnUrl로 복귀).
- 엑셀 다운로드·금년 구분·건수 컬럼은 요청에 없으므로 이번엔 제외 (단순성 우선).

## 컨텍스트 노트

- 물품 금액은 계약 등록이 아니라 지급자재 수불부(원장 행)에서 나온다. 계약현황 서류철의
  "물품 소계 (지급자재 수불부 확인 바랍니다)" 안내와 같은 근거. 보정·연계 행 포함 합산이
  엑셀(품대계+조달수수료 합계)과 동일한 값이 되도록 전 행을 그대로 합산한다.
- 용역 컬럼에는 재해예방기술지도 용역 계약도 포함된다 — project_contracts의 실제 용역 계약이므로 의도된 동작.
- 관할 필터는 조인 필터 재현 대신 getProjectsByUserBranch 결과 id 목록으로 `.in()` 필터
  (getMaterialCountsByUserBranch와 동일 패턴) — 중첩 2단 임베드 필터보다 검증된 방식.
- (1차 구현의 숫자 불일치 원인) 등록된 계약 행들의 금차금액 합을 쓰면 미등록 차수만큼 서류철의
  총계약금액보다 작게 나온다. 서류철 총 합계 = 차수 병합 그룹당 대표(최근 체결일)의
  tot_cntrct_amt를 1회 합산 — 이 규칙으로 교정하고 "총차" 모드로 명명.
- 연도 모드 = 서류철 연도별 컬럼과 동일하게 귀속연도(contractYear)가 일치하는 차수의
  thtm_cntrct_amt 합. 물품의 연도 귀속은 지급자재 계약현황 엑셀과 동일하게 납품기한(dlvr_deadline)
  연도. 납품기한 미상 자재는 총차에만 포함.
