# 지급자재 수불부 — 조달청 지급자재 계약건 일괄 조회

## 배경

지급자재 수불부(`/project/[id]/material-ledger`)에서 조달청 납품요구 건을 등록하려면 납품요구번호를 건마다 직접 입력해야 한다. 현장에서는 어떤 납품요구가 나갔는지 번호를 모르는 경우가 많아, 프로젝트의 수요기관 기준으로 기간 내 납품요구(관급자재) 건을 한 번에 조회하고 골라서 등록하는 기능이 필요하다.

## 사용자 요청

수불부 대시보드 상단 헤더에 "조달청 지급자재 계약건 일괄 조회" 버튼 추가.

## API 검증 결과 (2026-07-07 실호출)

- `ShoppingMallPrdctInfoService/getDlvrReqInfoList` (납품요구 목록)
  - `inqryDiv=1` + `inqryBgnDate/inqryEndDate` — **월 단위 범위만 허용** (초과 시 resultCode 07 "입력범위값 초과").
  - `dminsttNm` 필터 — **부분일치로 작동** ("한국농어촌공사 경기지역본부" 검색 시 산하 지사 건까지 포함).
  - `dminsttCd` 필터 — 정확일치로 작동하나 지사 건이 빠지므로 사용하지 않음.
  - `dlvrReqNm`(건명) 파라미터 — **서버에서 무시됨**. 건명 키워드 필터는 클라이언트에서 처리.
  - 월별 건수: 수요기관 필터 시 수십~수백 건 수준(999 numOfRows 1페이지로 대부분 커버, 페이징 가드 추가).
- 수요기관명 출처: 프로젝트의 `g2b_cntrct_no` → 기존 `/api/g2b/contract` 조회 → `dminsttNms[0]` 프리필. 없으면 직접 입력.

## 설계

1. **신규 API 라우트** `/api/g2b/dlvr-req-list`
   - 파라미터: `inst`(수요기관명), `bgn`, `end`(YYYYMMDD, 같은 달 이내).
   - 한 달 조회 + 페이징(999×3) 후 정규화된 목록 반환. 차수 dedupe는 클라이언트에서.
2. **페이지** — 대시보드 헤더 우측에 버튼(g2b.png 아이콘 + "조달청 일괄 조회").
   - 모달: 수요기관명(자동 프리필·수정 가능) + 기간(월 단위 from/to, 기본 착공월~이번 달) + 조회.
   - 클라이언트가 월 목록을 만들어 동시 3개씩 라우트 호출, 진행률 표시 ("N/M개월").
   - 결과: dlvrReqNo별 최신 차수만 dedupe, 접수일 내림차순. 건명 키워드 필터 입력 제공.
   - 이미 등록된 번호(자재/행의 dlvrReqNo)는 "등록됨" 배지 + 체크 불가.
   - 선택 건 등록: 건별로 기존 `/api/g2b/dlvr-req` 상세 조회 → 자재+발주 행 생성 (기존 단건 등록 로직을 `insertMaterialFromDlvrReq` 헬퍼로 추출해 공용).

## 완료 기준

- 버튼 → 모달 → 조회 → 선택 등록 → 인벤토리에 자재 타일 생성(연계 마크 포함)까지 동작.
- tsc/lint에서 변경 파일 신규 오류 없음.
