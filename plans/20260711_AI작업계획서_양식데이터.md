## 공통 — 인양능력·줄걸이 검토 (2-1·2-4 공용)

- 건설기계 인양능력 검토 — 중량물 총 하중(ton), 최대 양중능력(ton). 안전율 = (중량물 총 하중 / 최대 양중능력) × 100%, **100% 초과시 사용불가**.
  - 주석 ① 중량물 총 하중 = 양중물 최대무게 + 샤클·와이어·슬링벨트 등 줄걸이 총 무게. ② 최대 양중능력 = 해당 작업환경의 붐 길이 및 작업반경 상 크레인 최대 양중능력.
- 줄걸이 인양능력 검토.
  - 줄걸이 용구(체크) — 와이어로프 / 섬유로프 / 체인블럭 / 기타( ).
  - 줄걸이 규격 — D( )mm, L( )m, ( )EA, 각 안전하중 ( )ton.
  - 줄걸이 방법(체크) — 1줄걸이 / 2줄걸이 / 3줄걸이 / 4줄걸이.
  - 고리걸이용구/규격 — 훅/샤클/아이볼트 D( )in, ( )EA, 각 안전하중 ( )ton.
  - 줄걸이 절단하중(ton), 줄걸이 안전하중(ton) = 절단하중 × 줄걸이 수 ÷ (안전계수 × 장력계수).
  - 안전계수 표 — 근로자 탑승 작업 10, 줄걸이 작업 5(섬유로프 7).
  - 장력계수 표 — 0°=1, 30°=1.04, 60°=1.16, 90°=1.41, 120°=2.
  - 안전율 = (중량물 총 하중 / 줄걸이 안전하중) × 100%, 100% 초과시 사용불가.
