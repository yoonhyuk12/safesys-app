# CSI 자체 품질시험 조회 기간

실적 조회 위에 등록일 시작·종료일과 1달·2달·3달·6달·1년·2년 프리셋을 추가한다. 기본값은 오늘부터 한 달 전까지다. 사업 선택과 별도 조회 동작은 유지한다.

1. 기존 CSI 프리셋과 날짜 변환 패턴을 확인하고 말일 보정·입력 검증을 공유 헬퍼로 구현한다.
2. 날짜 변경 때 기존 결과를 초기화하고 조회 요청에 날짜를 전달한다.
3. API에서 로그인 전 유효한 날짜 쌍을 검증하고 CSI 모든 페이지에 YYYYMMDD를 전달한다.
4. 날짜·API·페이지네이션 회귀 테스트와 변경 파일 린트를 수행한다.
