# 결정과 근거

- 기존 성적서 모달의 Date.setMonth는 말일을 넘길 수 있어 자체 품질시험용 작은 순수 날짜 헬퍼를 둔다. 추가 의존성은 필요 없다.
- 날짜는 CSI 목록의 등록일 기준이다. 메인 에이전트가 실제 CSI 응답에서 startYmd=20260701, endYmd=20260731 적용을 확인했다.
- 프리셋은 선택된 종료일과 관계없이 클릭 당시 오늘을 기준으로 계산한다. 말일은 대상 월의 마지막 날짜로 보정한다.
- API 날짜는 선택 사항이나 하나라도 전달되면 유효한 YYYY-MM-DD 날짜 쌍과 시작일≤종료일을 요구한다. 사업 탐색과 상세는 기간으로 제한하지 않는다.
- 외부 검색 대신 동일 저장소의 CSI 프리셋·테스트 패턴을 재사용한다. 사용 중인 워커 도구에서 Opus 모델을 지정할 수 없어 메인의 위임 작업을 현재 워커가 수행한다.
- 날짜 헬퍼 부재와 API 검증·전달·페이지네이션 실패를 먼저 확인한 뒤 구현했다. 최종 CSI 회귀 테스트 39개와 변경 소스 4개 ESLint가 통과했다. 전체 타입 검사 및 브라우저 확인은 메인에서 수행한다.
