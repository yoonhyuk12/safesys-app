# 관급자재 수불부 — 납품요구번호 자동입력

## 배경

자재 수불부(`/project/[id]/material-ledger`)의 자재 등록 시 품명·규격·발주량을 전부 수기로 입력한다. 관급자재는 대부분 나라장터 종합쇼핑몰 납품요구로 조달되므로, 조달청 오픈API로 납품요구번호 하나만 입력하면 발주 쪽 데이터를 자동으로 채울 수 있다.

## API 검증 결과 (2026-07-06 실호출 확정)

- 엔드포인트: `https://apis.data.go.kr/1230000/at/ShoppingMallPrdctInfoService/getDlvrReqDtlInfoList`
- 조회: `inqryDiv=2&dlvrReqNo={번호}` — 번호 직접 조회 동작 확인 (예: R25TB00824197)
- 응답: 품목(prdctSno)×변경차수(dlvrReqChgOrd)별 행. 세부품명(dtilPrdctClsfcNoNm), 규격 전문(prdctIdntNoNm), 단위(prdctUnit), 단가(prdctUprc), 증감수량(incdecQty), 납품기한(dlvrTmlmtDate), 수요기관(dminsttNm), 업체(corpNm), 건명(dlvrReqNm)
- 유효 수량 = 품목별 incdecQty 합산 (차수00=최초수량, 이후 차수는 증감분)
- 제약: D-1 데이터 (당일 결재 건은 다음날 조회됨)
- 인증키: `DATA_GO_KR_API_KEY` (.env.local + Vercel, 승인 확인됨)

## 범위 (이번 작업)

1. **API 라우트** `src/app/api/g2b/dlvr-req/route.ts`
   - GET `?no={납품요구번호}` → 조달청 호출 → 품목별 정규화(차수 증감 합산) 후 반환
   - 키는 서버에서만 사용, 응답 포맷 `{ success, data, error }`
2. **자재 등록 모달 UI** (material-ledger/page.tsx)
   - 상단에 입력 방식 선택 탭: **직접 입력**(기존 그대로) / **납품요구번호**
   - 납품요구번호 모드: 번호 입력 → 조회 → 건명·수요기관·업체·품목 목록 미리보기(체크박스, 기본 전체 선택) → 등록 시 자재 1건(첫 품목의 세부품명·단위) + 선택 품목별 발주 행(name_or_spec=규격, order_qty=유효수량) 생성

## 2차 구현 (2026-07-06 완료)

3. **발주량 증감 행** — 계약수량 변경 시 ± 행 추가로 기록. 유효 발주량 = 첫 행 + 증감 행 합산 (`calcEffectiveOrderQty`)
4. **연계 컬럼 마이그레이션** — `database/20260706-0848_add_material_ledger_g2b_link.sql` (적용 확인됨)
5. **조달청 연계/동기화 버튼** — 자재 상세 헤더의 링크 버튼. 기존 수동 자재 ↔ 납품요구번호 연결, 품목·규격 매칭(자동 추천 + 수동 확정), 발주량 차이 시 증감 행 보정(선택), 초과 반입 상태면 자동 보정 차단. 이미 연계된 자재는 저장된 번호로 바로 재조회(동기화).

## 범위 밖 (후속 단계)

- 수요기관 기준 신규 납품요구 자동 감지/일괄 동기화
- 종합쇼핑몰 품목 검색(품명·규격 자동완성)
