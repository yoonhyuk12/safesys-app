## Context

- 본부 미서명은 성과총괄표의 확인자 서명이 `NULL` 또는 빈 문자열인 경우다.
- 서명 이미지 본문 전송을 피하기 위해 미서명 행만 서버에서 필터링하고 `project_id`만 별도 병렬 조회한다.
- `BusinessQualityTestView.tsx`와 `projects.ts`에는 다른 품질 현황 작업이 진행 중이므로 필요한 변경만 덧붙인다.
- `npx tsc --noEmit`, `npm run lint`, `git diff --check`가 통과했다. 린트에는 기존 경고만 남아 있다.
