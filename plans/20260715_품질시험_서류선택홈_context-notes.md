# 품질시험 결과 관리대장 서류 선택 홈 컨텍스트 노트

- 대상은 `safesys-app/src/app/project/[id]/quality-test-ledger/page.tsx`다.
- 현재 `activeTab` 기본값은 `records`라서 최초 진입 즉시 실시대장이 렌더링된다.
- 기존 세 탭 컴포넌트와 데이터 전달 구조는 변경하지 않고 페이지의 선택 상태와 내비게이션 UI만 바꾼다.
- `canSignQualityRecords` 전달은 다른 동시 작업의 기존 미커밋 변경이므로 보존한다.
- 성과총괄표 미확인 반려 건수는 선택 홈과 컴팩트 메뉴에 모두 노출한다.
- 최초 화면은 앰버 실시대장, 스카이 성과총괄표, 에메랄드 확인시험 의뢰서의 세 서류 카드로 구성한다.
- 선택 후에는 같은 아이콘과 색상을 유지하는 3분할 컴팩트 메뉴를 표시한다.
- `npx tsc --noEmit`, 대상 페이지 ESLint, `git diff --check`가 통과했다.
- 브라우저에서 최초 세 카드, 성과총괄표 진입, 컴팩트 메뉴를 통한 확인시험 의뢰서 전환을 확인했다.
- 실제 저장이나 데이터 변경은 수행하지 않았고 검증 후 원래 프로젝트의 최초 선택 화면으로 복귀했다.
