# 자재 수불부 — 조달청 연계 자재의 계약 상세 링크

## 배경

계약현황 서류철에서는 계약명 클릭 시 조달청(나라장터) 계약 상세로 이동한다 (계약현황 API가 `cntrctDtlInfoUrl` 딥링크를 반환, DB에 저장).
자재 수불부의 조달청 연계 자재(납품요구번호 연계)도 같은 방식으로 조달청 사이트에서 볼 수 있게 해달라는 피드백.

## 핵심 발견 (2026-07-08 실호출 확인)

- 납품요구 API(`getDlvrReqDtlInfoList`·`getDlvrReqInfoList`)는 **URL 필드를 반환하지 않는다**.
- 대신 응답에 연계 단가계약의 `cntrctNo`·`cntrctChgOrd`가 있다 (예: 002250779 / 04).
- 물품 계약현황 API `getCntrctInfoListThngPPSSrch` (inqryDiv=2, `dcsnCntrctNo=계약번호+차수2자리`)를 조회하면 공식 딥링크 `cntrctDtlInfoUrl`을 얻는다.
  - 예: `https://www.g2b.go.kr/link/FIUA027_01/single/?ctrtNo=002250779_1&ctrtChgOrd=04&prcmBsneSeCd=조070001&srchName=ctrtCrst&openUrl=Y`
  - `ctrtNo`의 `_1` 접미어는 규칙을 알 수 없어 **URL 자체 조합은 불가** — 반드시 API 응답 값을 쓴다.
- 속도: 납품요구 목록(inqryDiv=2, 번호 지정) ~2.8초 + 물품 계약 조회 ~0.2초 → 클릭 시 즉석 조회 가능.

## 구현

1. 새 API 라우트 `/api/g2b/dlvr-req-url?no=납품요구번호`
   - ① `getDlvrReqInfoList`(inqryDiv=2)로 최신 차수 행의 `cntrctNo`·`cntrctChgOrd` 획득.
   - ② `getCntrctInfoListThngPPSSrch`로 `cntrctDtlInfoUrl` 획득 (실패 시 차수 00으로 1회 재시도).
   - g2b.go.kr 홈만 가리키는 URL은 무효 처리 (계약현황 서류철의 `isDetailUrl`과 동일 기준).
2. 자재 수불부 상세 헤더 — `dlvrReqNo` 연계 자재의 자재명을 링크(파란색 `#7ec8ff`+ExternalLink)로 렌더.
   - 클릭 시 빈 새 창을 먼저 열고(팝업 차단 방지) URL 조회 후 이동. 실패 시 창 닫고 alert.
   - 자재별 해석 URL은 ref 캐시에 보관해 재클릭 시 즉시 연다.

## 컨텍스트 노트

- DB 저장(마이그레이션) 없이 클릭 시 즉석 해석을 택했다 — 기존 연계 건에도 즉시 동작하고, 계약 차수 변경에도 항상 최신 URL을 얻는다.
- 목록 뷰(인벤토리 그리드)의 자재 칸은 클릭=상세 진입이므로 외부 링크는 상세 헤더에만 둔다.
