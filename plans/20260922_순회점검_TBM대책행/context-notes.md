# 컨텍스트 노트 — 순회점검 TBM 대책 3행

- 양식 표1 높이 합 56291 = 2751 + 1045 + 2825 + 항목 행 합 + 사진 행. 서명 떠 있는 그림 y 좌표가 이 값을 상수로 쓰므로 표 높이는 바꾸지 않는다. 13×2600 + 15870 = 49670 = 10×3092 + 18750.
- 항목 셀 글자는 12pt(charPr 19 height 1200), 줄 전진 1920, 셀 상하 여백 141. 한 줄 행 최소 2202이므로 2600이면 한 줄은 안전하고 두 줄이면 행이 자란다(현행도 동일).
- AI 라우트는 정확히 10건을 강제 파싱한다. TBM 대책 3행은 클라이언트가 사용자 권한으로 조회해 붙이므로 라우트를 건드리지 않는다.
- `loadTbmWorkForDate` 테스트가 `queries.length === 2`를 단언하므로 대책 조회는 별도 함수로 둔다.
- 픽스처 `tests/fixtures/patrol-ledger-db.mjs`는 마이그레이션을 순서대로 exec한다. 새 SQL도 같은 방식으로 뒤에 붙인다.
- 한글 2022 실행 파일 `C:\Program Files (x86)\Hnc\Office 2022\HOffice120\Bin\Hwp.exe`. PDF 변환은 COM `HWPFrame.HwpObject`.
