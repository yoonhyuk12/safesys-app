# 법적이행확인 현황 카드 + 분기 엑셀 내보내기 구현 계획

작성일 2026-07-14. 선행: plans/20260714_법적이행확인_서류철.md (서류철·테이블·2분기 데이터 적재 완료).

## 목표

/safe 안전현황에 "법적이행확인" 카드를 추가하고, 본부→지사→프로젝트 3단 드릴다운 현황 테이블을 제공한다. 각 테이블 우측 상단에서 연도·분기를 골라 원본 「안전활동점검표」 엑셀과 동일한 2시트 양식으로 현재 범위의 데이터를 다운로드할 수 있게 한다.

3. **드릴다운 View** — `src/components/dashboard/LegalComplianceView.tsx` (자체 데이터 조회로 Dashboard 수정 최소화. BusinessConstructionContractView의 initialHq/initialBranch prop 패턴 참고)
   - 연도·분기 선택(기본 = 데이터가 있는 최신 분기, 없으면 현재 분기).

   - 본부 레벨: 본부별 행 — 프로젝트 수 / 점검표 제출 프로젝트 수 / 점검표 건수(공종행) / 도급사업 건수 / 미이행 항목 수. 행 클릭 → 지사 레벨.
   - 지사 레벨: 해당 본부 지사별 동일 컬럼 + 소계행(SafetyManagerView 관례). 행 클릭 → 프로젝트 레벨.
   - 프로젝트 레벨: 프로젝트별 행 — 프로젝트명 / 공종(점검표별) / 도급 여부 / 미이행 수 / 수정일. 행 클릭 → `/project/{id}/legal-compliance`.
   - 각 레벨 우측 상단: 연도·분기 select + "엑셀 다운로드" 버튼(현재 범위: 전체/해당 본부/해당 지사).
   - 스코프 게이팅: Dashboard의 selectedSafetyHq 초기화·canSeeAllHq 관례를 따르므로 View는 받은 initialHq/initialBranch 범위만 조회.
4. **엑셀 내보내기** — `src/lib/excel/legal-compliance-export.ts` (exceljs ^4.4.0, inspection-checklist-export.ts의 setCell/mergeSet/borderRange/downloadWorkbook 헬퍼 패턴 복제)
   - 시트1 "발주자 안전활동 점검표": 원본 열 구조(B~BS) 재현 — 제목(□ 건설현장 발주자의 안전활동 점검표), 3~4단 병합 헤더(사업개요 B~S / 안전활동 기본사항 T~AK / 안전활동 세부사항 AL~BQ / 도급사업 BR / 비고 BS와 하위 필드 헤더), 데이터 행.
   - 시트2 "도급사업 안전활동 점검표": 사업개요 B~S + 의무사항 9열(T~AB) + 비고 AC. `isContractedWork==='여'`인 레코드만.
   - 값 변환: 날짜 `YYYY-MM-DD`→`yy.mm.dd`, 연월 `YYYY-MM`→`yy.mm`, 위험공종 targetWorks(①~⑨)→AN~AV 열에 `○`, 금액은 숫자(천단위 서식 `#,##0`), 여/부 그대로, 미기재는 빈 칸.
   - 파일명 `안전활동점검표_{범위}_{연도}년{분기}분기.xlsx` (범위=전체/본부명/지사명).

## 미이행(부) 카운트 규칙 (View·엑셀 공용 유틸로 constants.ts 또는 export 파일에 배치)
