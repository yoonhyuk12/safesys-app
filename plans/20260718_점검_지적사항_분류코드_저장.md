# 점검 지적사항 분류코드 저장 계획

## 목표

- 정기점검과 본부불시점검의 사진 지적 원문에 고정 분류 코드를 자동 저장한다.
- 과거 지적을 확정 규칙으로 백필한다.
- 사고 통계 화면은 저장된 코드를 우선 집계하고, 미적용 환경에서는 기존 분류기를 임시 fallback으로 사용한다.

## 구현 순서

1. `safety_inspection_results`와 `headquarters_inspections`에 분류 컬럼을 추가한다.
2. PostgreSQL 분류 함수와 입력·수정 트리거를 추가하고 기존 데이터를 백필한다.
3. TypeScript 분류 규칙에 사용자 확정 재분류와 `F20_WORK_METHOD`를 반영한다.
4. 사고 분석 조회에서 저장된 분류 코드를 읽어 통계에 사용한다.
5. 타입 검사, 린트, SQL 정적 검토, 로그인 화면 통계를 검증한다.

## 성공 기준

- 신규 정기점검 결과행 저장 시 `finding_category_code`가 자동 기록된다.
- 신규 본부불시점검 저장 시 `issue1_category_code`, `issue2_category_code`가 자동 기록된다.
- 메타·상태 문구는 분류 코드가 `NULL`로 저장되어 통계에서 제외된다.
- 기존 `기타 안전관리` 91건은 사용자 결정대로 제외 29건, 재분류 60건, F19 유지 2건으로 정리된다.
- 사고 분석의 지적사항 순위가 저장 코드를 우선 사용한다.
