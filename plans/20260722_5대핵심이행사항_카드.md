# 5대 핵심이행사항 이행 현황 카드 (안전현황)

## 목적

`/safe` 안전현황 카드 그리드에 "5대 핵심이행사항" 카드를 추가한다. 카드 클릭 시 관할 프로젝트별로 본부 불시점검에서 평가한 5대 핵심 안전수칙(①~⑤ 카테고리) 이행 등급을 한눈에 보는 현황 뷰를 연다.

## 데이터 출처

- 테이블 `headquarters_inspections`의 `five_key_items` JSONB — 5개 카테고리 17개 항목, 항목별 `grade`(`'1'`~`'5'`, `'N/A'`, `''`)와 `remarks`, 일부 항목은 `count`(횟수).
- 등급 라벨. 1 매우우수, 2 우수, 3 보통, 4 미흡, 5 불이행, N/A 해당없음.
- 기준 정의는 `src/app/project/[id]/headquarters-inspection/page.tsx`의 `DEFAULT_FIVE_KEY_ITEMS`(94~117행)와 `FiveKeyItem` 타입(69~78행) 참조.
- 주의. 레거시 점검 행은 `five_key_items`가 비어 있을 수 있다. **빈 배열이나 모든 grade가 `''`인 행은 "미점검"으로 취급하고, 기본값(grade '1')으로 채워 넣지 않는다** (normalizeFiveKeyItems의 기본 채움을 흉내 내면 허위 "매우우수"가 된다).

## 화면 설계

기존 패턴 재사용. 카드·라우트·뷰 구조는 **법적이행확인 카드**(자체 데이터 로딩 뷰 + thin 라우트 페이지)를 그대로 따른다.

1. 카드 — `Dashboard.tsx` 카드 그리드에서 법적이행확인 카드(3997행) 다음, 사고 통계 분석 카드(4022행) 앞. 제목 "5대 핵심이행사항", 본문 "현황 / 확인하기", 아이콘 `ShieldCheck`(lucide), emerald 색 계열. 클릭 시 지사 선택 여부에 따라 `/safe/five-key` 또는 `/safe/branch/{지사}/five-key`로 이동.
2. 라우트 — `src/app/safe/five-key/page.tsx`, `src/app/safe/branch/[branch]/five-key/page.tsx`. 기존 `src/app/safe/headquarters/page.tsx`와 동일한 thin `<Dashboard />` 래퍼.
3. 경로 동기화 — `Dashboard.tsx` 516행·528행의 카드명 목록에 `'five-key'` 추가. (789행 정규식·분기 sessionStorage 로직은 건드리지 않는다.)
4. 뷰 — 새 컴포넌트 `src/components/dashboard/FiveKeyStatusView.tsx`. `selectedSafetyCard === 'five-key'`일 때 렌더.

### FiveKeyStatusView 상세

Props 계약 (두 워커가 병렬 작업하므로 고정. 변경 금지).

```ts
interface FiveKeyStatusViewProps {
  initialHq: string | null
  initialBranch: string | null
  onBack: () => void
}
```

- 데이터 로딩(자체). `getProjectsByUserBranch(userProfile)`로 관할 프로젝트 목록을 얻고(준공 프로젝트 제외 — `LegalComplianceView.tsx`의 `isCompleted` 판별 참고), 해당 프로젝트들의 `headquarters_inspections`를 supabase로 직접 조회한다. select는 `id, project_id, inspection_date, five_key_items`만.
- 프로젝트별 대표 점검 = grade가 하나라도 입력된(`'1'`~`'5'` 또는 `'N/A'`) 행 중 `inspection_date` 최신 1건.
- 카테고리 대표 등급 = 해당 카테고리 항목들의 grade 중 **최악값**(숫자 최대). 전부 N/A면 "해당없음", 등급 입력이 없으면 "-"(미점검). 횟수 항목(`count`)은 등급 집계에서 제외.
- 상단 요약 3칸(컴팩트). 대상 프로젝트 수 / 점검 실시 프로젝트 수 / 미흡·불이행(4·5등급) 보유 프로젝트 수.
- 필터. 본부 select(`HEADQUARTERS_OPTIONS`) + 지사 select(`BRANCH_OPTIONS[본부]`), 초기값 `initialHq`/`initialBranch`. 발주청 소속 범위 제한은 `getProjectsByUserBranch`가 이미 처리.
- 테이블 컬럼. 지사 · 프로젝트명 · 최근 점검일 · ①TBM · ②신규근로자 · ③건설기계 · ④보호구 · ⑤표지 (각 셀은 등급 라벨 뱃지). 미점검 프로젝트도 행으로 표시(등급 "-").
- 등급 뱃지 색. 매우우수 blue, 우수 green, 보통 gray, 미흡 amber, 불이행 red, 해당없음 연회색.
- 행 클릭 시 `/project/{id}/headquarters-inspection?fromBranch={지사}`로 이동.
- 디자인. 흰 배경, 내용물 맞춤 폭, 컴팩트(사용자 선호). 전반 톤은 `LegalComplianceView.tsx` 참고.
