# 장비 점검 항목 문구 수정

- 요청. 점검 항목 내용을 수정할 수 있는 입력 UI를 표시한다.
- 구현. 원본 카탈로그를 기본값으로 사용하고 수정 문구를 해당 점검의 answers에 저장한다. 항목 ID·분류·순서는 유지한다.
- 검증. 빈 문구 제출 차단, 서명 무효화, 변경 문구 저장·상세·HWPX 전달, 장비 변경 시 초기화를 확인한다.
- 사용자가 새 점검과 제출된 내역 모두 편집을 요청했다. 제출 수정은 작성자 본인에게 허용하고, SQL은 파일을 제공하여 사용자가 직접 실행한다.
- 작업 체크리스트와 판단 기록은 20260915_equipment_item_edit 디렉터리에 둔다.
