# 서버 이전 타당성 조사 (CSAP 인증 클라우드)

> 2026-08-02 조사. 발주처·기관의 요구로 서버 이전 가능성이 제기되어, 비용·기간·난이도를 사전 산정한 문서다. **이전을 결정하거나 착수한 것은 아니다.**

## 배경

발주처·기관이 서버 이전을 요구했다. 현재 SafeSys는 Supabase(AWS 서울 리전) + Vercel 조합이며, Vercel은 국가공공기관 민간클라우드 도입 가능목록(CSAP)에 없다.

## 결론 요약

1. **CSAP 목록에 Supabase 같은 BaaS는 없다.** 현실적 해법은 CSAP 인증 IaaS 위에 **Supabase 오픈소스를 자체호스팅**하는 것이다. 이래야 RLS 158개·RPC 6개·스토리지 호출 59곳이 그대로 살아난다.
2. **월 비용은 18만~58만원**이다. 요구 수준에 따라 다르다. 현재(약 6만원) 대비 3~9배 증가.
3. **초기 비용은 0원(직접, 3~5주)에서 8,100만원(외주 + CSAP SaaS 인증)까지** 갈린다.
4. **가장 먼저 할 일은 서버 이전이 아니라 발주처 요구 수준 확인이다.** 요구가 "국내 저장"이면 **이미 충족**이고 이전이 불필요하다.
5. 2027년 7월 CSAP 제도가 국정원 단일 검증체계로 개편된다. 인증 취득 타이밍에 영향이 있다.

## CSAP 제도 정리

### 규제 구조

- 근거는 「클라우드컴퓨팅 발전 및 이용자 보호에 관한 법률」 제23조의2다. **의무 주체는 "국가기관등"이며 사업자가 아니다.**
- 따라서 Vercel 사용 자체가 SafeSys의 위법이 되는 구조는 아니다. 사업자에게 오는 결과는 "위법"이 아니라 **"조달 자격 없음"** 이다.
- 다만 발주청 486명(전체의 45%)이 이용 중이고 공사감독일지 같은 공적 기록이 쌓이고 있어, 기관이 정식 도입한 형태라면 해당 기관 측에 지침 위반 소지가 생긴다.

## 데이터 이전 난이도 (실측 기반)

### 쉬운 것

- **Postgres 314MB** — `pg_dump` / `psql` 한 번씩. RLS 158개·함수 23개·트리거 17개가 전부 덤프에 포함된다.
- **Auth 1,079명** — 자체호스팅도 **같은 GoTrue**를 쓴다. `auth.users`를 복사하면 bcrypt 해시가 그대로 검증되어 **비밀번호 재설정이 불필요**하다. 이것이 Supabase 자체호스팅을 택하는 결정적 이유다. 세션 토큰만 만료되어 1회 재로그인은 필요하다.
- **Storage 10GB / 46,922개** — Supabase가 S3 호환 엔드포인트를 제공하므로 `rclone sync`로 복사된다. 용량보다 객체 개수가 병목이며 30분~2시간을 본다.

### 실제로 어려운 것 — Vercel 탈출

작업량으로 보면 **데이터 이전이 10%, 환경 구축이 90%**다. Vercel이 무상 제공하던 HTTPS 인증서 자동 갱신, 이미지 최적화, CDN, 자동 롤백, 프리뷰 배포, 빌드 파이프라인이 전부 직접 구성 대상이 된다.

USB 등 이동식 매체는 쓰지 않는다. 클라우드 간 직접 전송이 빠르고, 근로자 신분증 사진 115건이 담긴 매체의 물리적 반출은 개인정보보호법상 별도 관리 대상이 되어 오히려 위험하다.

### 컷오버 순서

1. 새 서버 구축 (2~3주) — 서비스가 도는 상태로 완성
2. 1차 복사 + **리허설** — 실제 데이터로 검증
3. 점검 공지 — 새벽 2~4시간 중단 예고
4. 서비스 중단 → 증분 복사

6. DNS 전환 → 검증 → 재개
7. 기존 환경 1~2주 유지 (롤백 대비)

실제 중단 시간은 2~4시간이다.

## Vercel 계속 사용의 법적 검토

### CSAP 관점

의무 주체가 공공기관이므로 사업자의 위법이 성립하는 구조는 아니다. 결과는 "조달 자격 없음"이다. 다만 발주청 486명이 이용 중이고 공사감독일지 같은 공적 기록이 쌓이는 형태라, 기관 정식 도입이라면 해당 기관 측 지침 위반 소지가 있고 감사 지적 가능성도 있다.

### 개인정보보호법 관점 (더 시급함)

이쪽은 **사업자에게 직접 적용**된다.

- `workers.id_card_url` **115건이 근로자 신분증 사진**이다. 서명·성명도 함께 처리한다.
- 제26조 — 처리위탁 시 개인정보처리방침에 **수탁자(Supabase, Vercel) 공개 의무**가 있다.
- 제28조의8 — 국외이전. **DB는 AWS 서울 리전이라 저장 위치는 국내**이나, Vercel은 미국 법인이고 엣지 네트워크 경유 가능성이 있어 고지·동의 요건 검토가 필요하다.

CSAP는 "자격 없음"이지만 개인정보보호법은 **과태료** 사안이다. 우선순위는 이쪽이 앞선다.

> 위 해석은 공개 자료에 근거한 정리이며 법률 자문이 아니다.

## 제도 변경 — 2027년 7월

- **2026년 상반기** — 국가 정보보안 기본지침·클라우드컴퓨팅 보안 가이드라인 개정
- **2027년 7월** — 국정원 단일 검증체계로 공식 전환 (현 CSAP 체계 종료, 1년 유예 포함)
- SaaS 79개 항목 중 **별표 1~3은 ISMS로 통합되어 자율인증**, 별표 4(공공기관 추가요건)만 국정원 검증 대상 → **인증 부담 감소**
- 새 국가망보안체계(N2SF)의 기밀(C)·민감(S)·공개(O) 3등급과 정합성 추진
- **2027년 6월까지 취득한 CSAP는 유효기간 5년을 그대로 인정**

즉 지금 2,600만원을 써서 2032년까지 확보할지, 2027년 7월 이후 완화된 제도로 갈지의 선택이 생긴다.

## 다음 단계

### 1순위 — 발주처 요구 수준 확인 (서버 이전보다 먼저)

요구 수준에 따라 비용이 0원부터 6,200만원까지 갈린다.

| 요구 수준 | 대응 | 비용 | 기간 |
|---|---|---:|---|
| ① 데이터를 국내에 저장 | **이미 충족 가능성** (AWS 서울) | 0원 | — |
| ② CSAP 인증 클라우드 사용 | IaaS 이전 (구성 A) | 월 18만원 | 2~3주 |
| ③ 서비스의 CSAP SaaS 인증 | 이전 + 인증 취득 | 초기 2,600만원+ / 월 58만원 | 6개월+ |
| ④ 국정원 보안성 검토 | 별도 절차 | 별도 산정 | 6개월+ |

**발주처 질의 항목**

1. 요구 근거가 무엇인가 (내부 지침 / 국가 정보보안 기본지침 / 계약 특수조건)
2. 요구 수준이 위 ①~④ 중 무엇인가
3. 기한은 언제인가
4. 무엇을 제출하면 충족으로 인정되는가 (확인서 / 인증서 사본 / 서버 위치 증빙)
5. 2027년 7월 제도 개편을 감안한 유예가 가능한가

담당자도 IaaS와 SaaS 인증을 구분하지 못하는 경우가 흔하므로 구체적으로 물어야 한다. **요구사항은 공문·메일 등 문서로 받아둔다.** 구두 요구는 이전 후 범위가 늘어날 위험이 있다.

### 2순위 — 답변과 무관하게 손해가 아닌 사전 작업

- **사진 URL 39,099행을 상대 경로로 정리** — 어느 경로로 가든 필요하고, 이전 당일 최대 리스크를 제거한다. **효과가 가장 크다.**
- **Edge Function 1개를 API 라우트로 흡수** — 반나절. 새 서버에서 해당 부품을 세우지 않아도 된다.
- **NHN Cloud 공공기관용 계정 개설** — 무료이며 사용량 과금이라 개설 비용이 0원이다.

서버 실제 생성과 이전 착수는 발주처 답변 이후로 한다.
