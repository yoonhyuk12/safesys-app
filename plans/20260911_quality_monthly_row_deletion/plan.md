# 품질 월례보고서 행 삭제 유지.

행 변경마다 실시대장에 있는 항목을 다시 추가하고, 저장된 보고서 조회 시 전월 행을 다시 이월하는 동작 때문에 삭제가 취소된다.

1. 기존 node:test 방식으로 삭제 직후·저장 후 조회 회귀 테스트를 작성하고 실패를 확인한다.
2. 새 보고서 생성·보고 연월 변경 때만 누락된 실시대장 행을 추가한다. 기존 보고서 조회와 일반 편집은 현재 행 구성을 유지하며 집계한다.
3. 저장된 보고서 간 누계 연결은 일치하는 행만 갱신한다.
4. 관련 테스트·린트·타입 검사와 diff 검토를 수행한다.

DB 스키마 변경이나 새 라이브러리는 필요하지 않다. 커밋·배포는 담당 메인 에이전트가 판단한다.
