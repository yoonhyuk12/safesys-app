# TBM 투입인원 총원 자동계산 + 수정 가능

작성일: 2026-07-01

## 배경 / 문제

`/project/[id]/tbm-submission` 모달의 "투입인원" 칸은 자유 텍스트 textarea다. 현장 담당자가 직종·숫자를 비정형으로 적어, 금일 투입 인원의 "숫자"를 집계·정리하기 어렵다.

### 실제 데이터 실태 (tbm_submissions, 총 19,137건)

- 약 70%(13,407건)가 여러 줄 직종별 내역, 67%가 `명` 포함, 순수 숫자는 1.4%(259건)뿐.
- 형식 제각각: `작업반장 1명` / `작업반장1명` / `보통인부2` / `3인 1조` / `- 보통인부 1명` / `. 직원4명` / `ㅡ현장소장1명, 전공1명...` 등.
- `#NAME?` 45건(엑셀 오류 유입), `0`·`없음`·`-없음` 무작업 표기 혼재.
- 현재 총원 집계는 `src/lib/chat/tbm-personnel.ts`의 `parsePersonnelCount` 정규식 휴리스틱으로 추정 중 — 비정형/비인원 숫자에 취약.

## 결정 사항 (사용자 확정)

- 입력 방식: **텍스트 내역 유지 + 총원 숫자칸 추가**.
- 총원칸: **자동 계산 + 사용자 수정 가능**(수정 시 자동계산 중단, ↻자동 버튼으로 복귀).
- 저장: **신규 숫자 컬럼 `personnel_total_count`(integer, nullable)** 추가. 기존 `personnel_count`(text) 그대로 유지.

### 왜 이렇게 했나 (Context Notes)

- 자동 계산은 자유 텍스트 휴리스틱이라 `작업반장 1명 (2공구)`처럼 비인원 숫자가 섞이면 틀린다. 그래서 자동값을 기본으로 채우되 수정 가능으로 둬야 한다.
- 수정한 값을 보존하려면 저장처가 필요 → 기존 텍스트 컬럼에는 내역이 들어가므로 숫자 전용 컬럼 신설이 필요.
- 기존 19,137건과의 호환: 레거시 행은 `personnel_total_count`가 NULL이므로 편집 시 텍스트에서 자동 계산해 채운다.

## 선행 작업 (사용자가 Supabase 콘솔에서 실행, MCP는 읽기전용)

```sql
ALTER TABLE tbm_submissions
  ADD COLUMN IF NOT EXISTS personnel_total_count integer;

COMMENT ON COLUMN tbm_submissions.personnel_total_count
  IS '금일 총 투입인원(명). 내역(personnel_count)에서 자동 합산하되 사용자가 수정 가능.';
```

## 추가 수정: 합산 휴리스틱 보강 (`src/lib/chat/tbm-personnel.ts`)

문제: `총원 5명 / 보통인부 2명`처럼 총인원이 선언된 줄이 있으면 기존 파서가 5+2=7로 중복 합산.

수정: `parsePersonnelCount`가 `총원/총인원/총인력/총계/합계/전체/총 N명` 선언 줄을 먼저 탐지해 그 값을 우선 사용하고, 없을 때만 직종별 합산으로 폴백. `총괄`·`전공`·`합판` 등은 숫자가 인접해야 매칭되어 오인하지 않음. 폼 자동계산과 챗봇 집계가 같은 함수를 공유하므로 양쪽 모두 개선됨.

검증: 사용자 케이스 포함 15개 케이스 통과(`scratchpad/parse-test.mjs`).

## 추가 수정 2: 파서 보강 — 시각·팀순번 제거 (`tbm-personnel.ts`)

`1팀투입 07시30분`의 `1·07·30`을 인원으로 오합산하던 문제. 시각(`07시30분`, `08:30`)·팀순번(`1팀`)을 제거 후 합산. 라이브 폼·챗봇·백필 모두 개선. 테스트 21/21 통과.

## 추가 수정 3: 작업없음 → 0 (폼)

작업없음(noWorkCheck) 체크 시 저장 페이로드에서 `personnel_total_count: 0` 강제. 작업이 없으면 총원 0.

## 백필 결과 (scratch/backfill-personnel-total.mjs, 앱과 동일 파서 사용)

- 컬럼 `personnel_total_count` 추가 후 19,137건 중 **18,979건 채움 / 158건 NULL**.
  - 1차(휴리스틱 합산): 17,972건. 선언총원은 크기 무관 신뢰, 비선언은 60명 초과 시 NULL(중복합산·잡음 방지, 최댓값 71).
  - 2차(작업없음/공란 → 0): 1,007건.
- NULL 158건 = 인원칸 공란(작업기록만 있음) 100 + 비정형(RC팀 소계중복 등) 58. → 제출 편집 시 자동계산 또는 수동 입력으로 채움.
- 참고: 작업없음인데 인원이 적힌 31건은 양수값 유지(실제 인원 데이터라 0으로 지우지 않음).
