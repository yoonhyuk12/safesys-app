# 사고보고 한글 출력 중복 보정

저장된 사고내용에 작업내용·사고원인·피해현황·귀책사유가 라벨 블록으로 포함되면 HWPX가 전용 필드와 함께 두 번 출력한다. 기존 저장 데이터는 변경하지 않고 다시 다운로드할 때 중복을 보정한다.

1. 명시 라벨 블록과 전용 필드 전체가 정확히 같은 경우에만 사고내용의 중복 블록을 제거하는 순수 함수를 만든다. 개행과 바깥 공백만 비교 정규화하고 부분 일치·추정·요약은 사용하지 않는다.
   피해현황은 실측된 목록 형식 차이에 한해 줄앞 글머리와 개행/쉼표+공백으로 나눈 2개 이상 항목의 전체 텍스트와 순서가 같을 때도 정리한다. 내부 공백·추가 내용·순서 차이는 보존한다.
2. 출력과 AI 추출 정규화에 같은 함수를 적용하고 추출 프롬프트에 하위 항목 분리 규칙을 명시한다. 불일치·누락 필드·일반 서술의 정보는 모두 보존한다.
3. 합성 회귀 테스트 RED/GREEN, 타입검사, 관련 린트를 수행한다. HWPX 패키지 생성·COM·실제 파일 재출력 검증은 coordinator가 독점한다.

사용자 증상이 텍스트 중복으로 확정되어 페이지 분할기·글꼴·원본 양식은 변경하지 않는다. DB 쓰기, 원본 다운로드 파일 수정, 기존 PDF 추출·저장 오류 변경, build/commit/push는 금지한다.
