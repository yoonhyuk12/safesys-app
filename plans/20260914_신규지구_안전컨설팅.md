# 신규지구 안전컨설팅 구현 계획

**Goal.** 신규 착공지구에 대한 본부 컨설팅 실적을 연도별로 파악한다.
**Architecture.** Dashboard 안전카드에 독립 뷰를 추가한다. 기존 관할 프로젝트 조회와 대표 계약·본부불시점검 테이블을 읽고 순수 집계 함수로 본부→지사→프로젝트 표를 만든다.
**Tech Stack.** Next.js 15, React 19, Supabase, 기존 date-fns, node:test.
**Spec.** 사용자 요청 및 이 계획의 집계 규칙.

## 집계 규칙

- 카드명은 신규지구 안전컨설팅. 연도는 기본 올해이며 대표 계약 시작 연도로 신규지구를 선정한다. 사용자가 착공연도 기준을 명시 확정했다.
- 지사 표는 사용자의 추가 지시에 따라 `BRANCH_OPTIONS[본부]`에 정의된 기존 순서를 유지한다. 미등재 지사는 뒤에 표시한다.
- 사용자 추가 지시에 따라 점검 건수 0은 표·소계·상단 요약에서 `-`로 표시한다. 내부 집계의 0은 유지한다.
- 대표 계약 기간은 계약현황에서 표시하는 대표 그룹의 최초 시작일 기준이다. 최신 연차의 시작일만 쓰면 기존 지구가 신규로 오분류되므로 계약현황의 대표 지정·기본 대표·그룹 규칙을 확인한다.
- 기본 3개월, 위/아래 버튼으로 1개월씩 증감하며 최소 1개월. 30일 환산 대신 달력상 개월로 계산한다. 시작일과 만료일 모두 포함, 연말 시작이면 다음 해 실적도 포함한다.
- 신규지구 전체를 분모로 삼고 기간 내 점검한 고유 지구 수와 점검 건수를 구별한다. 미점검 지구도 프로젝트 표에 남긴다. 실시율은 점검 지구 수/신규지구 수이며 소계에서 원수를 합산해 다시 계산한다.
- 대표 시작일 미확인 프로젝트는 집계 제외 사실을 표시하고 임의의 착공일로 대체하지 않는다. 준공 여부·현재 분기로 과거 신규지구를 제외하지 않는다.
- 프로젝트 표는 지구명, 대표 계약 시작일, 인정 기한, 점검일, 점검 건수, 점검 여부를 보여준다. 각 수준에 소계 행을 둔다.
- 기존 인증과 조직 범위를 보존하고 조회 페이지네이션·오류·비동기 전환을 처리한다. 스키마 변경·새 패키지·배포·프로덕션 빌드는 필요 없다.
