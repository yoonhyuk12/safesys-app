# 성과총괄표 HWPX — 컨텍스트 노트

## 결정

- 접근. 템플릿 치환이 아니라 코드 조립. 로컬에 채워 넣을 양식 hwpx가 없고, 행 수가 동적(실적 표)이라 TBM 방식과 맞음.
- 엑셀 유지. 사용자 피드백은 HWPX "받을 수 있게"이므로 엑셀을 대체하지 않고 병행.
- 열 그리드. A4 본문 폭 51024를 엑셀 9열 비율로 분배. 셀 폭 = colSpan 구간의 열폭 합.
- 표 헤더. TBM 셀 빌더는 `rowSpan=1` 고정이므로, 2단 헤더는 한 줄 헤더(계획/실시/합격/…)로 단순화하거나 두 행에 라벨 중복. 엑셀 2단과 시각이 약간 달라도 데이터 열 구성은 동일.
- 서명 좌표. 본문 높이가 가변이라, 조립 중 추정 높이(문단 줄고·표 행 높이 합)를 누적해 PAPER 좌표를 계산. 서명 크기 대략 70×26mm 수준이 아니라 HWPUNIT 약 3500×1400 내외로 `(인)` 영역에 맞춤.

## 함정 (hwpx-authoring)

- mimetype STORE 첫 항목
- pic 전체 자식 순서 (TBM `buildPicXml` 복사)
- 서명 `textWrap=IN_FRONT_OF_TEXT` + PAPER 절대좌표
- 셀 폭 ↔ colAddr/colSpan 일치

## 구현 후기

- Worker 구현. 신규 export + UI 버튼 2곳. Hwp.exe 크래시 테스트 ALIVE.
- 서명 Y는 문단/표 높이 추정 누적이라 실측과 수 mm 어긋날 수 있음. 사용자 피드백 시 정답 hwpx 좌표 보정.
- 서명 floating 앵커는 확인시험 표 문단에 부착 (PAPER 절대좌표).
