# 품질 월례보고서 동일 공종 물량 동기화

## 목표

품질 월례보고서에서 한 공종의 첫 시험행에 연간 시공계획·이번 달 시공·다음 달 시공계획 물량을 입력하면, 실시대장 연동 등으로 추가된 같은 공종의 시험행에도 같은 물량과 단위가 즉시 반영되게 한다.

## 구현 계획

1. 기존 행 입력 전파 규칙과 공종 비교 방식을 확인한다.
2. 첫 번째 동일 공종 행의 물량 필드 변경을 같은 공종의 모든 행에 불변 업데이트로 전파한다.
3. 기존 콘크리트·토공·강관류 전파 및 횟수 자동 계산을 유지하는지 diff와 정적 검사로 확인한다.

## 완료 기준

- 같은 공종의 첫 시험행에서 연간 시공계획·이번 달 시공·다음 달 시공계획 물량을 수정하면 아래 추가 시험행의 해당 물량이 동일해진다.
- 다른 공종의 행에는 값이 전파되지 않는다.
- 빈 공종 행에서는 전파되지 않는다.
- TypeScript 타입 검사와 ESLint 검사가 통과한다.
