# 품질시험 결과 관리대장 서류 선택 홈

## 목표

품질시험 결과 관리대장에 처음 들어오면 특정 탭 내용을 바로 표시하지 않고, 실시대장·성과총괄표·확인시험 의뢰서 중 하나를 고르는 중앙 서류 선택 화면을 표시한다. 문서를 선택한 뒤에는 같은 세 문서를 컴팩트한 전환 메뉴로 유지하고 기존 탭 내용을 보여준다.

## 구현 범위

1. 최초 활성 문서를 선택되지 않은 상태로 변경한다.
2. 세 문서를 A4 서류 느낌의 아이콘 카드로 표현한다.
3. 문서 설명과 서식명을 카드에 표시한다.
4. 문서 선택 후 기존 탭 콘텐츠를 그대로 렌더링한다.
5. 선택 후 전환 메뉴는 카드의 색상과 아이콘을 유지한 컴팩트 형태로 표시한다.
6. 기존 권한·반려 알림·뒤로가기·데이터 로드 흐름을 보존한다.

## 검증 기준

- 최초 진입 시 세 문서 카드만 표시되고 실시대장 내용은 보이지 않는다.
- 각 문서 카드를 선택하면 해당 콘텐츠와 컴팩트 전환 메뉴가 표시된다.
- 컴팩트 메뉴로 세 문서 사이를 전환할 수 있다.
- 성과총괄표 미확인 반려 건수는 초기 카드와 컴팩트 메뉴 모두에 표시된다.
- 타입 검사, 대상 파일 린트, 브라우저 수동 시나리오가 통과한다.
