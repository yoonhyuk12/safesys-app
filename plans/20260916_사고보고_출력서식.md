# 사고보고 한글 출력 서식.

사고보고 본문을 1쪽, 사진대지를 2쪽에 배치한다. 본문 글꼴을 통일하고 자동 줄바꿈과 직접 입력한 줄바꿈의 이어지는 위치를 맞춘다. 기본 서식에서 줄간격·장평·자간을 차례로 조절하며 필요한 경우 본문 글자 크기를 12pt까지 균일하게 줄인다. 내용을 삭제하거나 요약하지 않으며 가독성 하한에서도 넘치면 분량 조정 안내를 표시한다.
