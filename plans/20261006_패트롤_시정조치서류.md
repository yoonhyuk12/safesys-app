# 패트롤 시정조치 서류

현재 분기·조직 범위의 모든 점검과 개별 점검에서 요구서·결과보고서·계획서를 다운로드한다. 제공된 원본 HWPX를 그대로 복사해 셀 내용만 채운다. 여러 건은 개별 HWPX를 ZIP 한 개로 묶는다.

1. 기존 XML 스캐너와 JSZip 템플릿 패턴, 패트롤 AI 인증·조직 검사·사용량 기록을 재사용한다.
2. 원본 양식 셀 매핑과 사실/미기록 구분을 테스트로 먼저 정의한다.
3. 계획 전용 API를 gpt-6-luna low로 고정하고 ID·응답 형식을 엄격히 검사한다.
4. 다운로드 잠금·진행·오류 및 범위/개별 버튼을 통합한다.
5. 테스트·린트·타입 검사와 원본/생성 표본의 한글 열기·PDF 렌더를 검증한다.

완료 사실·날짜·서명은 추정하지 않는다. 계획 문구는 AI 초안이며 제출 전에 검토한다. 본문이 양식 허용량을 넘으면 원본 양식을 복제한 다음 쪽으로 이어 쓴다. AI 입력은 지적별 10,000자 초과 시 명시적 오류를 돌려준다. 원본 보존을 위해 점검별 파일을 유지한다.

빌드·커밋·푸시는 실행하지 않는다. 기존 사고 폴더와 사용방법.md는 변경하지 않는다.
