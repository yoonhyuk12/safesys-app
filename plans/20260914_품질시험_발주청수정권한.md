# 품질시험 발주청 수정 권한.

- 문제. 성과총괄표 감독 서명 후 저장이 작성자 전용 검사와 UPDATE RLS에 막힌다.
- 범위. 품질시험 관리대장 세 탭(성과총괄표·실시대장·확인시험 의뢰서)에서 모든 발주청 계정의 수정 저장을 허용한다.
- 기존 작성자 권한과 서명란별 소속 기준은 유지한다. 수정 시 created_by를 변경하지 않는다.
- 화면 권한 검사와 DB UPDATE 정책을 함께 변경하고, 수정 대상이 0건이면 저장 성공으로 표시하지 않는다.
- 기존 Node 테스트와 PGlite를 재사용해 역할별 허용/거부 및 작성자 보존을 검증한다. 새 패키지는 필요 없다.
- 린트·타입체크·관련 테스트 및 가능한 브라우저 확인 후 커밋한다.
