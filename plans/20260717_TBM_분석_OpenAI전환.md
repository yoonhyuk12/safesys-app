# TBM 분석 OpenAI 전환 계획

- TBM 텔레그램 분석 라우트의 Gemini 호출만 OpenAI Chat Completions로 교체한다.
- 기존 프롬프트, 검증, 권한 확인, 청크 처리, 결과 스키마는 유지한다.
- 모달 우측 상단의 닫기 버튼 왼쪽에 사용 모델명을 표시한다.
- 분석 결과 단계는 데스크탑에서 사용 가능한 가로폭을 모두 사용한다.
- 분석 요약과 메시지 컬럼이 결과 표의 여유 폭을 우선 사용하도록 배분한다.
- 결과 헤더에 분석 대상 TBM 항목을 한글로 표시한다.
- 현장명 셀에 지사명과 소관사업명을 괄호로 함께 표시한다.
- 분석 결과 표의 별도 소관사업 컬럼은 제거한다.
- 대상 선택 표의 현장명 아래에도 지사명을 표시한다.
- 진입 버튼과 모달의 사용자 노출 명칭을 AI 분석과 메시지 발송으로 통일한다.
- API가 JSON이 아닌 오류 본문을 반환해도 사용자에게 안전한 오류 메시지를 표시한다.
- 인증 401 응답에서는 세션을 한 번 갱신한 뒤 요청을 자동 재시도한다.
- 인증 서버 연결 실패와 실제 무효 토큰을 구분해 안내한다.
- AI 분석 대상은 사용자 소속 본부·지사 범위와 현재 조회 범위를 모두 적용한다.
- 준비·분석·발송 API에서도 사용자 소속 범위를 다시 검증한다.
- 결과 표의 메시지 오른쪽에 수신 가능·전송 컬럼을 두고, 현장별 발주청·시공사 전송 대상을 선택한다.
- 텔레그램 ID가 등록된 수신자만 기본 선택하고 현장별 선택을 발송 API까지 전달한다.
- 타입 검사와 대상 파일 ESLint로 검증한다.
