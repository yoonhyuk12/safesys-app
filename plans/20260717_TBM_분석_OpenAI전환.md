# TBM 분석 OpenAI 전환 계획

- TBM 텔레그램 분석 라우트의 Gemini 호출만 OpenAI Chat Completions로 교체한다.
- 기존 프롬프트, 검증, 권한 확인, 청크 처리, 결과 스키마는 유지한다.
- 모달 우측 상단의 닫기 버튼 왼쪽에 사용 모델명을 표시한다.
- 분석 결과 단계는 데스크탑에서 사용 가능한 가로폭을 모두 사용한다.
- 분석 요약과 메시지 컬럼이 결과 표의 여유 폭을 우선 사용하도록 배분한다.
- 결과 헤더에 분석 대상 TBM 항목을 한글로 표시한다.
- 현장명 셀에 지사명과 소관사업명을 괄호로 함께 표시한다.
- 분석 결과 표의 별도 소관사업 컬럼은 제거한다.
- 대상 선택 표의 현장명 아래에도 지사명을 표시한다.
- 타입 검사와 대상 파일 ESLint로 검증한다.
