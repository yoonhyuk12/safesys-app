# 수시 위험성평가 현황 카드 (안전현황)

작성일 2026-08-03. `/safe` 안전현황에 "수시 위험성평가" 현황 카드를 추가하고, 본부→지사→프로젝트 3단 드릴다운으로 월별 작성 건수를 집계한다.

## 배경

`/project/[id]/risk-assessment`(수시 위험성평가 서류철)는 이미 구현되어 `risk_assessments` 테이블에 평가서를 쌓고 있다. 다만 프로젝트 안에서만 볼 수 있어, 발주청이 본부·지사 단위로 "어느 현장이 몇 월에 몇 번 했는지"를 한눈에 볼 방법이 없다.

기존 "작업계획서" 현황 카드(`WorkPlanStatusView`)가 같은 3단 드릴다운 + 연도 선택 구조를 갖고 있으므로 이를 골격으로 삼는다. 다른 점은 유형별 컬럼 자리에 1~12월 컬럼이 들어간다는 것뿐이다.

## 사용자 확정 사항

- **월 집계 기준은 `created_at`(작성일).** `risk_assessments`에는 점검 시행일에 해당하는 컬럼이 없다. `manage_period_start`(관리기간 시작일)는 nullable이라 후보에서 제외했고, 작업계획서 현황과 같은 기준을 쓰는 편이 카드 간 일관성이 있다.
- **본부·지사·프로젝트 3단 표 모두 1~12월 컬럼을 노출한다.** 가로 스크롤이 생기더라도 어느 단계에서든 월별 흐름이 바로 보이는 쪽을 택했다.
- **"미작성 프로젝트" 컬럼은 넣지 않는다.**

## 범위

### 1. 뷰 컴포넌트 (신규)

`safesys-app/src/components/dashboard/RiskAssessmentStatusView.tsx`

- props — `{ initialHq: string | null; initialBranch: string | null; onBack: () => void }` (다른 현황 뷰와 동일한 계약)
- 데이터 — `getProjectsByUserBranch(userProfile)` 로 권한 범위 프로젝트를 받고, `risk_assessments`를 1회 조회해 클라이언트에서 필터·집계
- 연도 선택 — 우측 상단 ChevronUp/Down 스피너. 데이터가 있는 최신 연도로 최초 1회 자동 설정
- 컬럼
  - 본부/지사 표 — `본부(지사) | 대상 프로젝트 | 작성 프로젝트 | 합계 | 1 … 12`
  - 프로젝트 표 — `프로젝트명 | 합계 | 1 … 12 | 최근 작성일`
  - 값이 0인 달은 `-`
- 최상단 소계 행
- 준공 프로젝트는 숨기되, 선택 연도에 작성 건이 있으면 표시
- 프로젝트 행 클릭 → `/project/[id]/risk-assessment?returnUrl=...`
- 발주청 role 게이팅

### 2. 라우트 (신규)

- `safesys-app/src/app/safe/risk-assessment/page.tsx`
- `safesys-app/src/app/safe/branch/[branch]/risk-assessment/page.tsx`

둘 다 기존 `work-plan` 라우트와 동일한 thin `<Dashboard />` 래퍼.

### 3. Dashboard 배선

`safesys-app/src/components/Dashboard.tsx` 4곳.

1. import 추가 (41행 `WorkPlanStatusView` 옆)
2. 지사 경로 카드키 화이트리스트 (518행 부근) 에 `'risk-assessment'` 추가
3. 루트 경로 카드키 화이트리스트 (530행 부근) 에 `'risk-assessment'` 추가
4. 렌더 블록 추가 (`selectedSafetyCard === 'five-key'` 블록 뒤, 3648행 부근)
5. 카드 JSX 추가 (작업계획서 카드 뒤, 4062행 부근) — 아이콘 `ShieldAlert`, rose 계열

> 화이트리스트 2곳을 빠뜨리면 카드 라우트가 인식되지 않는다. 5대 핵심이행사항 카드 구현 때 같은 함정을 겪었다.

## 병렬 Worker 분담
