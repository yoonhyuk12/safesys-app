# 발주청 캐비넷 — AI 공사감독일지 작성 기능

## 목표

발주청 캐비넷의 "AI 공사감독일지" 서류철을 작업일보 페이지와 같은 캘린더 형태로 만들고, `/tbm`의 AI공감일지(공사감독일지 엑셀 생성) 기능을 그대로 가져온다. 단, 별도 서버 저장은 없다.

## 사용자가 확정한 동작 (Option B)

- 메인 페이지에는 TBM 제출일을 표시하는 캘린더(표시 전용)를 둔다.
- 캘린더 우측 상단에 "감독일지 작성" 버튼을 둔다.
- 버튼 클릭 → `/tbm`의 기간선택 달력 모달 → 옵션 모달(이름·AI토글·서명) → 엑셀 다운로드. `/tbm`과 동일한 흐름.
- DB 테이블/마이그레이션 없음. `tbm_submissions`만 읽고 결과물은 엑셀 다운로드로 끝.

## 구현 방식

`/tbm`의 `TBMStatus.tsx`(약 4,800줄)는 건드리지 않는다. 검증된 공유 엔진 `generateSupervisorDiaryExcel`을 재사용하고, 두 모달 + 진행률 오버레이를 새 컴포넌트로 충실히 포팅한다.

### 1. 새 컴포넌트 `SupervisorDiaryGenerator.tsx`

- props: `isOpen`, `onClose`, `projectId`, `projectName`, `managingHq`, `managingBranch`, `defaultEndDate`.
- 열리면 해당 사업의 TBM 제출 일자 로드(project_id + 이름/본부/지사) → 기간선택 모달.
- 기간선택 모달 → 옵션 모달 → `generateSupervisorDiaryExcel(...)` → 진행률 오버레이 → 다운로드.
- 포팅 출처: `TBMStatus.tsx` 진행률 3748-3811, 기간선택 3963-4197, 옵션 4199-4517, 생성 핸들러 4418-4505.

### 2. 페이지 재작성 `project/[id]/supervisor-diary/page.tsx`

- 현재는 "준비중" 플레이스홀더 → 캘린더 페이지로 교체.
- 작업일보 페이지(`work-daily-report/page.tsx`)의 캘린더 레이아웃·`loadTbmDates` 재사용.
- 헤더 + 캘린더(TBM `*` 표시) + 우측 상단 "감독일지 작성" 버튼(emerald-teal 그라데이션, /tbm 버튼과 동일 색) + `<SupervisorDiaryGenerator>`.

## 검증

- `npx tsc --noEmit`로 신규 파일 타입 오류 0 확인.
- 빌드는 동의 없이 실행하지 않음(프로젝트 규칙).
