> 대상: 공사감독(감리단) 신규 사용자
> 목적: 가입부터 일상 업무 활용까지 전 과정 안내
> 예상 슬라이드: 약 50~55장
> 작성일: 2026-04-03

---

## 제1부: 시스템 소개 및 접속 (슬라이드 1~6)

### 슬라이드 1 — 표지
- 제목: **안전관리시스템(SafeSys) 공사감독 활용안내**
- 부제: 가입부터 현장 활용까지
- 로고, 날짜, 작성부서
- **디자인**: 메인 컬러(#2563EB) 배경, 건설현장 이미지 오버레이

### 슬라이드 2 — 목차
- 제1부: 시스템 소개 및 접속
- 제2부: 회원가입 및 로그인
- 제3부: 대시보드 화면 구성
- 제4부: 프로젝트 관리
- 제5부: PDCA 서류철 활용
- 제6부: AI 기능 활용
- 제7부: 안전현황 대시보드
- 제8부: 보고서 생성 및 내보내기
- 제9부: 모바일(PWA) 활용
- 부록: FAQ / 용어 정리 / 문의처

### 슬라이드 3 — 시스템 개요
- **SafeSys란?** → 건설현장 안전관리 통합 플랫폼
- 핵심 가치 흐름도:
  ```
  현장 안전점검 → 데이터 기록 → AI 분석 → 보고서 자동생성 → 이력 관리
  ```
- 주요 기능 한눈에 보기 (아이콘 8개):
  | 아이콘 | 기능 | 설명 |
  |--------|------|------|
  | 📋 | 안전점검 | 본부/지사/정기 점검 기록 |
  | 🔧 | TBM 관리 | 일일 안전교육 제출·모니터링 |
  | 🌡️ | 폭염점검 | 열중질환 예방 현장 점검 |
  | 👷 | 근로자관리 | 등록·교육·서류 통합 관리 |
  | 🤖 | AI 분석 | 위험분석·점검표·번역 자동화 |
  | 📊 | 보고서생성 | PDF/Excel/HWP 자동 생성 |
  | 📱 | 모바일 현장활용 | PWA로 현장에서 바로 사용 |
  | 🔔 | 텔레그램 알림 | 점검 결과 실시간 공유 |

> **발표 포인트**: "기존 수기 점검표 → 디지털 전환으로 업무 효율 극대화"

### 슬라이드 4 — 사용자 역할 구분
- 역할별 접근 가능 기능 비교표:

  | 기능 | 발주청 | 감리단 | 시공사 |
  |------|:------:|:------:|:------:|
  | 전사 데이터 조회 | ✅ | ❌ | ❌ |
  | 지사별 현황 모니터링 | ✅ | ✅(소속) | ❌ |
  | 프로젝트 등록/수정 | ✅ | ✅ | ✅ |
  | 안전점검 실행 | ✅ | ✅ | ❌ |
  | TBM 제출 | ❌ | ❌ | ✅ |
  | TBM 점검/모니터링 | ✅ | ✅ | ❌ |
  | 근로자 관리 | ✅ | ✅ | ✅ |
  | 보고서 생성 | ✅ | ✅ | ✅ |
  | AI 기능 | ✅ | ✅ | ✅ |

- **감리단(공사감독)** ← 이 안내서의 대상 강조 표시
- 감리단 핵심 역할: 프로젝트 안전점검 실행, PDCA 서류 관리, 보고서 작성, 시공사 TBM 점검

> **발표 포인트**: "감리단은 현장 안전관리의 실행 주체로, 점검·기록·보고 전 과정을 시스템에서 수행"

### 슬라이드 5 — 접속 방법
- **PC 접속**:
  - URL: https://safesys.vercel.app/
  - 권장 브라우저: Chrome / Edge (최신 버전)
  - 접속 화면 스크린샷 + URL 입력 부분 빨간 원 표시
- **모바일 접속**:
  - 동일 URL → PWA 설치하면 앱처럼 사용
  - "제9부에서 PWA 설치 방법 상세 안내" 참조 표시
- **네트워크**: 인터넷 연결 필수 (오프라인 미지원)

### 슬라이드 6 — 시스템 이용 흐름 전체 요약
- 전체 업무 흐름도 (인포그래픽):
  ```
  ① 회원가입/승인 → ② 프로젝트 배정 → ③ 서류철(PDCA) 관리
       → ④ 현장 점검 기록 → ⑤ AI 분석 활용 → ⑥ 보고서 생성/제출
  ```
- 각 단계별 해당 슬라이드 번호 표기 (빠른 참조용)

> **발표 포인트**: "이 흐름도를 기억하시면 전체 시스템 사용이 쉬워집니다"

## 제2부: 회원가입 및 로그인 (슬라이드 7~13)

### 슬라이드 7 — 회원가입 절차 요약
- 3단계 절차 다이어그램:
  ```
  ① 약관 동의 → ② 정보 입력 → ③ 이메일 인증 완료
  ```
- 소요 시간: 약 3~5분
- 필요한 것: 이메일 주소, 전화번호

### 슬라이드 8 — 약관 동의
- 화면 캡처 (약관 동의 페이지)
- 동의 항목:
  - ✅ 이용약관 동의 (필수)
  - ✅ 개인정보 처리방침 동의 (필수)
- 전문 확인 가능 (스크롤 영역)
- 모두 동의 후 "다음" 버튼 활성화

> **발표 포인트**: "두 항목 모두 필수 동의이며, 약관 내용은 스크롤하여 확인 가능합니다"

### 슬라이드 9 — 회원가입 입력 항목
- 화면 캡처 (회원가입 폼 — 감리단 선택 상태)
- 입력 항목 상세:
  | 항목 | 입력 내용 | 비고 |
  |------|-----------|------|
  | 이메일 | 영문 이메일 주소 | 중복확인 자동 수행 |
  | 비밀번호 | 6자 이상 | 확인 재입력 |
  | 이름 | 실명 | |
  | 전화번호 | 010-XXXX-XXXX | 자동 포맷팅 |
  | 직위 | 감독관, 감리원 등 | |
  | **역할** | **감리단** 선택 | ← 빨간 원 강조 |
  | 소속 회사명 | 감리업체명 입력 | |

- 참고: 발주청 역할은 `@ekr.or.kr` 도메인만 가능
- 감리단은 도메인 제한 없음

> **발표 포인트**: "역할을 '감리단'으로 반드시 선택해주세요. 역할에 따라 사용 가능한 기능이 달라집니다"

### 슬라이드 10 — 본부/지사 선택 (발주청 전용 안내)
- 발주청 역할일 경우만 표시되는 항목
- 본부 선택 → 소속 지사 자동 필터링
- 예시: 경기본부 → 여주·이천지사, 양평·광주·서울지사 등
- **감리단은 이 단계 해당 없음** (스킵됨을 안내)
- 감리단은 프로젝트 배정을 통해 소속이 결정됨

> **발표 포인트**: "감리단은 본부/지사 선택 없이 바로 가입됩니다. 프로젝트 배정 시 소속이 자동 연결됩니다"

### 슬라이드 11 — 이메일 인증 및 가입 완료
- 가입 완료 시 입력한 이메일로 인증 메일 발송
- **24시간 이내 인증 필요** (빨간 강조)
- 인증 메일 수신 확인 방법:
  - 받은 편지함 확인
  - 스팸/정크 메일함 확인
  - 메일이 안 올 경우 재발송 가능
- 인증 완료 → 로그인 가능

### 슬라이드 12 — 로그인
- 화면 캡처 (로그인 화면)
- 로그인 구성 요소:
  - 이메일 입력
  - 비밀번호 입력
  - **로그인 정보 기억하기** 체크박스 (다음 접속 시 자동 입력)
  - 공유 버튼 (URL 복사/SNS 공유 — 동료에게 시스템 안내 시 활용)
- 로그인 실패 시 안내 메시지
- 하단: 아이디 찾기 / 비밀번호 찾기 링크

> **발표 포인트**: "'로그인 정보 기억하기'를 체크하면 다음 접속 시 편리합니다"

### 슬라이드 13 — 계정 관리 (아이디 찾기 / 비밀번호 변경 / 프로필 수정)
- **아이디 찾기**: 이름 + 전화번호 입력 → 등록된 이메일 확인 (일부 마스킹)
- **비밀번호 찾기**: 이메일 입력 → 재설정 메일 발송
- **프로필 수정** (로그인 후):
  - 변경 가능: 이름, 전화번호, 직위, 역할, 소속 회사
  - 프로필 아이콘 클릭 → 수정 화면 진입
- **비밀번호 변경**: 현재 비밀번호 확인 후 새 비밀번호 설정

## 제3부: 대시보드 화면 구성 (슬라이드 14~19)

### 슬라이드 14 — 메인 화면 레이아웃
- 화면 캡처 (메인 대시보드 전체 화면 — 영역별 번호 표시)
- ① **상단 헤더**: 로고, 사용자 이름·역할 표시, 프로필 수정 버튼, 로그아웃 버튼
- ② **뷰 전환 탭 바**: TBM | 지도 | 목록 | 안전현황 | 사업관리 (5개 탭)
- ③ **프로젝트 카드 영역**: 배정된 프로젝트 카드 목록
- ④ **PWA 설치 버튼**: 모바일에서 앱 설치 안내 (미설치 시 표시)
- ⑤ **분기 필터**: 현재 분기 공사중 현장만 보기 토글

> **발표 포인트**: "로그인 후 가장 먼저 보는 화면입니다. 상단 탭으로 원하는 뷰를 전환할 수 있습니다"

### 슬라이드 15 — 뷰 모드 상세 설명
- 각 뷰 모드별 화면 캡처 (5분할 또는 탭 전환 시연)

  | 뷰 모드 | 아이콘 | 용도 | 주요 활용 상황 |
  |---------|--------|------|---------------|
  | **TBM 현황** | 📋 | TBM 제출 현황 모니터링 | 매일 아침 시공사 TBM 제출 여부 확인 |
  | **지도 보기** | 🗺️ | 프로젝트 위치 지도 표시 | 관할 현장 위치 파악, 방문 계획 |
  | **목록 보기** | 📄 | 프로젝트 목록 검색/필터 | 특정 프로젝트 빠른 검색 |
  | **안전현황** | 🛡️ | 종합 안전점검 현황 | 지사별/카테고리별 점검 현황 한눈에 |
  | **사업관리** | 📦 | 자재수불부 관리 | 자재 입출고 기록 관리 |

> **발표 포인트**: "감리단이 가장 많이 사용하는 뷰는 TBM 현황(매일)과 안전현황(주간/월간)입니다"

### 슬라이드 16 — 프로젝트 카드 이해하기
- 프로젝트 카드 확대 캡처 + 각 요소 번호 표시
- ① **프로젝트명**: 클릭 시 상세 페이지 이동
- ② **위치 정보**: 시/군/구 행정구역
- ③ **상태 배지**: 공사중(녹색) / 중지(회색)
- ④ **분기 토글**: Q1~Q4 활성/비활성 상태 표시
- ⑤ **미조치 건수 배지**: 본부불시점검 미조치 건이 있으면 빨간 숫자 표시
- ⑥ **감독관 정보**: 담당 감독관 이름
- 카드 클릭 → 프로젝트 상세 페이지(PDCA 서류철) 이동

> **발표 포인트**: "빨간 배지가 보이면 미조치 건이 있다는 뜻입니다. 우선 확인이 필요합니다"

### 슬라이드 17 — 프로젝트 필터링 및 검색
- **본부/지사별 필터**: 드롭다운으로 소속 지사 필터링
- **검색**: 프로젝트명으로 빠른 검색
- **분기 필터**: 현재 분기 공사중 현장만 표시 토글
- **편집 모드**: 프로젝트 카드 순서 드래그&드롭 변경
- 화면 캡처 (필터 적용 전/후 비교)

### 슬라이드 18 — 프로젝트 등록
- **새 프로젝트 등록 절차** (단계별 스크린샷):
  1. "프로젝트 추가" 버튼 클릭
  2. 기본 정보 입력:
     - 프로젝트명 (필수)
     - 위치: 주소 검색 (VWorld 연동 — 입력 시 자동 완성)
     - 예산, 공사기간
     - 사업분류: 기반사업처 / 수자원시설처 / 환경사업처 / 산업단지처 등
  3. 감독관 정보: 이름, 전화번호
  4. 본부/지사 자동 배정
  5. 등록 완료

### 슬라이드 19 — 프로젝트 수정/삭제/공유/인수인계
- **수정**: 프로젝트 상세 → 메뉴 → 수정 (등록 정보 변경)
- **삭제**: 프로젝트 상세 → 메뉴 → 삭제 (확인 후 삭제)
- **공유**: 프로젝트 URL 복사 → 동료에게 전달
- **인수인계**: 프로젝트 상세 → 메뉴 → 인수인계
  - 다른 사용자에게 프로젝트 관리 권한 이전
  - 담당자 변경 시 활용 (인사이동, 휴가 등)

> **발표 포인트**: "인수인계 기능은 담당자 변경 시 매우 유용합니다. 데이터가 모두 유지됩니다"

## 제4부: 프로젝트 상세 및 PDCA 서류철 (슬라이드 20~34)

### 슬라이드 20 — 프로젝트 상세 페이지 구성
- 화면 캡처 (프로젝트 상세 전체 화면)
- **프로젝트 기본 정보 영역**:
  - 프로젝트명, 위치, 예산, 공기
  - 감독관: 이름 + 📞 전화 아이콘 (탭하면 바로 전화 연결)
  - CCTV 연동 버튼 (설정된 경우)
  - 프로젝트 상태: 공사중 / 중지 전환
- **PDCA 서류철 메뉴 영역**: 4개 색상 카테고리로 구분

> **발표 포인트**: "감독관 전화번호를 탭하면 바로 전화 연결됩니다. 현장 연락 시 편리합니다"

### 슬라이드 21 — PDCA 서류철 시스템 개요
- **PDCA 개념 설명 인포그래픽**:
  ```
  P(Plan/계획) 🔴 → D(Do/실행) 🟡 → C(Check/점검) 🔵 → A(Act/조치) 🟢
  ```
- **서류철 전체 목록표**:

  | 구분 | 색상 | 서류철명 | 서류철 수 |
  |------|------|---------|----------|
  | **P (계획)** | 🔴 빨강 | 안전서류, 시공서류, 품질서류, 위험성평가 AI GPT, (AI)수시위험성평가 | 5개 |
  | **D (실행)** | 🟡 노랑 | AI TBM일지, 신규근로자교육, 근로자관리, 폭염점검, 자재수불부, PTW(작업허가) | 6개 |
  | **C (점검)** | 🔵 파랑 | 본부안전점검, 지사안전점검, 정기점검, 안전점검GPT, (AI)일일안전점검 | 5개 |
  | **A (조치)** | 🟢 초록 | 관리자TBM점검, 휴일작업관리, 지적사항관리 | 3개 |

  **총 19개 서류철**로 건설 안전관리 전 영역 커버

> **발표 포인트**: "PDCA 사이클로 계획→실행→점검→조치의 체계적 안전관리가 가능합니다"

### 슬라이드 22 — [P] 안전서류관리 / 시공서류 / 품질서류
- **안전서류관리**: 안전 관련 문서 업로드 및 관리
- **시공서류관리**: 시공 관련 서류 정리
- **품질서류관리**: 품질 관리 문서 보관
- 공통 기능:
  - 문서 카테고리별 분류
  - 파일 업로드 (이미지, PDF 등)
  - 문서 상태 관리 (준비중/완료)

### 슬라이드 23 — [P] 위험성평가 AI GPT
- **AI 기반 위험성평가 자동 작성**:
  - 오늘의 작업 내용 입력
  - 인원, 장비 정보 입력
  - AI가 자동으로 생성:
    - 잠재 위험요인 분석
    - 위험등급 평가
    - 안전대책 및 예방조치 제안
- 생성된 내용 수정/보완 가능
- 위험성평가표 PDF 출력

> **발표 포인트**: "AI가 작업 내용을 분석하여 위험요인과 대책을 자동으로 제안합니다. 검토 후 수정하여 사용하세요"

### 슬라이드 24 — [D] 일일안전교육 (AI TBM일지)
- **TBM(Toolbox Meeting) 일일 안전교육 기록**
- 시공사가 매일 제출하는 TBM 일지 확인
- 주요 기능:
  - 작업 내용, 인원, 장비 기록
  - 잠재 위험 3건 + 대책 기록
  - **AI 안전 조언**: 작업 내용 기반 6개 핵심 안전수칙 자동 생성
  - 제출 현황 캘린더 뷰 (제출일 표시)
  - TBM 일지 PDF 다운로드
  - TBM 뷰 상세 페이지: **15개 언어 번역 + TTS 음성 재생** 지원

> **발표 포인트**: "외국인 근로자가 많은 현장에서는 다국어 번역·음성 기능이 특히 유용합니다"

### 슬라이드 25 — [D] 신규근로자 현장안내
- **신규 근로자 현장 교육 기록**
- 입력 항목:
  - 교육 일시, 장소, 교육시간
  - 근로자 출석부 (이름 + 서명)
  - 멘토 지정 및 서명
  - 주요 작업종류 / 위험요인 기록
  - 관리자 서명 및 특기사항
- **Excel 내보내기**: 교육 기록 일괄 다운로드
- 교육 이수 현황 추적

### 슬라이드 26 — [D] 근로자관리대장
- **근로자 통합 관리**
- 등록 정보:
  - 이름, 생년월일, 연락처
  - 외국인 여부 / 비자 종류
  - 신분증 사진, 자격증 사진 업로드
  - 전자 서명 수집
- **동의서 관리**:
  - 개인정보 수집 동의서
  - 건강설문 (근로자 건강 상태 확인)
  - 안전서약서 (장비 사용 동의 + 서명)
- **QR코드 근로자 자가 등록**: 링크 생성 → 근로자 스마트폰으로 직접 입력
  - 4단계: ① 개인정보 → ② 동의서 → ③ 건강설문 → ④ 안전서약+서명
  - 신분증/자격증 카메라 촬영 및 **AI OCR 자동 인식**
- **일괄 인쇄**: 동의서, 건강설문, 안전서약 문서 생성

> **발표 포인트**: "QR코드를 현장에 비치하면 근로자가 스마트폰으로 직접 등록할 수 있습니다. 수기 작성 대비 시간을 크게 절약합니다"

### 슬라이드 27 — [D] 폭염대비점검
- **열중질환 예방 현장 점검 기록**
- 월별 캘린더 뷰 (점검일 색상 표시)
- 점검 항목 체크리스트:
  | 점검 항목 | 내용 |
  |-----------|------|
  | 온도 기록 | 현장 기온·체감온도 |
  | 음용수 | 깨끗한 음용수 비치 여부 |
  | 휴게시설 | 그늘막·쉼터 설치 확인 |
  | 냉방장비 | 선풍기·에어컨 작동 확인 |
  | 응급조치 | 응급키트·비상연락체계 확인 |
  | 근무시간 | 폭염 시 근무시간 조정 여부 |
- 점검자 서명 + 현장 사진 첨부
- **월별/다월 점검 기록 일괄 다운로드**

### 슬라이드 28 — [D] 위험공종 작업허가제(PTW)
- **고위험 작업 사전 허가 관리**
- 작업 허가 신청 → 검토 → 승인 프로세스
- 위험공종 분류 및 안전대책 기록

### 슬라이드 29 — [C] 본부 안전점검 (본부불시점검)
- **본부 주도 예고 없는 현장 안전점검 기록**
- 기록 구성:
  - 점검일, 점검자 정보
  - 현장사진 촬영 (지적사항 2건)
  - **조치 전/후 사진 비교**: 좌우 배치로 개선사항 시각화
  - 조치 상태: 완료 ✅ / 미조치 ⏳
- **미조치 건수 추적**: 프로젝트 카드에 빨간 배지로 표시
- 미조치 건 클릭 → 해당 점검 기록으로 바로 이동

> **발표 포인트**: "미조치 건은 프로젝트 카드에 빨간 배지로 표시됩니다. 조치완료 사진 업로드 시 배지가 사라집니다"

### 슬라이드 30 — [C] 지사 안전점검 (관리자점검)
- **지사 단위 정기 안전점검 기록**
- 날짜별 점검 기록 생성
- 점검 내용:
  - 작업종류, 위험요인 기록
  - 이행상태 추적
  - 위험성평가 사진 첨부
  - 재해예방보고서 사진 첨부
  - 점검자 소견 작성
  - 점검자 연락처
- **분기별 관리**: 1~4분기 점검 현황 구분
- PDF 보고서 자동 생성

### 슬라이드 31 — [C] 정기점검 (안전점검 관리대장)
- **4개 시즌별 점검 관리**:
  | 시즌 | 시기 | 주요 점검 내용 |
  |------|------|---------------|
  | 해빙기 | 2~3월 | 동결 해소 후 구조물 안전 |
  | 우기 | 6~9월 | 배수, 침수, 사면 안전 |
  | 종합 | 연중 | 전반적 안전 상태 종합 점검 |
  | 특별 | 수시 | 특수 상황 발생 시 긴급 점검 |
- 탭 인터페이스로 시즌 선택
- 지적사항 기록: 내용 + 조치사항 + 전/후 사진
- **점검 보고서 PDF/HWPX 자동 생성**

### 슬라이드 32 — [C] AI 안전점검 기능
- **(AI)일일안전점검**: AI가 작업 내용 기반 23개 항목 점검표 자동 생성
  - 기본 점검 8항목 + 작업 특화 15항목
  - 입력: 오늘의 작업 설명
  - 출력: 구조화된 안전점검 체크리스트
- **안전점검 GPT**: AI와 대화형으로 안전점검 수행
- 생성된 점검표 수정/보완 후 저장

> **발표 포인트**: "AI가 생성한 점검표는 참고자료입니다. 현장 상황에 맞게 반드시 검토·수정하세요"

### 슬라이드 33 — [A] 관리자 TBM 활동 점검
- **월별 캘린더**로 TBM 활동 감사 현황 확인
- 점검 양식:
  - 점검 일시 선택
  - TBM 활동 체크리스트 확인
  - TBM 자료 사진 첨부
  - 현장 활동 사진 첨부
- 수정/삭제 가능
- TBM 활동 점검 보고서 PDF 생성

### 슬라이드 34 — [A] 휴일작업관리 / 지적사항관리
- **휴일작업관리대장**:
  - 휴일/야간 작업 신청 및 승인
  - 작업 내용, 인원, 안전조치 기록
- **지적사항관리대장** (자동):
  - 각 점검에서 발생한 지적사항 자동 수집
  - 조치 상태 통합 추적
  - 미조치 건 알림

## 제5부: AI 기능 활용 (슬라이드 35~38)

### 슬라이드 35 — AI 기능 전체 소개
- **SafeSys에 탑재된 8가지 AI 기능**:

  | AI 기능 | 위치 | 활용 장면 |
  |---------|------|----------|
  | AI 위험성평가 | P > 위험성평가 | 작업 위험요인 자동 분석 |
  | AI 수시위험성평가 | P > 수시위험성평가 | 돌발 상황 위험 분석 |
  | AI TBM 안전조언 | D > TBM일지 | 6개 핵심 안전수칙 생성 |
  | AI 일일안전점검 | C > 일일안전점검 | 23항목 점검표 자동 생성 |
  | AI 감독일지 요약 | 감독일지 | 일일 감독 내용 자동 요약 |
  | AI 번역 | TBM 뷰 | 15개 언어 안전문서 번역 |
  | AI 음성변환(TTS) | TBM 뷰 | 번역된 내용 음성 재생 |
  | AI OCR | 근로자관리 | 신분증/자격증 자동 인식 |

> **발표 포인트**: "AI 기능은 업무를 대체하는 것이 아니라 보조합니다. 생성 결과는 반드시 검토 후 사용하세요"

### 슬라이드 36 — AI 위험분석 & 안전조언 상세
- **AI 위험분석 시연 예시**:
  - 입력: "오늘 철근 조립 작업, 10명 투입, 타워크레인 사용"
  - AI 출력:
    - 잠재 위험요인: 추락, 낙하물, 크레인 전도 등
    - 위험등급: 고위험
    - 안전대책: 안전대 착용, 신호수 배치, 작업반경 통제 등
- **AI TBM 안전조언 예시**:
  - 작업 내용 기반 6개 핵심 안전수칙
  - 현장 특화 안전 메시지

### 슬라이드 37 — AI 다국어 번역 & 음성(TTS) 기능
- **지원 언어 15개** (국기 아이콘과 함께 표시):

  | 언어 | 국기 | 언어 | 국기 |
  |------|------|------|------|
  | 한국어 (기본) | 🇰🇷 | 태국어 | 🇹🇭 |
  | 영어 | 🇺🇸 | 인도네시아어 | 🇮🇩 |
  | 일본어 | 🇯🇵 | 타갈로그어 | 🇵🇭 |
  | 중국어(간체) | 🇨🇳 | 미얀마어 | 🇲🇲 |
  | 중국어(번체) | 🇹🇼 | 크메르어 | 🇰🇭 |
  | 베트남어 | 🇻🇳 | 네팔어 | 🇳🇵 |
  | 우즈베크어 | 🇺🇿 | 몽골어 | 🇲🇳 |
  | 러시아어 | 🇷🇺 | | |

- **활용 시나리오**: TBM 뷰 → 언어 선택 → 번역된 내용 표시 → TTS로 음성 재생
- **현장 활용법**: 외국인 근로자에게 오늘의 안전수칙을 모국어로 읽어줌
- 필드별 복사 기능: 번역된 내용 클릭 → 클립보드 복사

> **발표 포인트**: "외국인 근로자 비율이 높은 현장에서 활용도가 매우 높습니다"

### 슬라이드 38 — AI OCR & 감독일지 요약
- **AI OCR (카드 인식)**:
  - 근로자 기초안전보건교육 이수증 촬영
  - AI가 자동 인식: 성명, 생년월일, 등록번호, 이수일
  - 인식 결과 확인 후 자동 입력
- **AI 감독일지 요약**:
  - 일일 감독 활동 입력
  - AI가 투입인원·장비 현황 요약
  - 감독일지 작성 시간 단축

## 제6부: 안전현황 대시보드 (슬라이드 39~43)

### 슬라이드 39 — 안전현황 메인 화면
- 화면 캡처 (안전현황 뷰 전체)
- 안전현황 뷰 진입: 상단 탭 → **안전현황** 클릭
- **카테고리 카드 8개**:

  | 카테고리 | 내용 | 주요 지표 |
  |---------|------|----------|
  | 폭염점검 | 열중질환 예방 점검 현황 | 날짜별 점검 완료율 |
  | 관리자점검 | 지사 안전점검 현황 | 분기별 점검 이력 |
  | 본부불시점검 | 본부 점검 현황 | 미조치 건수 추적 |
  | TBM | TBM 제출 현황 | 프로젝트별 제출율 |
  | 안전서류 | 안전서류 관리 현황 | 서류 준비 상태 |
  | 정기점검 | 안전점검 관리대장 | 시즌별 점검 현황 |
  | 신규교육 | 신규근로자 교육 현황 | 교육 이수 현황 |
  | 근로자 | 근로자 관리 현황 | 등록·서류 현황 |

- 전체 현황 vs 지사별 현황 전환

### 슬라이드 40 — 지사별 안전현황 조회
- **지사 선택** → 해당 지사 프로젝트만 필터링
- URL 기반 라우팅: `/safe/branch/[지사명]/[카테고리]`
- 뒤로가기 버튼으로 상위 뷰 복귀
- 화면 캡처 (지사 선택 전/후 비교)

> **발표 포인트**: "지사명을 선택하면 해당 지사 관할 프로젝트만 모아서 볼 수 있습니다"

### 슬라이드 41 — 안전현황 상세 조회 — 폭염/관리자점검
- **폭염점검 현황**:
  - 날짜별 점검 완료율 표시
  - 미점검 프로젝트 강조
- **관리자점검 현황**:
  - 프로젝트별 점검 이력 목록
  - 분기별 위험성평가 완료 현황
  - 일괄 보고서 생성 버튼

### 슬라이드 42 — 안전현황 상세 조회 — 본부점검/TBM
- **본부불시점검 현황**:
  - 미조치 건수 실시간 추적
  - 프로젝트별 점검 이력
  - 조치 전/후 사진 대비
- **TBM 현황**:
  - 프로젝트별 TBM 제출 현황
  - 미제출 현장 강조 표시
  - 날짜별 제출 이력

### 슬라이드 43 — 일괄 보고서 다운로드
- **다중 프로젝트 일괄 처리**:
  - 체크박스로 대상 프로젝트 선택
  - 일괄 PDF 생성 (여러 프로젝트 한 번에)
  - 일괄 Excel 다운로드
  - 지사별 종합 보고서 생성
- **다운로드 진행률** 표시 (대량 생성 시)
- 생성 중 취소 가능

> **발표 포인트**: "월말/분기말 보고서 작성 시 일괄 다운로드 기능으로 시간을 크게 절약할 수 있습니다"

## 제8부: 모바일(PWA) 활용 (슬라이드 48~51)

### 슬라이드 48 — PWA란? & 설치 방법
- **PWA(Progressive Web App)란?**
  - 웹사이트이지만 앱처럼 설치하여 사용
  - 앱스토어 다운로드 불필요
  - 설치 후 홈 화면 아이콘으로 실행
- **설치 방법 (기기별)**:

  | 기기 | 브라우저 | 설치 방법 |
  |------|---------|----------|
  | **아이폰** | Safari | 공유 버튼(□↑) → "홈 화면에 추가" |
  | **안드로이드** | Chrome | ⋮ 메뉴 → "홈 화면에 추가" 또는 "앱 설치" |
  | **PC** | Chrome | 주소창 오른쪽 설치 아이콘(⊕) 클릭 |

- 각 기기별 스크린샷 (단계별 빨간 원 표시)

> **발표 포인트**: "현장에서는 PWA로 설치하면 앱처럼 바로 실행할 수 있어 편리합니다"

### 슬라이드 49 — 현장 모바일 활용 시나리오
- **시나리오 1: 아침 TBM 확인** (매일 08:00~09:00)
  - 앱 실행 → TBM 현황 확인 → 미제출 현장 연락
- **시나리오 2: 현장 점검 중** (수시)
  - 지적사항 발견 → 카메라로 바로 촬영 → 점검 기록에 첨부
  - 전자서명 현장 수집 (터치로 서명)
- **시나리오 3: 근로자 등록** (수시)
  - QR코드 표시 → 근로자 스마트폰 스캔 → 자가 등록
  - 신분증 촬영 → AI OCR 자동 인식
- **시나리오 4: 외국인 안전교육** (수시)
  - TBM 뷰 → 언어 선택 → 번역 내용 표시 → TTS 음성 재생
- **시나리오 5: 폭염점검** (하절기 매일)
  - 현장에서 체크리스트 확인 → 사진 촬영 → 실시간 기록

### 슬라이드 50 — 업데이트 알림
- 새 버전 배포 시 화면 상단에 알림 배너 표시
- **"새 버전이 있습니다"** 메시지
- 알림 클릭 → 자동으로 최신 버전 적용 (페이지 새로고침)
- 나중에 업데이트: 닫기(X) 버튼으로 나중에
- 서비스 워커가 백그라운드에서 자동 업데이트 준비

### 슬라이드 51 — 모바일 사용 팁
- **카메라 권한**: 최초 사진 촬영 시 권한 허용 필요
- **알림 설정**: 브라우저 알림 허용 시 텔레그램 알림 연동
- **데이터 절약**: Wi-Fi 환경에서 대용량 보고서 다운로드 권장
- **화면 잠금**: 서명 입력 시 화면 자동 잠금 해제 확인
- **북마크**: PWA 미설치 시 브라우저 즐겨찾기 등록
