# 품질시험 실시대장 시험구분 선택 흐름

## 목표

품질시험 실시대장의 `추가` 버튼을 누르면 등록 폼을 바로 열지 않고 시험·검사구분 선택 창을 화면 중앙에 표시한다. 사용자가 `자체(관리)시험`, `의뢰(수탁)시험`, `확인시험` 중 하나를 선택하면 해당 값을 초기값으로 반영한 기존 등록 폼을 연다.

## 구현 범위

1. `QualityTestRecordsTab`에 시험구분 선택 창 표시 상태를 추가한다.
2. 헤더와 빈 상태의 `추가` 버튼이 선택 창을 열도록 연결한다.
3. 시험구분 선택 시 기존 신규 등록 초기화 흐름을 실행하고 선택값을 `test_category`에 반영한다.
4. 선택 창은 닫기 버튼, 배경 클릭, Escape 키로 취소할 수 있게 한다.
5. 기존 수정·저장·서명·출력 흐름과 현재 미커밋 변경은 보존한다.
6. 각 시험구분은 아이콘과 한 줄 정의가 있는 선택 카드로 표시한다.
7. 대상 재료 프리셋은 이전 기록·토공·콘크리트로 구분하고, 콘크리트는 시험 유형과 규격을 순서대로 고르게 정리한다.

## 검증 기준

- 두 `추가` 버튼 모두 선택 창을 연다.
- 세 시험구분 중 하나를 누르면 선택 창이 닫히고 등록 폼이 열린다.
- 등록 폼의 시험·검사구분은 사용자가 선택한 값과 일치한다.
- 취소 동작은 등록 폼을 열지 않는다.
- 프리셋의 기존 자동 입력 항목과 기준값은 변경되지 않는다.
- `npx tsc --noEmit`, `npm run lint`, 브라우저 수동 시나리오가 통과한다.
