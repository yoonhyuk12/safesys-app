# 사고보고 PDF 사진 자동 추출

PDF 업로드 시 본문 AI 초안과 별도로 브라우저에서 embedded raster 사진 후보를 최대 2장 추출한다. 기존 사진과 처리 중 사용자가 변경한 사진 목록은 보존하며 자동 저장하지 않는다.

1. Mozilla PDF.js 공식 API와 npm 버전을 확인하고 exact pin 및 same-origin worker 번들을 사용한다.
2. 4MB 입력, 앞 8쪽, 최대 12MP 이미지, 15초 처리 제한을 두고 작은 그림·마스크·쪽 전체 스캔을 제외한다.
3. JPEG 정규화와 별도 `result.photos` 반환, 최신 목록 기반 안전 병합 및 확인 안내를 구현한다.
4. 합성 PDF 회귀 테스트, scoped lint 및 tsc로 검증한다. 브라우저와 HWPX 실물 검증은 부모 담당이다.

작업 기록은 [체크리스트](./20260916_사고보고_PDF사진자동추출/checklist.md), [컨텍스트](./20260916_사고보고_PDF사진자동추출/context-notes.md), [보고서](./20260916_사고보고_PDF사진자동추출/report.md)에 기록한다. 추가 에이전트·build·commit·push·DB 변경은 수행하지 않는다.
