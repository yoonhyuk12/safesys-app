## 표 구조

3부(시설물·공종별)의 모든 표는 동일한 컬럼을 쓴다.

```
시설물 │ 검사(검측) 대상            │ 검사  │ 시기 │ 책임 검사지정
       │ 공종(분류) │ 대상         │ 방법  │      │ 공감소(감독원)│지역본부 사업단│본사 주관부서
```

검사방법은 검측·검사·시험·점검·검수·검토로 구분된다([[검사방법]]). 책임 검사지정은 ○ 표시로 해당 주체를 지정한다([[책임검사지정]]).

## 판독 한계 (중요)

- 이 PDF는 한글 폰트에 ToUnicode 매핑이 없어 `pdftotext` 추출이 깨진다(라틴·숫자만 복원).
- 따라서 모든 내용은 페이지를 2.5~3.5배 이미지로 렌더링해 **시각 판독**한 것이다.
- 작은 글씨의 "대상" 셀, 일부 공종명, 책임지정 ○ 위치는 오독 가능성이 있다.
- 각 시설물 페이지 하단의 "판독 주의" 절에 불확실 항목을 모았다. 현장 적용 전 원본 대조 필수.
