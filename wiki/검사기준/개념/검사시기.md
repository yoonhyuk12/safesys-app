# 검사시기

검사 매트릭스의 "시기" 축은 검사를 **언제** 수행하는지를 나타낸다. 원본 표에 등장하는 시기 값은 다음과 같다.

| 시기 | 의미 | 대표 등장 대상 |
|------|------|----------------|
| **성과품 제출시** | 측량 성과품 제출 시점 | 기준BM·IP·삼각점 측량 |
| **타설전** | 콘크리트 타설 직전 | 철근·거푸집 규격, 청소 상태 |
| **설치시** | 부재 설치 시점 | 철근 두께, 동바리 배치·조임재 |
| **매립전** | 구조물 매립 직전 | 매립되는 구조물 규격 |
| **완료시** | 해당 공정 완료 시점 | 구조물 계획고, 굴착·터파기 단면, 노출면 상태 |
| **제거시** | 부재 해체 시점 | 거푸집 존치기간 |
| **필요시** | 필요에 따라 수시 | 자재 보관 상태, 반입 자재 수량, 점토대 폭 |
| **발생시 / 요청시** | 사안 발생 또는 감독원 요청 시 | 암절분류, 토공량(암발생량), 용출수 |
| **수시** | 진행 중 상시 | 계측관리, 토목섬유 포설, 문비 시공상태 |
| **시공전 / 시공후 / 시공전·후** | 시공 전후 단계 | 사석·피복공·돌망태, 도로 포장 두께 |
| **분기별** | 분기 단위 반복 | 담수 후 누수·침수·정착 확인 |
| **2회이상** | 최소 2회 반복 검사 | 양·배수장 시운전 항목 |
| **준공·인수** | 준공 및 인수 시점 | 방조제 시운전(작동·수압·누수) |

## 참고

- 시기는 시설물·공종에 따라 같은 대상도 달라진다. 시설물별 정확한 시기는 [[공통]] · [[저수지]] · [[양배수장]] · [[방조제]]의 표를 본다.
- 방법 축은 [[검사방법]], 책임 축은 [[책임검사지정]] 참조.

## 판독 주의

일부 시기 셀은 병합·소형 글씨로 판독이 불확실하다(특히 그라우팅 투수시험, 일부 기계·전기 항목). 해당 페이지의 "판독 주의" 절 참조.
